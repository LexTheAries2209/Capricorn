# Capricorn V3.0.0

发布日期：2026-10-30

完整版本 `3.0.0`，Build `0049`。构建号是独立、全局递增的四位发布构建序号，不再拼入版本号。

## 更新内容

- 新增实验性 USB-NVMe SNT SMART 手动读取，自动选择兼容的桥接协议，并尝试恢复卷挂载。
- SMART 页面提供读取引导，右键菜单支持刷新 SNT SMART；展示读取到的序列号，并保留手动读取结果。
- 分别显示物理设备容量与卷容量，完善 USB SMART 数据来源和读取状态说明。

## 安装与兼容性

下载 `Capricorn-v3.0.0-macOS.zip`，解压并安装 `Capricorn.app`。要求 macOS 14.0 或更高版本，提供 arm64 / x86_64 Universal App。V2.10.2 及以后支持应用内更新；更早版本或旧开发 Build `1000` 需手动安装。

常规 SMART 继续使用内置 smartctl 7.5。实验性 SNT 工具单独提供，支持 JMicron、ASMedia、Realtek USB-NVMe 桥接协议；不保证所有桥接器、固件或存储卡兼容，不等于通用 SD 卡健康读取。

SNT 只在用户手动确认后运行，需要管理员授权，并会暂时卸载该 USB 设备上的所有卷。请先关闭相关文件、结束其他磁盘任务并备份重要数据。释放设备后会尝试恢复原有挂载，恢复失败时可能需要重新连接设备或使用“磁盘工具”。普通自动刷新不会自动接管 USB 设备。

应用不会自动安装 SAT SMART Drive。测速及负载使用选定文件夹内的临时文件，请确认目标并保留备份。

App 使用有效 ad-hoc 签名，更新包及清单使用既有 Ed25519 密钥。没有 Developer ID 或 Apple 公证。
