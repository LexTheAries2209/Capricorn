## 中文

Capricorn V1.1.1 使用 `Version = 1.1`、`Build = 1` 和 Display Name `Capricorn V1.1.1`。本版改善 SMART 数据可读性，并为实时活动和测速加入更灵活的续接与单项测试方式。

### 下载

- Release 包名：`Capricorn-v1.1.1-macOS.zip`
- App 名称：`Capricorn V1.1.1.app`
- 系统要求：macOS 14.0 或更新版本

### 重点更新

- 原生 macOS SMART 温度为 Kelvin 时，同时显示原始值和换算后的摄氏度；来源已是摄氏度时只显示摄氏度。
- macOS 原生和 `smartctl` 的 NVMe 累计读取/写入量统一换算为 TB，同时保留原始 Data Units 计数。
- 实时活动停止后可选择“继续监控”，新样本会续接当前图表；原有“开始监控”仍会清空图表并开始新的监控段。
- 点击测速矩阵左侧的绿色项目按钮，可沿用当前引擎、文件大小和数据模式，只运行该项目一次。
- 单项测速固定运行一次并关闭加量测试；正在测速时会阻止再次启动，并保留写入文件和当前配置确认。
- 新增“提高小块文件测试效率”：开启后可选择 5%、10%、20%、30% 或 50%，按比例缩减 4 KiB、16 KiB 和 64 KiB 项目的实际测试文件量。
- 小块文件效率控制默认关闭，首次开启默认 20%；测速期间锁定，完整测速与单项测速、同步与异步引擎均采用同一规则。
- 调整测速项目按钮文字布局，较长项目名称保持单行显示。

### 发布校验

## English

Capricorn V1.1.1 uses `Version = 1.1`, `Build = 1`, and the Display Name `Capricorn V1.1.1`. This release makes SMART values easier to read and adds more flexible continuation and single-item workflows for Live Activity and benchmarks.

### Download

- Release package: `Capricorn-v1.1.1-macOS.zip`
- App name: `Capricorn V1.1.1.app`
- Requirement: macOS 14.0 or later

### Highlights

- Native macOS SMART temperatures reported in Kelvin now show both the original value and a Celsius conversion; values already reported in Celsius remain Celsius-only.
- Native macOS and `smartctl` NVMe cumulative read/write values are converted to TB while retaining the raw Data Units count.
- After stopping Live Activity, Continue Monitoring appends new samples to the current chart; the existing Start Monitoring action still clears the chart and begins a new segment.
- Clicking a green benchmark-row button runs only that item once using the current engine, file size, and data pattern.
- Single-item runs force one pass and disable incremental testing. Active benchmarks block another run, and the write/configuration confirmation remains required.
- A new small-block efficiency option scales the actual test data for 4 KiB, 16 KiB, and 64 KiB items to 5%, 10%, 20%, 30%, or 50%.
- The option is off by default and starts at 20% when first enabled. It is locked during a run and works consistently for full/single-item and synchronous/asynchronous tests.
- Long benchmark item labels now remain on one line within the green row buttons.

### Release Verification

- Full test suite: 135 passed, 0 failed.

- Swift 6 compatibility build passed while the project remains on Swift 5 mode by default.
- The Release App contains arm64 and x86_64 and reports `Version = 1.1`, `Build = 1`, and `Capricorn V1.1.1`.
- `script/build_and_run.sh --verify` successfully built and launched the application.
