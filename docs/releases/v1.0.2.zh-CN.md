# Capricorn V1.0.2 发布说明

Capricorn V1.0.2 是第一个以新版本命名原则整理的公开发布版：`Version = 1.0`，`Build = 2`，因此 Display Name 显示为 `Capricorn V1.0.2`。

## 下载

- Release 包名：`Capricorn-v1.0.2-macOS.zip`
- App 名称：`Capricorn V1.0.2.app`
- 系统要求：macOS 14.0 或更新版本

首次打开时，如果 macOS Gatekeeper 提示来自互联网下载的 App，请在 Finder 中右键点击 App 后选择“打开”，或在“系统设置 > 隐私与安全性”中允许打开。

## 重点更新

- 更新为 Capricorn 命名和版本体系，Display Name 由 `Version + Build` 组成。
- 磁盘列表支持本机物理磁盘、外接 SSD、普通挂载分区、网络卷和 SD/SDXC 存储卡。
- 修复普通外接分区挂载点归属判断，例如 `/Volumes/40G4T_NTFS_E` 会正确映射到对应的外接物理磁盘。
- SMART 页面会根据数据来源自适应显示属性字段，并提供固定中文解释。
- SD/SDXC、网络卷、USB/NVMe 等 SMART 受限设备会显示有限支持说明，不再误导为标准硬盘 SMART。
- 测速页支持 Default、Peak/NVMe、RealWorld、Demo 和 Custom 配置。
- Custom 配置支持最多 4 个项目组，可选择 SEQ/RND、块大小、Q、T 和混合测试。
- 每个测速配置可选择同步或 POSIX AIO 异步引擎。
- 测速结果可保存本次实时磁盘活动曲线。
- 实时活动页支持独立监控、采样间隔选择、大文件读取/写入/读写混合负载和历史保存。
- 历史页支持 SMART、测速、实时活动记录隐藏、管理隐藏记录和恢复。
- 报告导出支持 JSON、CSV 和纯文本，默认隐藏序列号。

## 安全提示

- Capricorn 只在用户选择的目标文件夹里创建临时文件，不做裸设备写入。
- 写入、混合、循环和大文件负载会对存储设备造成压力和写入磨损。
- 运行测试前请确认目标文件夹位于你想测试的磁盘上。
- 网络卷可以作为文件夹测速目标，但不会提供本机单盘 IOKit 活动计数。
- 当前 Release 资产使用本地已构建 App 打包，未通过本仓库流程自动公证。

## 可选依赖

Capricorn 不捆绑 `smartctl`。如需更完整的 ATA/NVMe SMART 数据，可以自行安装 smartmontools：

```sh
brew install smartmontools
```

安装后请重启或刷新 Capricorn。

