# Capricorn V2.10.2

发布日期：2026-10-17。

## 版本与安装

- 完整版本 `2.10.2`，Build `0042`。构建号是独立、全局递增的四位发布构建序号，不再拼入版本号；迁移基线为此前核实的 41 次正式 Release。
- 下载 `Capricorn-v2.10.2-macOS.zip`，解压后将固定名称的 `Capricorn.app` 放到本地 Applications 目录。
- V2.10.1 及更早的公开版本尚无 Sparkle，需要手动安装本版一次。本地开发版若同为 Build `0042`，不会因营销版本变化被判定为新构建；Build `1000` 的旧开发包同样需要手动替换。
- 最低 macOS 14.0，包含 arm64 与 x86_64。

## 主要更新

- 新增应用内手动更新、启动时自动检查，以及可选的自动下载和退出时安装；更新偏好会保存。
- 有测速、实时监控、磁盘检查、自检等冲突任务时，提示并阻止更新；安装前保存历史。
- 更新设置采用更紧凑的检查时间与按钮布局，缩短错误提示；构建号可在开发者选项中开启显示，默认隐藏。

## 更新与安全

更新清单与安装包使用 Ed25519 签名验证，下载遵循 macOS 系统代理设置。本次 App 使用 ad-hoc 签名，没有 Developer ID 或 Apple 公证，首次打开仍可能需要在系统隐私与安全性设置中允许。

自动检查默认关闭；启用后每次启动完成首次磁盘刷新时检查一次。自动下载另行选择，默认关闭。手动检查始终可用，有冲突任务时仍会阻止。

SwiftData 历史位于应用数据目录，更新 App 不清理历史。测速写入只在所选文件夹中进行；写入、混合和大文件负载仍需注意设备与数据安全。内置 smartctl 7.5，无需额外安装。
