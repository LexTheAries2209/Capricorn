# Capricorn V1.2.5 发布说明

Capricorn V1.2.5 使用 `Version = 1.2`、`Build = 5`，Display Name 为 `Capricorn V1.2.5`。本版主要增强 SMART 自检、smartctl 7.5 兼容性和外接磁盘 SMART 信息布局。

## 下载

- Release 包名：`Capricorn-v1.2.5-macOS.zip`
- App 名称：`Capricorn V1.2.5.app`
- 系统要求：macOS 14.0 或更新版本

## 更新内容

- 提升 ATA、NVMe、SAT 自检日志解析兼容性，保留原始 smartctl JSON/文本作为回退。
- SMART 页面增加快速自检、完整自检、自动轮询和中止操作，并显示最近记录和详细状态。
- 概览仅显示最近一次设备自检摘要，完整日志和操作集中在 SMART 页面。
- macOS 原生 NVMe 不支持 admin command `0x14` 时不强行执行自检，保留可用的健康信息和日志读取。
- 系统盘自检可在设置中单独允许，并使用 macOS 管理员授权。
- 增强 smartctl 7.5 诊断与休眠磁盘保护；外接 SMART 信息已验证时默认折叠。
