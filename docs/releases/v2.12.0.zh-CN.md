# Capricorn V2.12.0

发布日期：2026-10-29。完整版本 `2.12.0`，Build `0048`。

Build 是独立、全局递增的四位发布构建序号，不再拼入版本号。

## 更新内容

- 新增共享硬盘连接拓扑，查看 USB、雷雳、PCIe 通路、链路速率与芯片信息；点击硬盘同步切换侧边栏及详情，点击机身选择系统盘。
- 支持拖动节点、触控板缩放和平移，以及 M 打开、- / = 缩放和 Z 重新整理。
- 增加 Mac 机型与端口视图，支持桌面机型前后接口选择；常见控制器和 SSD 主控名称由本地数据库提供，无需联网查询。

## 安装与兼容性

macOS 14.0+，支持 Apple silicon 与 Intel。下载 `Capricorn-v2.12.0-macOS.zip` 并安装固定名称的 `Capricorn.app`。V2.10.2 及以后可应用内更新；更早版本或旧开发 Build `1000` 需手动安装。

拓扑使用系统报告的信息，链路速率不代表实测吞吐量，未收录芯片保留原始标识。启动检查与开发者自动更新默认关闭，下载及安装继续检查任务冲突并保存历史。内置 smartctl 7.5，可选 SAT SMART Drive 按需配置。测速和负载使用所选文件夹中的临时文件，请确认目标并备份重要数据。

App 使用有效 ad-hoc 签名，更新包和清单使用既有 Ed25519 密钥；没有 Developer ID 或 Apple 公证。
