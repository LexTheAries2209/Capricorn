# Capricorn V2.10.0

Release date: 2026-10-15

## Highlights

- Developer Options supports simulated virtual disks with configurable identity, capacity, partitions, and overview metrics. Create one with Add Virtual Disk or `Command+T` and edit it from the context menu.
- Names include “(Virtual Disk)”; virtual disks exist only for the current session. Ejecting deletes them, and disabling the relevant developer switches ejects all simulated devices without retaining caches or history.
- Operating-system logical devices and installer volumes are no longer listed as separate disks; disk actions appear directly in the context menu.
- Add Virtual Disk, language, and refresh share one row; the sidebar version and user label opens update settings.

## Download, Compatibility, and Safety

- Download: [Capricorn-v2.10.0-macOS.zip](https://github.com/LexTheAries2209/Capricorn/releases/download/v2.10.0/Capricorn-v2.10.0-macOS.zip).
- App: `Capricorn V2.10.0.app`; Version `2.10`, Build `0`, display name `Capricorn V2.10.0`.
- macOS 14.0 or later; smartctl 7.5 is bundled, so smartmontools need not be installed separately. The optional SAT SMART driver is not installed automatically.
- Virtual disks simulate overview information only, without creating real disks, images, mount points, or allocating disk space, and without running real SMART, benchmarks, Live Activity, or First Aid.
- SMART information depends on the device and bridge; network volumes do not provide all local physical-disk activity data.
- Benchmarks and large-file workloads create temporary files; read workloads also write source files first. Sustained writes may cause storage stress and wear. Verify the target and keep important backups.
- The GitHub distribution is not Developer ID signed, notarized, or Gatekeeper-trust verified; manual approval may be required on first launch. Apple Development signing in the local run script does not establish public distribution trust.
