## 中文

Capricorn V2.0.1 使用 `Version = 2.0`、`Build = 1` 和 Display Name `Capricorn V2.0.1`。本版重构磁盘身份与 Native SMART 刷新流程，使多块同型号磁盘、USB 设备和临时读取失败下的显示与历史归属更加稳定。

### 主要更新

- 历史记录优先按完整硬件序列号匹配；没有序列号时，以卷 UUID 作为兜底。新数据库位于 Application Support 下的 `CapricornHistory` 目录，旧版历史不会导入。
- 通过 `system_profiler` XML 与 IOKit 补充序列号；侧边栏以最大容量卷名作为首行，并显示商品名/型号和序列号。设置中可开启仅影响 UI 与 SMART CSV 的序列号脱敏。
- 磁盘发现与 Native SMART 采集拆分。磁盘列表先显示，Native 数据随后以最多 2 路并发补充；超时或暂时缺失会按立即、1 秒、3 秒静默重试，明确不支持的设备不会重复探测。
- 瞬时 Native SMART 失败会保留同一稳定磁盘的上次有效数据，并显示“正在刷新”或“上次读取”；约 5 秒的 `diskutil info` 超时会终止并回收子进程，不会阻塞其他磁盘。
- 测速目标与侧边栏所选硬盘联动，支持自动分区、同盘分区和同盘文件夹，并在运行前再次验证目标归属。
- SMART CSV 在统一属性表中加入磁盘身份、设备类型、卷 UUID，以及外接盘的卷名和卷格式；历史页旧的 JSON/CSV/文本复制入口已移除，等待后续统一导出设计。
- 修复 SD/SDXC 的 ExFAT 格式与可用容量识别；温度只在概览中按 `70–85 °C` 黄色、`85 °C` 及以上红色提示，不改变 SMART 健康等级。
- 型号目录扩展到 177 条规则，覆盖 12 个品牌/品牌组的消费级、OEM、数据中心与企业 HDD/SSD，包括 U.2/U.3、NVMe、SATA 和 SAS 系列。

## English

Capricorn V2.0.1 uses `Version = 2.0`, `Build = 1`, and Display Name `Capricorn V2.0.1`. It rebuilds drive identity and Native SMART refresh handling so same-model disks, USB devices, and transient probe failures remain easier to distinguish and less likely to cross-match.

### Highlights

- History matches the full hardware serial first and falls back to volume UUIDs when no usable serial exists. The new `CapricornHistory` Application Support database does not import legacy history.
- Serial discovery combines `system_profiler` XML and IOKit. The sidebar leads with the largest volume name, followed by product/model and serial. Optional redaction affects only UI and SMART CSV output.
- Drive discovery and Native SMART collection are separate. Drives appear first, then Native data arrives with at most two concurrent probes. Transient failures retry immediately, after 1 second, and after 3 seconds; explicitly unsupported devices do not retry.
- Last-known-good Native values survive transient failures with refreshing or last-read status. A roughly 5-second `diskutil info` timeout terminates and reaps the child process without blocking other disks.
- Benchmark targets follow the sidebar drive and support automatic partition, same-drive partition, or same-drive folder selection with a second ownership check before execution.
- SMART CSV adds identity, device type, volume UUID, and external-drive volume metadata to the existing attribute table. Legacy JSON/CSV/text copy actions were removed from History pending a unified export redesign.
- SD/SDXC ExFAT and available-capacity detection are corrected. Temperature is highlighted only in Overview at `70–85 °C` yellow and `85 °C` or higher red, without changing SMART health.
- The drive-model catalog now has 177 rules spanning consumer, OEM, data-center, and enterprise HDD/SSD families across 12 brands or brand groups, including U.2/U.3, NVMe, SATA, and SAS products.
