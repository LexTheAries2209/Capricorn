# Capricorn V2.9.1 中文发布说明

发布日期：2026-09-23

双语发布说明：[v2.9.1.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.1/docs/releases/v2.9.1.md)

Capricorn V2.9.1 使用 `Version = 2.9`、`Build = 1` 和 Display Name `Capricorn V2.9.1`。

## 主要更新

- 测速和单项测试的运行确认改为类似 SMART 自检的紧凑活动窗口，按字段展示配置、目标文件夹和写入风险；不再使用系统提醒或大面积遮罩。
- 启动后在活动窗口显示进度、当前测试、状态与取消操作；隐藏窗口不停止测速，运行中可重新打开。
- 界面使用可用空间快照，减少活动窗口切换时的重复卷查询；运行前仍重新确认目标文件夹归属、可写性和剩余空间。

## 下载、兼容性与安全

- Release 包名：`Capricorn-v2.9.1-macOS.zip`；App 名称：`Capricorn V2.9.1.app`。
- macOS 14.0 或更新版本；内置 smartctl 7.5。
- 测速可能写入完整临时文件并造成存储磨损；开始前确认目标及备份。隐藏窗口不等于取消。
- 人工核对了完整/单项测试的确认窗口和取消返回；没有执行完整实盘测速，因此运行中的进度动画尚未实测。
