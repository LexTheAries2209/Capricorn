# Capricorn V2.9.6 中文发布说明

发布日期：2026-10-05

双语发布说明：[v2.9.6.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.6/docs/releases/v2.9.6.md)

Capricorn V2.9.6 使用 `Version = 2.9`、`Build = 6` 和 Display Name `Capricorn V2.9.6`。

## 主要更新

- 将“默认打开测速窗口”更名为“默认打开测速进度窗口”，使设置含义更明确。
- 新增“默认打开 SMART 自检进度窗口”选项。关闭后，SMART 自检仍会在后台运行，只有点击“查看进度”时才打开进度窗口。
- 两个选项默认保持开启，升级后不会改变既有使用习惯。

## 下载、兼容性与安全

- Release 包名：`Capricorn-v2.9.6-macOS.zip`；App 名称：`Capricorn V2.9.6.app`。
- 需要 macOS 14.0 或更新版本；内置 smartctl 7.5。
- SMART 信息取决于磁盘、存储卡、USB 桥接器和网络卷实际提供的数据。
- 测速会在目标文件夹创建临时测试文件，请确认目标位置并保留重要数据备份。
- 此分发包未执行 Developer ID 签名、公证或 Gatekeeper 信任验证，首次运行可能需要手动允许。
