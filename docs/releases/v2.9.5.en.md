# Capricorn V2.9.5 English Release Notes

Release date: 2026-10-04

Bilingual release notes: [v2.9.5.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.5/docs/releases/v2.9.5.md)

Capricorn V2.9.5 uses `Version = 2.9`, `Build = 5`, and display name `Capricorn V2.9.5`.

## Highlights

- Shows external-drive connection type and link speed in the disk list and overview.
- Supports recognition for more CFast media and external SSD models.
- Improves the presentation of cumulative SMART read and write data for CFast media.
- Improves the presentation of drive media types and SMART information.

## Download, Compatibility, and Safety

- Package: `Capricorn-v2.9.5-macOS.zip`; App: `Capricorn V2.9.5.app`.
- macOS 14.0 or later; smartctl 7.5 is bundled.
- SMART information depends on the data provided by the drive, memory card, USB bridge, or network volume.
- Benchmarks create temporary test files in the selected target folder; verify the target and keep important backups.
- This distribution is not Developer ID signed, notarized, or Gatekeeper-trust verified; manual approval may be required on first launch.
