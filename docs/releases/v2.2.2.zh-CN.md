# Capricorn V2.2.2 发布说明

发布日期：2026-08-25

## 主要更新

- 重新设计卷宗过滤：通过 `diskutil` 的 APFS Physical Store 关系、分区内容和卷宗可操作性识别容器承载分区，不再依赖 `disk11s2` 这类 BSD 名称。
- 小于或等于 1 GB 的容量只在磁盘拓扑信息不完整时作为辅助判断；正常挂载、带 UUID 的小容量文件系统仍会显示、可切换并可测速。
- APFS 容器承载分区、EFI 和其他结构分区不会进入概览、侧边栏代表卷、切换卷宗、测速、实时活动负载、检查修复或 SMART CSV 卷信息。
- 容量与文件系统汇总只统计用户可见卷，避免结构分区重复计入磁盘容量或格式列表。

## 下载与兼容性

- Release 包名：`Capricorn-v2.2.2-macOS.zip`
- App 名称：`Capricorn V2.2.2.app`
- 系统要求：macOS 14.0 或更新版本
- 可选依赖：用户自行安装的 smartmontools (`smartctl`) 与 SAT SMART Driver
- 本版使用本机 Apple Development 开发签名，但未使用 Developer ID 签名且未公证；首次打开可能需要在 Finder 中右键选择“打开”，或到“系统设置 > 隐私与安全性”中允许。

## 安全说明

- Capricorn 只在选定文件夹内创建测速或负载临时文件，不会直接写入裸设备。
- 写入、混合、循环和大文件负载会对介质产生压力，请确认目标卷位于预期磁盘。
- 被识别为存储拓扑或元数据用途的分区不会成为文件操作目标。
