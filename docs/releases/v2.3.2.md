## 中文

Capricorn V2.3.2 使用 `Version = 2.3`、`Build = 2` 和 Display Name `Capricorn V2.3.2`。

### 主要更新

- 新增 ARRI Codex Compact Drive、Compact Drive Express 和 SXR Capture Drive 型号识别。
- 修正摄影机/录制介质 UDF 卷宗从 `diskutil list` 缺失时的设备信息回填，恢复真实卷名、容量、只读状态、卷 UUID 和格式。
- 侧边栏与卷宗相关操作使用真实挂载卷名，不再用硬盘型号代替卷名。

### 下载与兼容性

- `Capricorn-v2.3.2-macOS.zip` / `Capricorn V2.3.2.app`
- macOS 14.0 或更新版本；可选 smartmontools 与 SAT SMART Driver。
- 跳过 Developer ID 签名和公证，首次打开可能需要手动允许。

### 验证

- 完整 macOS 测试：237 项通过，0 失败。

## English

Capricorn V2.3.2 uses `Version = 2.3`, `Build = 2`, and Display Name `Capricorn V2.3.2`.

### Highlights

- Added ARRI Codex Compact Drive family recognition.
- Recovered mounted UDF volume metadata omitted by `diskutil list`, including the actual volume name, capacity, read-only state, volume UUID, and filesystem type.
- Sidebar and volume-aware operations now use the mounted volume name instead of the drive model.

### Download And Compatibility

- `Capricorn-v2.3.2-macOS.zip` / `Capricorn V2.3.2.app`
- macOS 14.0 or later; optional smartmontools and SAT SMART Driver.
- Developer ID signing and notarization are skipped; macOS may require manual approval on first launch.

### Verification

- Full macOS test suite: 237 tests passed, 0 failures.
- Release build verified a universal `arm64`/`x86_64` Mach-O App with `Version 2.3`, `Build 2`, and `Capricorn V2.3.2`.
