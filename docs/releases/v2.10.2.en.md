# Capricorn V2.10.2

Release date: October 17, 2026.

## Version And Installation

- Complete Version `2.10.2`, Build `0042`. Build is an independent, globally increasing four-digit release-build sequence and is no longer appended to the version. The migration baseline is 41 previously verified stable Releases.
- Download `Capricorn-v2.10.2-macOS.zip` and install the fixed-name `Capricorn.app` in a local Applications directory.
- Public V2.10.1 and earlier do not contain Sparkle and require one manual installation. Local development builds already numbered `0042` are not considered older merely because the marketing version changes; old development Build `1000` also requires manual replacement.
- Requires macOS 14.0 or later; includes arm64 and x86_64.

## Highlights

- Adds manual in-app updates, automatic checks on launch, and optional automatic downloads with installation on quit; update choices persist.
- Conflicting benchmarks, live monitoring, disk checks, self-tests, and other disk tasks block updates with a warning; history is saved before installation.
- Makes update settings more compact with the last-check time beside the button and shorter error messages; build visibility is optional under Developer Options and off by default.

## Updates And Safety

The appcast and update archive use Ed25519 signature verification, and downloads follow macOS system proxy settings. The App is ad-hoc signed without Developer ID or Apple notarization; macOS may require manual approval on first launch.

Checks on launch are off by default. When enabled, one check runs after the initial disk refresh in each new app process. Automatic downloads are a separate opt-in, also off by default. Manual checks remain available and respect task conflicts.

SwiftData history stays in the application data directory and is not cleared by replacing the App. Benchmarks write only in the selected folder; write, mixed, and large-file workloads still require appropriate device and data precautions. smartctl 7.5 is bundled.
