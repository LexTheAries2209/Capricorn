# Capricorn V2.5.0 Release Notes

Release date: 2026-09-08

Capricorn V2.5.0 uses `Version = 2.5`, `Build = 0`, and the display name `Capricorn V2.5.0`.

## Highlights

- Adds the SMART diagnostics surface with device self-test status, quick/full tests, history, error-entry reads, exports, and capability- and permission-aware controls.
- Keeps SMART temperature and error-log entries as independent signals: `70–85 °C` remains a warning and `85 °C` or above remains an error, while neither signal changes the overall SMART health level.
- When macOS smartctl cannot send the NVMe self-test command `0x14`, the UI shows a muted “self-test cannot be completed” state with localized messaging instead of presenting an unknown self-test result.
- Adds a Quick Disk Check entry to Overview with the same action as the drive context menu; quick-check reports persist by drive identity, system-disk checks require a Settings opt-in, and Settings can be dismissed with Escape.
- Fixes the SMART diagnostics build and adds coverage for error-log behavior, temperature thresholds, system-disk permissions, and self-test history.

## Download And Compatibility

- Release package: `Capricorn-v2.5.0-macOS.zip`
- App name: `Capricorn V2.5.0.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.

## Data And Safety Notes

- Quick Disk Check and SMART hardware self-tests are separate features; system-disk self-tests remain protected by a dedicated Settings switch.
- When macOS smartctl cannot send NVMe self-test command `0x14`, Capricorn does not fabricate a self-test result.
- Capricorn does not install or remove kernel extensions and does not search or select external smartctl binaries from PATH or Homebrew.
- Benchmark, write, repair, and self-test operations continue to use target confirmation, system-disk protection, and device-capability checks.
