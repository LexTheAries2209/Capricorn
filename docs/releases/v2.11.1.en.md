# Capricorn V2.11.1

Release date: October 19, 2026.

## Version And Installation

- Complete Version `2.11.1`, Build `0047`. Build is an independent, globally increasing four-digit release-build sequence and is not appended to the version.
- Download `Capricorn-v2.11.1-macOS.zip` and install the fixed-name `Capricorn.app`.
- V2.10.2 and later support in-app upgrades; earlier versions and old development Build `1000` require manual installation.
- Requires macOS 14.0 or later; includes arm64 and x86_64.

## Highlights

- Allows update checks alongside disk refreshes, benchmarks, and other tasks without an “Update blocked” warning.
- Quietly retains the available version when developer automatic updates find a release while busy, without starting a download. Retry manually after tasks finish or check on the next launch.

## Updates And Safety

Launch checks and developer automatic updates default to off. Manual downloads still check all task conflicts; new conflicts cancel active downloads with a warning. Installation, resumed installation, and update relaunch recheck conflicts and save history; save failures block installation. Ordinary quit does not install an unconfirmed update, and blocked updates do not resume themselves when tasks finish.

The feed and archive use the existing Ed25519 key. The App uses ad-hoc signatures without Developer ID or Apple notarization; first launch may require manual approval. smartctl 7.5 is bundled. SAT SMART Drive is optional and configured manually for applicable devices.

Benchmarks and workloads create temporary files in the selected folder and do not write directly to raw devices. Reads may first create a source file; sustained writes cause storage stress and wear. Verify targets and back up important data.
