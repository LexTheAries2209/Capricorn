# Capricorn V2.7.2 English Release Notes

Release date: 2026-09-17

Bilingual release notes: [v2.7.2.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.2/docs/releases/v2.7.2.md)

Capricorn V2.7.2 uses `Version = 2.7`, `Build = 2`, and the display name `Capricorn V2.7.2`.

## Highlights

- Settings now includes Interface Display and Keyboard Shortcuts sections. The shortcut reference sits below SMART and above History Database and lists Settings, refresh, SMART snapshot export, and page navigation commands.
- Automatic drive refresh, sleeping-drive protection, and SMART diagnostics options are consolidated under Disk Actions. History Database now appears at the bottom of Settings.
- Feature pages now always advance in order with `Tab`. The former setting and the Control-Tab and Control-Shift-Tab combinations have been removed, leaving Tab as the only page-switching shortcut.
- The app now bundles only `SATSMARTDriver-0.10.3.pkg` for SAT SMART Drive instead of duplicating the installer in a ZIP resource.

## Download And Compatibility

- Release package: `Capricorn-v2.7.2-macOS.zip`
- App name: `Capricorn V2.7.2.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled.
- SAT SMART Driver is optional for compatible USB-SATA devices and is never installed or loaded automatically.
