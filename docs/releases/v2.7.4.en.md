# Capricorn V2.7.4 English Release Notes

Release date: 2026-09-19

Bilingual release notes: [v2.7.4.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.4/docs/releases/v2.7.4.md)

Capricorn V2.7.4 uses `Version = 2.7`, `Build = 4`, and the display name `Capricorn V2.7.4`.

## Highlights

- Benchmark adds Read Only, Write Only, and Read & Write selection, filtering the next run and updating configuration details and write confirmation.
- Benchmark actions, configuration controls, and result-row spacing are reorganized for clearer regular and narrow-window layouts.
- Each benchmark run stores one activity sample set. History places that chart above all results saved by the run.
- Legacy records that repeated one chart across several results are grouped automatically without a history-database migration.
- Saved Live Activity records display their line chart with time, sample count, interval, and read/write peak summaries.
- The three History panels remain side by side down to about 1200 pt, and the SMART snapshot empty-state copy is shorter.

## Download, Compatibility, And Safety

- Release package: `Capricorn-v2.7.4-macOS.zip`
- App name: `Capricorn V2.7.4.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled.
- SAT SMART Driver is optional for compatible USB-SATA devices and is never installed or loaded automatically.
- Capricorn creates temporary files only in the selected benchmark folder and never writes directly to raw devices. Read Only may still create a preparation file and is not a zero-write mode.
- Write, mixed, looped benchmark, and Live Activity large-file workloads create storage writes and wear. Confirm the target and available capacity first.
