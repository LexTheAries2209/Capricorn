# Capricorn V2.1.1 发布说明

发布日期：2026-08-24

## 主要更新

- 监听磁盘装载、卸载和设备终止事件，经过约 0.75 秒防抖后刷新磁盘列表；新盘接入或盘被移除时无需手动刷新。
- 设置新增自动磁盘刷新：默认关闭，可选 1、3、5、10、15 或 30 分钟。事件刷新和定时刷新都不会让一块缓慢的外接盘阻塞其他磁盘更新。
- SMART 快照保存支持 `Command-S`，保存按钮的悬浮提示会显示快捷键。
- 设置新增“打开历史数据库位置”，可在 Finder 中直接定位 `CapricornHistory` 数据目录。
- 磁盘右键菜单新增受设置控制的“检查与修复”入口，默认关闭。启用后将快速检查、深度检查和急救归入同一子菜单，避免在常用操作菜单中暴露修复类命令。
- SMART 自检状态、记录和控制也改为独立设置开关，默认隐藏。启用后才能在概览和 SMART 页面查看或运行自检；已有自检记录与会话不会被删除。

## 下载与兼容性

- Release 包名：`Capricorn-v2.1.1-macOS.zip`
- App 名称：`Capricorn V2.1.1.app`
- 系统要求：macOS 14.0 或更新版本
- 架构：arm64 + x86_64 通用二进制
- 可选依赖：用户自行安装的 smartmontools (`smartctl`) 与 SAT SMART Driver
- 本版按要求跳过签名和公证；首次打开时可能需要在 Finder 中右键选择“打开”，或到“系统设置 > 隐私与安全性”中允许。
