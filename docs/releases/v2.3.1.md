## 中文

Capricorn V2.3.1 使用 `Version = 2.3`、`Build = 1` 和 Display Name `Capricorn V2.3.1`。本版加强本地历史数据管理，并让系统盘测速与实时监控的目标和操作状态更清晰可控。

### 主要更新

- 设置的“历史数据库”区域现在显示数据库目录、占用空间和记录总数；可在 Finder 打开位置，并在二次确认后清理全部本地历史数据。
- “历史与报告”显示当前硬盘未隐藏和已隐藏记录数量。可清理当前硬盘的全部历史，或仅清理已隐藏数据；两项操作均需确认，且不会影响其他硬盘的记录。
- 系统盘测速的自动目标优先选择桌面目录，避免默认写入系统根目录。
- 实时活动监控或大文件负载运行时，侧边栏其他硬盘行会变灰且不可点击，键盘选择也会被阻止；停止后自动恢复切换。
- 设置中的 Tab 切换说明已移动到对应开关下方，避免与 smartctl 设置混排。

### 下载与兼容性

- Release 包名：`Capricorn-v2.3.1-macOS.zip`
- App 名称：`Capricorn V2.3.1.app`
- 系统要求：macOS 14.0 或更新版本
- 可选依赖：用户自行安装的 smartmontools (`smartctl`) 与 SAT SMART Driver
- 该包不使用 Developer ID 签名，也未公证；首次打开可能需要 Finder > 打开或在“系统设置 > 隐私与安全性”中允许。

### 数据提示

- 清理数据库、清理当前硬盘历史和清理已隐藏数据都会永久删除对应本地记录，确认前请先核实数量。
- 测速仅在所选目标目录创建临时文件；写入、混合和循环模式会对存储产生压力。

### 验证

- 完整 macOS 测试：235 项通过，0 失败。
- Release 构建通过；App 元数据为 `Version 2.3`、`Build 1`、`Capricorn V2.3.1`。
- App 二进制包含 `arm64` 与 `x86_64` 两种架构。
- 发布包采用 adhoc 签名，未使用 Developer ID 签名且未公证。

## English

Capricorn V2.3.1 uses `Version = 2.3`, `Build = 1`, and the display name `Capricorn V2.3.1`. This release improves local history management and clarifies system-disk benchmark targets and active monitoring state.

### Highlights

- The History Database area in Settings now shows the database location, disk usage, and record count. It can reveal the folder in Finder and clear all local history after confirmation.
- History and Reports now shows visible and hidden record counts for the selected drive. You can clear all history for that drive or only its hidden data, with confirmation and without affecting other drives.
- The automatic benchmark target for the system disk now prefers the Desktop directory instead of the system root.
- While Live Activity monitoring or a large-file workload is running, other sidebar drive rows are dimmed and disabled. Keyboard selection is blocked as well, and normal switching returns after the task stops.
- The Tab navigation note now appears directly beneath its setting instead of being mixed into the smartctl area.

### Download And Compatibility

- Release package: `Capricorn-v2.3.1-macOS.zip`
- App name: `Capricorn V2.3.1.app`
- System requirement: macOS 14.0 or later
- Optional dependencies: user-installed smartmontools (`smartctl`) and SAT SMART Driver
- This package is not Developer ID signed or notarized. On first launch, macOS may require Finder > Open or approval in System Settings > Privacy & Security.

### Data Notes

- Clearing the database, selected-drive history, or hidden data permanently removes the corresponding local records. Verify the displayed counts before confirming.
- Benchmarks create temporary files only in the selected target directory. Write, mixed, and loop modes can stress storage.

### Verification

- Full macOS test suite: 235 tests passed, 0 failures.
- Release build passed; App metadata is `Version 2.3`, `Build 1`, and `Capricorn V2.3.1`.
- The App binary contains both `arm64` and `x86_64` architectures.
- The package uses an adhoc signature and is not Developer ID signed or notarized.
