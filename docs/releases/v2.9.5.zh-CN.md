# Capricorn V2.9.5 中文发布说明

发布日期：2026-10-04

双语发布说明：[v2.9.5.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.5/docs/releases/v2.9.5.md)

Capricorn V2.9.5 使用 `Version = 2.9`、`Build = 5` 和 Display Name `Capricorn V2.9.5`。

## 主要更新

- 在磁盘列表和概览中显示外接磁盘的连接类型和连接速度。
- 支持更多 CFast 媒体和外接 SSD 型号识别。
- 改进 CFast 媒体的 SMART 累计读写数据展示。
- 改进磁盘介质类型和 SMART 信息的显示。

## 下载、兼容性与安全

- Release 包名：`Capricorn-v2.9.5-macOS.zip`；App 名称：`Capricorn V2.9.5.app`。
- 需要 macOS 14.0 或更新版本；内置 smartctl 7.5。
- SMART 信息取决于磁盘、存储卡、USB 桥接器和网络卷实际提供的数据。
- 测速会在目标文件夹创建临时测试文件，请确认目标位置并保留重要数据备份。
- 此分发包未执行 Developer ID 签名、公证或 Gatekeeper 信任验证，首次运行可能需要手动允许。
