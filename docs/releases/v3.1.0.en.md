# Capricorn V3.1.0

Release date: November 1, 2026. Complete Version `3.1.0`, Build `0050`.
Build is an independent, globally increasing four-digit release-build sequence and is not appended to the version.

## Changes

- Adds one system-approved privileged device service for SMART reads, supported self-tests, and manual SNT, reducing repeated authentication.
- Supports service activation from permanent local folders, with safe service shutdown and restoration attempts during in-app updates.
- Moves settings explanations to hover tips and adds more SSD model names to topology.

## Installation And Safety

Download `Capricorn-v3.1.0-macOS.zip` and install the stable-name `Capricorn.app`. Requires macOS 14.0 or later. V2.10.2 and later support in-app upgrades; earlier versions and old development Build `1000` require manual installation.

Enable the privileged device service in Settings and complete system approval. `/Applications` is recommended; other permanent folders on local, writable, non-removable disks are supported. Temporary, translocated, read-only, removable and network locations cannot enable the service. Disable it before moving or manually replacing the app. In-app updates attempt to restore a previously enabled service; macOS may require renewed approval.

Each SNT operation still requires confirmation before unmounting all volumes on the USB device and attempting restoration afterward. Close files, finish other disk tasks, and back up important data first. Failed restoration may require reconnecting the device or using Disk Utility. Removable-volume privacy consent remains separate, and background scans never initiate USB capture.

Real service requests and read-only external NVMe SMART/log queries have passed on this Mac. USB-SNT privacy attribution, capture and mount restoration, and hardware self-test start/abort still require corresponding hardware acceptance tests. Experimental JMicron, ASMedia and Realtek bridge protocols do not guarantee compatibility with every device or firmware and do not provide general SD-card health queries.

smartctl 7.5 is bundled; SAT SMART Drive is optional. Benchmarks and workloads use temporary files in the selected folder, and write tests can stress storage.

The app and service use Apple Development certificate signatures; the archive and feed use the existing Ed25519 key. Developer ID and Apple notarization are not established. First launch and service approval on other Macs are not guaranteed.

## Verification And Source

Full suite: 688 tests, 679 passed, 9 skipped, 0 failed. Strict concurrency, Swift 6, universal archive, archived app launch, both architectures and matching dSYM UUIDs, and complete bundle/tool certificate signatures passed. Twenty real Sparkle fixture scenarios passed, including manual/automatic installation, service handoff, conflicts, cancellation and signature rejection. Skips cover Screen Recording-dependent checks and the opt-in hardware test. See the [combined release notes](https://github.com/LexTheAries2209/Capricorn/blob/v3.1.0/docs/releases/v3.1.0.md) for complete evidence.

Installation regressions use isolated fixture apps, history and preferences. The service-handoff installation scenario uses a mock coordinator, not a real root-service upgrade. Intel, macOS 14, and certificate trust and service approval on other Macs require separate validation.
