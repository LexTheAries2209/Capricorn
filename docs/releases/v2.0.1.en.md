# Capricorn V2.0.1 Release Notes

Release date: 2026-08-24

Capricorn V2.0.1 uses `Version = 2.0`, `Build = 1`, and Display Name `Capricorn V2.0.1`. This release rebuilds drive identity, history matching, and Native SMART refresh handling, and makes benchmark targets follow the drive selected in the sidebar just like Live Activity.

## Highlights

- History matches by full hardware serial first and falls back to volume UUIDs when no serial is available. The new store at `~/Library/Application Support/CapricornHistory/CapricornHistory.store` does not import legacy history.
- Serial discovery combines `system_profiler` XML and IOKit for internal, PCIe, and USB disks. The sidebar leads with the largest volume name, followed by drive product/model and serial.
- A new Redact Serial Numbers setting is off by default. When enabled, UI and SMART CSV retain only the first four characters and replace the rest with `*`; internal identity matching always uses the complete serial.
- Drive discovery publishes the list before Native SMART collection. At most two probes run concurrently, with system disks and SSDs prioritized, so one slow external drive cannot block another disk.
- Native SMART retries transient timeouts, missing fields, and Disk Arbitration readiness immediately, after 1 second, and after 3 seconds. Explicit Not Supported responses do not retry.
- A roughly 5-second `diskutil info` timeout terminates and reaps the child process. Transient failures preserve the last valid Native values for the same stable identity and label them as refreshing or last read.
- Benchmark targets follow the sidebar drive, automatically using its first naturally sorted mounted writable partition while supporting same-drive partition and folder overrides. AppModel and the benchmark service both validate ownership before execution.
- SMART CSV keeps the existing attribute-table shape while adding drive name, serial, device type, volume UUID, device node, protocol, capture time, and external-drive volume names/formats. Legacy History export controls are temporarily removed.
- SD/SDXC ExFAT and available-capacity detection are corrected. Overview temperatures are yellow from `70–85 °C` and red at `85 °C` or above, but temperature no longer changes overall SMART health.
- The model catalog now contains 177 rules for consumer, OEM, data-center, and enterprise families from Samsung, Intel, Solidigm, SK hynix, Micron, Crucial, KIOXIA, Toshiba, WD, Seagate, YMTC, and ZHITAI.
