# Capricorn V1.2.10 发布说明

Capricorn V1.2.10 使用 `Version = 1.2`、`Build = 10`，Display Name 为 `Capricorn V1.2.10`。本版汇总 V1.2.5 之后的 SMART 展示、容量统计、外接硬盘型号识别和实时活动磁盘联动改进。

## 下载

- Release 包名：`Capricorn-v1.2.10-macOS.zip`
- App 名称：`Capricorn V1.2.10.app`
- 系统要求：macOS 14.0 或更新版本

## V1.2.5 以来的更新

- SMART 页面采用稳定的纵向滚动布局，最近自检记录支持折叠，状态消息可独立清除而不改变自检会话。
- 常见外接 ATA SMART 字段提供更明确的中文名称；`Total LBAs Read/Written` 会按逻辑块大小换算为容量，并保留原始 LBA 信息。
- 侧边栏和概览显示磁盘总容量、已用和可用空间；APFS 共享容器去重后汇总，避免重复计算。
- 新增外接机械硬盘型号目录，为一组已验证的型号显示规范型号、产品系列和容量；未知设备继续保留系统原始名称。
- 已识别硬盘在侧边栏和页面标题使用更清晰且不易错误换行的名称，鼠标提示保留原始型号。
- 实时活动监控完全跟随左侧侧边栏磁盘，页面不再提供重复磁盘选择器。监控或负载期间锁定其他磁盘，活动磁盘消失时停止任务并提示错误。
- 实时活动样本、继续状态、历史操作和错误按磁盘隔离，停止后切换磁盘不会串联数据。
- 大文件负载自动使用当前磁盘第一个已挂载可写分区，也可选择同盘分区或文件夹；只读、未挂载、失效和跨盘目标会被拒绝或安全回退。
- 负载目标按磁盘分别持久化；旧全局文件夹只有在确认属于当前磁盘且可写时才会迁移。

## 安全与限制

- 写入、混合、循环和大文件负载会增加磁盘压力和写入磨损，请确认目标分区、剩余空间和供电稳定。
- 跨盘文件夹不会保存；启动前 AppModel 和负载服务会再次验证目标归属。
- 型号目录只增强已验证型号的显示名称，不代表健康、接口能力或保修结论。
- Capricorn 不捆绑 smartctl，也不会自动安装或卸载 SAT 内核扩展。
