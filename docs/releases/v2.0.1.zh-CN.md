# Capricorn V2.0.1 发布说明

发布日期：2026-08-24

Capricorn V2.0.1 使用 `Version = 2.0`、`Build = 1`，Display Name 为 `Capricorn V2.0.1`。本版重构磁盘身份、历史匹配与 Native SMART 刷新流程，并让测速目标像实时活动一样跟随侧边栏所选硬盘。

## 主要更新

- 历史记录优先按完整硬件序列号匹配；没有序列号时使用卷 UUID 兜底。新数据库位于 `~/Library/Application Support/CapricornHistory/CapricornHistory.store`，不导入旧版历史。
- 使用 `system_profiler` XML 与 IOKit 补充内置、PCIe 和 USB 磁盘序列号。侧边栏以最大容量卷名作为首行，下一行显示硬盘商品名/型号，随后显示序列号。
- 新增“脱敏序列号”设置，默认关闭。开启后 UI 与 SMART CSV 只保留前四位，其余替换为 `*`；历史匹配等内部逻辑始终使用完整序列号。
- 先发现并显示磁盘，再异步读取 Native SMART。并发上限为 2，优先处理系统盘和 SSD；单个外接盘超时不会阻塞其他磁盘的数据发布。
- Native SMART 对超时、字段暂时缺失和 Disk Arbitration 未就绪执行立即、1 秒、3 秒静默重试；明确返回 Not Supported 时不重试。
- 约 5 秒的 `diskutil info` 超时会终止并回收子进程。瞬时失败会保留同一稳定身份磁盘的上次有效 Native 数据并标记为正在刷新或上次读取。
- 测速目标跟随侧边栏所选磁盘，默认使用自然排序后的第一个已挂载可写分区，并支持同盘分区或文件夹选择；启动前继续执行 AppModel 与服务层双重归属校验。
- SMART CSV 在原有横向属性表中加入磁盘名称、序列号、设备类型、卷 UUID、设备节点、协议、采集时间，以及外接盘的卷名和卷格式。历史页旧导出入口暂时移除。
- 修复 SD/SDXC 卡 ExFAT 格式与可用容量识别。概览温度 `70–85 °C` 标黄、`85 °C` 及以上标红，但温度不再参与整体 SMART 健康等级。
- 硬盘型号目录扩展到 177 条规则，覆盖 Samsung、Intel、Solidigm、SK hynix、Micron、Crucial、KIOXIA、Toshiba、WD、Seagate、YMTC 和致钛的消费级、OEM、数据中心及企业系列。

## 下载与兼容性

- Release 包名：`Capricorn-v2.0.1-macOS.zip`
- App 名称：`Capricorn V2.0.1.app`
- 最低系统：macOS 14.0
- 架构：arm64 + x86_64 通用二进制
- 可选依赖：smartmontools (`smartctl`) 与 SAT SMART Driver，均需用户自行安装
