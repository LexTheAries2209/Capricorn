## 中文

- 更新检查可与硬盘刷新、测速等任务同时进行，不再因这些任务弹出“更新已阻止”。
- 开发者自动更新发现新版时若任务忙碌，会静默保留新版提示，不开始下载；任务完成后可手动重试或在下次启动时检查。

下载 `Capricorn-v2.11.1-macOS.zip` 并安装 `Capricorn.app`。V2.10.2 及以后支持应用内更新；更早版本或旧开发 Build `1000` 需手动安装。

启动检查和开发者自动更新默认关闭。手动下载及安装仍检查任务冲突；下载中出现冲突会取消下载并提示，安装前保存历史。普通退出不安装尚未确认的更新。更新清单和安装包使用既有 Ed25519 密钥；App 使用 ad-hoc 签名，没有 Developer ID 或 Apple 公证。内置 smartctl 7.5，可选 SAT SMART Drive 按需配置。测速及负载使用选定文件夹中的临时文件，请确认目标并备份重要数据。

## English

- Allows update checks alongside disk refreshes, benchmarks, and other tasks without an “Update blocked” warning.
- Quietly retains the available version when developer automatic updates find a release while busy, without starting a download. Retry manually after tasks finish or check on the next launch.

Download `Capricorn-v2.11.1-macOS.zip` and install `Capricorn.app`. V2.10.2 and later support in-app upgrades; earlier versions or old development Build `1000` require manual installation.

Launch checks and developer automatic updates default to off. Manual downloads and installation still check for task conflicts; new conflicts cancel active downloads with a warning, and history is saved before installation. Ordinary quit does not install an unconfirmed update. The feed and archive use the existing Ed25519 key. The App uses ad-hoc signatures without Developer ID or Apple notarization. smartctl 7.5 is bundled; SAT SMART Drive is optional. Benchmarks and workloads use temporary files in the selected folder. Verify targets and back up important data.
