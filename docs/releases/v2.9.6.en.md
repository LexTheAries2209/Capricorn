# Capricorn V2.9.6 English Release Notes

Release date: 2026-10-05

Bilingual release notes: [v2.9.6.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.6/docs/releases/v2.9.6.md)

Capricorn V2.9.6 uses `Version = 2.9`, `Build = 6`, and display name `Capricorn V2.9.6`.

## Highlights

- Renames “Open benchmark progress window by default” to make the setting's purpose explicit.
- Adds “Open SMART self-test progress window by default”. When disabled, the self-test continues in the background and the monitor opens only when View Progress is selected.
- Keeps both options enabled by default so upgrades preserve existing behavior.

## Download, Compatibility, and Safety

- Package: `Capricorn-v2.9.6-macOS.zip`; App: `Capricorn V2.9.6.app`.
- macOS 14.0 or later; smartctl 7.5 is bundled.
- SMART information depends on the data provided by the drive, memory card, USB bridge, or network volume.
- Benchmarks create temporary test files in the selected target folder; verify the target and keep important backups.
- This distribution is not Developer ID signed, notarized, or Gatekeeper-trust verified; manual approval may be required on first launch.
