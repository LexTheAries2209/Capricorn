## 中文

Capricorn V2.1.1 使用 `Version = 2.1`、`Build = 1` 和 Display Name `Capricorn V2.1.1`。本版把磁盘刷新改为可感知设备生命周期的后台流程，并把可能产生磁盘负载或文件系统修改的入口改为明确的设置项。

### 主要更新

- 监听磁盘装载、卸载和设备终止事件，经过约 0.75 秒防抖后刷新磁盘列表；新盘接入或盘被移除时无需手动刷新。
- 设置新增自动磁盘刷新：默认关闭，可选 1、3、5、10、15 或 30 分钟。事件刷新和定时刷新都不会让一块缓慢的外接盘阻塞其他磁盘更新。
- SMART 快照保存支持 `Command-S`，保存按钮的悬浮提示会显示快捷键。
- 设置新增“打开历史数据库位置”，可在 Finder 中直接定位 `CapricornHistory` 数据目录。
- 磁盘右键菜单新增受设置控制的“检查与修复”入口，默认关闭。启用后将快速检查、深度检查和急救归入同一子菜单，避免在常用操作菜单中暴露修复类命令。
- SMART 自检状态、记录和控制也改为独立设置开关，默认隐藏。启用后才能在概览和 SMART 页面查看或运行自检；已有自检记录与会话不会被删除。

## English

Capricorn V2.1.1 uses `Version = 2.1`, `Build = 1`, and Display Name `Capricorn V2.1.1`. This release makes disk refresh lifecycle-aware in the background and moves actions that can load a disk or modify filesystem metadata behind explicit Settings choices.

### Highlights

- Listens for disk mount, unmount, and device-termination events, then refreshes the drive list after roughly 0.75 seconds of debounce. Newly attached and removed drives no longer need a manual refresh.
- Settings adds automatic disk refresh. It is off by default and can run every 1, 3, 5, 10, 15, or 30 minutes. Event and timed refreshes prevent one slow external disk from blocking other drive updates.
- SMART snapshot saving supports `Command-S`, with the same shortcut exposed in the save-button help text.
- Settings can open the `CapricornHistory` data directory directly in Finder.
- Disk context actions now place Quick Check, Deep Check, and First Aid under a Settings-controlled Check and Repair submenu. It is off by default so repair-oriented commands are not exposed in routine menus.
- SMART self-test status, records, and controls also have an independent Settings switch and are hidden by default. Enabling it reveals the controls in Overview and SMART without deleting existing self-test records or sessions.

### Download And Compatibility

- App name: `Capricorn V2.1.1.app`

- Universal arm64 + x86_64 binary
- Optional user-installed smartmontools (`smartctl`) and SAT SMART Driver
- Signing and notarization were intentionally skipped as requested. First launch may require Finder > Open or approval in System Settings > Privacy & Security.
