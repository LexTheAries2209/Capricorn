# Capricorn V2.10.0

发布日期：2026-10-15

## 主要更新

- 开发者选项支持创建模拟虚拟硬盘，可配置硬盘信息、容量、分区和概览指标，通过“添加虚拟硬盘”或 `Command+T` 新建，并在右键菜单中修改配置。
- 虚拟硬盘名称带有“（虚拟硬盘）”标记，仅在当前会话存在；推出即删除，关闭相关开发者开关会推出全部模拟设备，不保留缓存或历史。
- 系统逻辑设备和安装包卷不再单独显示为硬盘；硬盘操作直接显示在右键菜单中。
- 添加虚拟硬盘、语言和刷新控件合并为一行；侧栏版本和用户名可直接打开更新设置。

## 下载、兼容性与安全

- 下载：[Capricorn-v2.10.0-macOS.zip](https://github.com/LexTheAries2209/Capricorn/releases/download/v2.10.0/Capricorn-v2.10.0-macOS.zip)。
- App：`Capricorn V2.10.0.app`；Version `2.10`、Build `0`、显示名 `Capricorn V2.10.0`。
- 需要 macOS 14.0 或更新版本；内置 smartctl 7.5，无需另行安装 smartmontools。可选 SAT SMART 驱动不会自动安装。
- 虚拟硬盘只模拟概览信息，不创建真实磁盘、镜像或挂载点，不预分配磁盘空间，也不执行真实 SMART、测速、实时活动或磁盘急救。
- SMART 信息取决于设备和桥接器；网络卷不提供全部本地物理磁盘活动数据。
- 测速和大文件负载会创建临时文件；读取负载也需先写入源文件，持续写入可能造成压力与磨损。请确认目标位置并保留重要数据备份。
- GitHub 分发包未执行 Developer ID 签名、公证或 Gatekeeper 信任验证，首次运行可能需要手动允许。本地脚本的 Apple Development 签名不适用于公开分发信任。
