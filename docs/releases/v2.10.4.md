## English

- Requires user confirmation for update downloads, installation, and relaunch; removes automatic downloads and installation on quit, and directs users to Check for Updates when a new version is available.
- Groups Sparkle, smartctl, and SAT SMART Drive versions and project links under Third-Party Components in Settings. Removes the separate license reader while retaining complete notices in the source tree.
- Places the SAT version beside its title, shortens the section, and renames the virtual-disk option to “Allow adding virtual disks”.

Download `Capricorn-v2.10.4-macOS.zip` and install `Capricorn.app`. V2.10.2 / V2.10.3 support in-app updates; V2.10.1 and earlier, and old development Build `1000`, require manual installation.

Checks on launch preserve the saved choice, default to off, and end after 15 seconds without a result. Previous automatic-download choices are disabled; an ordinary quit does not install an unconfirmed update. Conflicting tasks still block updates, and history is saved before installation. Downloads follow system proxy settings, and the feed and archive retain verification with the existing Ed25519 key. The App is ad-hoc signed without Developer ID or Apple notarization; first launch may require manual approval. smartctl 7.5 is bundled.
