# Capricorn V2.5.1 发布说明

发布日期：2026-09-09

Capricorn V2.5.1 使用 `Version = 2.5`、`Build = 1`，Display Name 为 `Capricorn V2.5.1`。

## 主要更新

- 概览健康度电池图标改用系统符号，并按健康度显示 100%、60–99%、40–59%、20–39%、1–19% 和 0% 六档填充。
- 历史页重新整理快速自检、自检报告和 SMART/测速/实时活动模块的布局，快速自检只保留一个“清理结果”入口，不进入隐藏记录。
- 对齐历史页操作按钮并限制按钮使用内容宽度，避免操作按钮拉伸到整行。
- 保留 SMART 温度和错误日志条目的独立提示；它们不会改变整个 SMART 健康等级。
- 完善自检能力探测、系统盘权限保护、无法发送 NVMe 自检命令 `0x14` 时的灰色状态和本地化提示。

## 下载与兼容性

- Release 包名：`Capricorn-v2.5.1-macOS.zip`
- App 名称：`Capricorn V2.5.1.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。
