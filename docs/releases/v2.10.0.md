## 中文

### 主要更新

- 开发者选项支持创建模拟虚拟硬盘，可配置名称、型号、序列号、容量、SSD/HDD、接口、扇区大小、分区和概览指标；通过“添加虚拟硬盘”或 `Command+T` 新建，在右键菜单中修改配置。
- 虚拟硬盘名称带有“（虚拟硬盘）”标记，只在当前应用会话中存在。推出即删除，关闭虚拟硬盘开关或开发者选项会推出全部模拟设备，不保留缓存或历史信息。
- 系统逻辑设备和安装包卷不再单独显示为硬盘；真实硬盘和虚拟硬盘的操作直接显示在硬盘右键菜单中。
- 添加虚拟硬盘、语言切换和刷新控件合并为一行；点击侧栏版本和用户名可直接打开更新设置。

### 下载、兼容性与安全

- 下载：[Capricorn-v2.10.0-macOS.zip](https://github.com/LexTheAries2209/Capricorn/releases/download/v2.10.0/Capricorn-v2.10.0-macOS.zip)；App 名称：`Capricorn V2.10.0.app`。
- 版本元数据：Version `2.10`、Build `0`、显示名 `Capricorn V2.10.0`。
- 需要 macOS 14.0 或更新版本；内置 smartctl 7.5，无需另行安装 smartmontools。可选 SAT SMART 驱动不会自动安装。
- 虚拟硬盘只模拟概览信息，不创建磁盘镜像、文件系统或真实挂载点，不预分配实际磁盘空间，也不执行真实 SMART、测速、实时活动或磁盘急救。
- SMART 信息取决于设备和桥接器提供的数据；网络卷不提供全部本地物理磁盘活动数据。
- 测速和大文件负载会在选定文件夹创建临时文件。读取负载也需要先写入源文件；持续写入和循环负载可能带来存储压力与磨损，请确认目标位置并保留重要数据备份。
- 此分发包未执行 Developer ID 签名、公证或 Gatekeeper 信任验证，首次运行可能需要手动允许。本地运行脚本使用 Apple Development 签名，不代表 GitHub 分发包获得 Developer ID 签名或公证。

## English

### Highlights

- Developer Options supports simulated virtual disks with configurable name, model, serial number, capacity, SSD/HDD type, interface, sector size, partitions, and overview metrics. Create one with Add Virtual Disk or `Command+T`, and edit it from the context menu.
- Virtual disk names include “(Virtual Disk)” and exist only for the current app session. Ejecting deletes them; disabling virtual disks or Developer Options ejects all simulated devices without retaining caches or history.
- Operating-system logical devices and installer volumes are no longer listed as separate disks; real and virtual disk actions appear directly in the disk context menu.
- Add Virtual Disk, language switching, and refresh share one row; the sidebar version and user label opens update settings.

### Download, Compatibility, and Safety

- Download: [Capricorn-v2.10.0-macOS.zip](https://github.com/LexTheAries2209/Capricorn/releases/download/v2.10.0/Capricorn-v2.10.0-macOS.zip); App: `Capricorn V2.10.0.app`.
- Bundle metadata: Version `2.10`, Build `0`, display name `Capricorn V2.10.0`.
- macOS 14.0 or later; smartctl 7.5 is bundled, so smartmontools need not be installed separately. The optional SAT SMART driver is not installed automatically.
- Virtual disks simulate overview information only. They do not create disk images, filesystems, real mount points, or allocate physical disk space, and do not run real SMART, benchmarks, Live Activity, or First Aid.
- SMART information depends on the device and bridge; network volumes do not provide all local physical-disk activity data.
- Benchmarks and large-file workloads create temporary files in the selected folder. Read workloads also write source files before reading; sustained writes and loops can cause storage stress and wear. Verify the target and keep important backups.
- This distribution is not Developer ID signed, notarized, or Gatekeeper-trust verified; manual approval may be required on first launch. The local run script uses Apple Development signing, which does not provide Developer ID signing or notarization for the GitHub package.
