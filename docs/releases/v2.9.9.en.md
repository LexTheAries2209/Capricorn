# Capricorn V2.9.9

Release date: 2026-10-15

## Highlights

- “Do not wake sleeping disks for SMART refresh” is off by default for new installations and settings resets; saved user choices are preserved.
- Adds Developer Options, off by default. Enabling it reveals separate custom-benchmark and virtual-disk switches, both off by default.
- Benchmarking shows four built-in profiles by default; enabling custom configuration adds Custom. Disabling it returns to Default while retaining custom settings and allowing an active benchmark to continue.

## Download, Compatibility, and Safety

- Download: [Capricorn-v2.9.9-macOS.zip](https://github.com/LexTheAries2209/Capricorn/releases/download/v2.9.9/Capricorn-v2.9.9-macOS.zip).
- App: `Capricorn V2.9.9.app`; Version `2.9`, Build `9`, display name `Capricorn V2.9.9`.
- macOS 14.0 or later; smartctl 7.5 is bundled, so smartmontools need not be installed separately. The optional SAT SMART driver is not installed automatically.
- The virtual-disk switch currently only saves its state; virtual-disk functionality will be provided later.
- SMART information depends on the device and bridge; network volumes do not provide all local physical-disk activity data.
- Benchmarks and large-file workloads create temporary files in the selected folder. Read workloads also write source files before reading; sustained writes and loops can cause storage stress and wear. Verify the target and keep important backups.
- This distribution is not Developer ID signed, notarized, or Gatekeeper-trust verified; manual approval may be required on first launch.
