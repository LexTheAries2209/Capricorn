# Capricorn V2.11.1

发布日期：2026-10-19。

## 版本与安装

- 完整版本 `2.11.1`，Build `0047`。构建号是独立、全局递增的四位发布构建序号，不再拼入版本号。
- 下载 `Capricorn-v2.11.1-macOS.zip`，解压后安装固定名称的 `Capricorn.app`。
- V2.10.2 及以后可使用应用内更新；更早版本和旧开发 Build `1000` 需手动安装。
- 要求 macOS 14.0 或更高版本，包含 arm64、x86_64。

## 更新内容

- 更新检查可与硬盘刷新、测速等任务同时进行，不再因这些任务弹出“更新已阻止”。
- 开发者自动更新发现新版时若任务忙碌，会静默保留新版提示，不开始下载。任务完成后可手动重试，或在下次启动时再次检查。

## 更新与安全

启动检查及开发者自动更新均默认关闭。手动选择下载时仍检查全部任务冲突；下载中出现冲突会取消并提示。安装、恢复安装及更新重启前继续复查冲突并保存历史；保存失败会阻止安装。普通退出不安装尚未确认的更新，受阻的更新不会在任务结束后自行恢复。

更新清单和安装包使用既有 Ed25519 密钥签名。App 使用 ad-hoc 签名，没有 Developer ID 或 Apple 公证，首次启动可能需手动允许。内置 smartctl 7.5，无需另装；可选 SAT SMART Drive 依设备需要手动配置。

测速及负载仅在选定文件夹创建临时文件，不直接向裸设备写入。读取项目也可能先写入临时源文件；持续写入会产生压力和磨损，请确认目标并备份重要数据。
