# Capricorn V2.12.0

Release date: October 29, 2026. Complete Version `2.12.0`, Build `0048`.

Build is an independent, globally increasing four-digit release-build sequence and is not appended to the version.

## Changes

- Adds shared storage topology with USB, Thunderbolt, and PCIe paths, link rates, and chip information. Select a disk to update the sidebar and details, or select the computer for the system disk.
- Supports draggable nodes, trackpad zoom and pan, M to open, - / = to zoom, and Z to rearrange.
- Adds Mac model and port views, with front and rear socket selection for desktop models. Common controller and SSD chip names are bundled locally without online lookups.

## Installation And Compatibility

Requires macOS 14.0 or later on Apple silicon or Intel. Download `Capricorn-v2.12.0-macOS.zip` and install the stable-name `Capricorn.app`. V2.10.2 and later support in-app upgrades; earlier versions or old development Build `1000` require manual installation.

Topology uses system-reported information. Link rates are not measured throughput, and unknown chips retain their original identifiers. Launch checks and developer automatic updates default to off, with task conflicts and history saving checked before installation. smartctl 7.5 is bundled; SAT SMART Drive is optional. Benchmarks and workloads use temporary files in the selected folder. Verify targets and back up important data.

The App uses valid ad-hoc signatures, and the archive and feed use the existing Ed25519 key. Developer ID and Apple notarization are not established.
