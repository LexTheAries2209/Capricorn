# Capricorn V2.9.0

中文发布说明：[v2.9.0.zh-CN.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.0/docs/releases/v2.9.0.zh-CN.md)

English release notes: [v2.9.0.en.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.0/docs/releases/v2.9.0.en.md)

发布日期 / Release date: 2026-09-23

V2.9.0 improves SMART self-test capability reporting, progress and completion feedback, and diagnostics export. System disks remain readable for SMART health, but Capricorn no longer offers checks or self-tests for them.

V2.9.0 改进 SMART 自检能力判断、进度与完成反馈以及诊断导出。系统盘仍可查看 SMART 健康信息，但 Capricorn 不再提供系统盘检查和自检。

## 中文

Capricorn V2.9.0 使用 `Version = 2.9`、`Build = 0` 和 Display Name `Capricorn V2.9.0`。

### 主要更新

- 修正 USB-NVMe 的自检能力判断与传输层提示。能读取 SMART 属性不代表桥接器支持启动 SMART 自检；实际功能仍取决于设备及 macOS 传输层。
- 对支持的非系统盘提供快速/完整 SMART 自检启动确认；启动后可隐藏并从 SMART 页面重新打开进度监视器。显示硬盘报告的进度、运行时间、预计完成时间、最近刷新与当前状态。隐藏窗口不会中止硬盘自检；中止需要二次确认。
- 自检结束区分通过、失败、用户中止、设备断开及结果未知，不把未知状态标为通过。设备不报告准确百分比时，不伪造进度或保证完成时间。
- 系统盘不再渲染概览快速自检、SMART 诊断自检与历史中的快速自检/自检报告；对应右键磁盘检查操作禁用，后台操作路径也拒绝系统盘检查和自检。常规 SMART 属性、快照与其他历史仍可查看。
- 设置将快速自检与修复及 SMART 诊断显示移入界面显示区域；新增重置所有设置（含已保存界面选项）并要求二次确认，保留硬盘缓存和历史数据库。
- 导出 SMART 诊断自检历史时，每次选择 CSV 或 JSON 的保存位置；SMART 快照 CSV 的导出方式保持不变。

### 下载、兼容性与安全

- Release 包名：`Capricorn-v2.9.0-macOS.zip`；App 名称：`Capricorn V2.9.0.app`。
- 系统要求：macOS 14.0 或更新版本；smartctl 7.5 已内置，无需另行安装 smartmontools。
- 硬盘自检由设备固件执行，长程测试可能持续很久；测试期间不要断开外接设备。进度取决于设备报告，不能表示逐项检查内容。虚拟 T7 仅用于开发演示，正式版不启用该演示入口；没有真实 T7 的实盘验证。
- 磁盘急救可能修改文件系统，只对用户确认的合格非系统卷提供。测速与实时活动负载可能创建临时文件并产生写入和磨损；开始前核对目标和备份。

## English

Capricorn V2.9.0 uses `Version = 2.9`, `Build = 0`, and display name `Capricorn V2.9.0`.

### Highlights

- Corrects USB-NVMe self-test capability reporting and transport guidance. Readable SMART attributes alone do not establish that a bridge can start a self-test; actual support depends on the device and macOS transport.
- Adds confirmation for short/extended SMART self-tests on supported non-system disks. The progress monitor can be hidden and reopened from SMART. It shows device-reported progress, elapsed time, estimated completion, last refresh, and current status. Hiding does not abort the on-drive test; abort requires confirmation.
- Distinguishes pass, failure, user abort, device disconnect, and unknown completion. Missing device progress is not invented, and completion time is only an estimate.
- Removes Overview quick checks, SMART diagnostic self-tests, and quick-check/self-test report sections in History for system disks. Disk checks are disabled in the context menu and rejected by operation paths. Ordinary SMART attributes, snapshots, and other history remain available.
- Moves Quick Self-Test and Repair and SMART diagnostics visibility under Interface Display. Reset All Settings confirms before clearing saved settings and UI choices while retaining disk caches and the history database.
- Each SMART diagnostics self-test history CSV/JSON export opens a save-location picker. SMART snapshot CSV export behavior is unchanged.

### Download, Compatibility, And Safety

- Release package: `Capricorn-v2.9.0-macOS.zip`; App name: `Capricorn V2.9.0.app`.
- Requires macOS 14.0 or later. smartctl 7.5 is bundled; no separate smartmontools installation is required.
- Self-tests run in drive firmware and extended tests can take a long time. Do not disconnect external drives during testing. Progress is device-reported and does not enumerate everything checked. The virtual T7 is development-only, excluded from the production experience; no physical T7 validation was available.
- First Aid may modify a filesystem and is offered only for eligible non-system volumes with confirmation. Benchmark and Live Activity workloads may create temporary files, writes, and wear; verify the target and backups first.
