## 中文

Capricorn V2.5.0 使用 `Version = 2.5`、`Build = 0` 和 Display Name `Capricorn V2.5.0`。

### 主要更新

- 新增 SMART 诊断界面：支持设备自检状态、快速/完整自检、历史记录、错误条目读取与导出，并根据设备能力和权限显示可用操作。
- SMART 温度和错误日志条目保持独立提示：温度沿用 `70–85 °C` 警告、`85 °C` 及以上错误，错误日志条目也保留单项提示，但两者都不会改变整个 SMART 健康等级。
- macOS 无法通过 smartctl 发送 NVMe 自检命令 `0x14` 时，界面显示灰色的无法完成自检状态和本地化说明。
- 概览新增与右键菜单一致的快速自检入口；快速自检报告按硬盘身份保存，系统盘运行前要求先在设置中允许检查，设置界面支持 Escape 关闭。
- 修复 SMART 诊断视图和测试目标配置导致的编译问题，并补充相关测试。

### 下载与兼容性

- Release 包名：`Capricorn-v2.5.0-macOS.zip`

- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。

## English

Capricorn V2.5.0 uses `Version = 2.5`, `Build = 0`, and the display name `Capricorn V2.5.0`.

### Highlights

- Adds SMART diagnostics with device self-test status, quick/full tests, history, error-entry reads, exports, and capability-aware controls.
- Keeps SMART temperature and error-log entries independent from the overall SMART health level; `70–85 °C` is a warning and `85 °C` or above is an error.
- Shows a muted, localized self-test-cannot-complete state when macOS smartctl cannot send NVMe self-test command `0x14`.
- Adds Overview Quick Disk Check, persists reports by drive identity, protects system-disk checks behind Settings, and supports Escape to close Settings.
- Fixes the SMART diagnostics build and adds coverage for the changed behavior.

### Download And Compatibility

- Release package: `Capricorn-v2.5.0-macOS.zip`
- App name: `Capricorn V2.5.0.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
