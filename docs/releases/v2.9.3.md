# Capricorn V2.9.3

中文发布说明：[v2.9.3.zh-CN.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.3/docs/releases/v2.9.3.zh-CN.md)

English release notes: [v2.9.3.en.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.3/docs/releases/v2.9.3.en.md)

发布日期 / Release date: 2026-09-29

Capricorn V2.9.3 是面向 SMART 诊断可靠性和硬盘操作状态隔离的维护版，包含自 `v2.9.1` 以来尚未单独公开发布的改动。

## 中文

Capricorn V2.9.3 使用 `Version = 2.9`、`Build = 3` 和 Display Name `Capricorn V2.9.3`。

### 主要更新

- 无 SMART 属性时隐藏 SMART 页面顶部标题、存储说明和保存操作；当前属性没有 `smartctl` 来源时隐藏 SMART 诊断区，避免对无法完成自检或错误日志读取的设备显示无效控件。
- 修复 SMART 自检确认窗口点击取消后的白色残留块，并恢复快速自检取消/关闭行为；sheet 先执行退出动画，再清理模型状态。
- 测速、实时监控和实时工作负载运行期间锁定侧边栏硬盘选择，避免切换硬盘导致测速或活动状态与目标设备不一致。
- 延续此前版本的硬盘型号识别扩展和 SMART 自检状态解析修复，包含更具体的外置盒匹配优先级，以及已完成自检不再被误判为进行中的修正。

## 下载、兼容性与安全

- Release 包名：`Capricorn-v2.9.3-macOS.zip`；App 名称：`Capricorn V2.9.3.app`。
- 需要 macOS 14.0 或更新版本；内置 smartctl 7.5。部分 USB 桥接器不能透传 SMART、自检或错误日志命令。
- SMART 属性来源和诊断区显示规则只影响界面，不会伪造设备能力，也不会自动向硬盘发起自检。测速仍会写入目标文件夹，请保留重要数据备份并确认目标位置。
- 此分发包不执行 Developer ID 签名、公证或 Gatekeeper 信任验证，首次运行可能需要手动允许。
