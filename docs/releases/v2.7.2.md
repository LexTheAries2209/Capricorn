This release reorganizes Settings around disk and SMART workflows, adds a complete shortcut reference, and standardizes feature-page switching on the Tab key.

## 中文

- SAT SMART Driver 仅是兼容 USB-SATA 设备的可选组件。Capricorn 不会自动安装或加载驱动，也不会修改系统安全设置。

## English

Capricorn V2.7.2 uses `Version = 2.7`, `Build = 2`, and the display name `Capricorn V2.7.2`.

### Highlights

- Settings now includes Interface Display and Keyboard Shortcuts sections. The shortcut reference sits below SMART and above History Database and lists Settings, refresh, SMART snapshot export, and page navigation commands.
- Automatic drive refresh, sleeping-drive protection, and SMART diagnostics options are consolidated under Disk Actions. History Database now appears at the bottom of Settings.
- Feature pages now always advance in order with `Tab`. The former setting and the Control-Tab and Control-Shift-Tab combinations have been removed, leaving Tab as the only page-switching shortcut.
- The app now bundles only `SATSMARTDriver-0.10.3.pkg` for SAT SMART Drive instead of duplicating the installer in a ZIP resource.

### Download And Compatibility

- Release package: `Capricorn-v2.7.2-macOS.zip`
- App name: `Capricorn V2.7.2.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
- SAT SMART Driver remains optional for compatible USB-SATA devices. Capricorn does not install or load it automatically or change system security settings.

- Strict-concurrency, Swift 6 compatibility, and Release Archive builds succeeded. The Swift 6 production build reported only the existing `String(cString:)` deprecation warning.
- App metadata, arm64/x86_64 universal architecture, bundled smartctl, and the SAT PKG were checked. Archive App and dSYM UUIDs match for both architectures.
- The release App was launched and its V2.7.2 identity, SAT status, and Settings section order were visually verified.
- Package size: 9,177,002 bytes; SHA-256: `baac9faca2b2487e3a6fb37770fee2f39b949cd511afc61e6cd0e4d9f0656355`; `unzip -t` passed.
- Developer ID signing, notarization, and Gatekeeper trust verification were not performed; macOS may require manual approval on first launch.
