# Capricorn V2.10.5

发布日期：2026-10-18。

## 版本与安装

- 完整版本 `2.10.5`，Build `0045`。构建号是独立、全局递增的四位发布构建序号，不再拼入版本号。
- 下载 `Capricorn-v2.10.5-macOS.zip`，解压后安装固定名称的 `Capricorn.app`。
- V2.10.2 及以后可使用应用内更新；更早版本、旧开发 Build `1000` 需手动安装。
- 系统要求：macOS 14.0 或更高版本，包含 arm64 和 x86_64。

## 更新内容

- 测速控制新增“停止”：完成当前一轮后计算结果，跳过剩余测试及自定义循环。“取消”仍立即结束，未完成的当前测试不计入结果。
- 精简自定义测速项目组，混合开关改为“读写混合”，最多四个项目组的限制保留。
- 虚拟硬盘入口标记 Beta，健康度默认根据指标自动计算，也可手动选择；支持内置系统盘模拟、CFast 2.0、网络和 SD 类型，扇区可选 512 B / 4 KB。
- 分区名称、类型、容量和已用容量独立成行，类型选择器右对齐；容量和已用容量均支持独立选择单位。新建虚拟硬盘名称从“虚拟硬盘01”依次编号。
- 首次启动默认简体中文，保留已有语言选择；“预故障”统一更名为“错误”，已有历史仍可读取。网络与虚拟硬盘使用专用图标。
- 开发者选项新增默认关闭的“自动下载并安装更新”，开启后可自动下载、安装并重启。

## 更新与安全

启动检查默认关闭，保留已保存的选择，15 秒无结果自动结束。开发者自动更新默认关闭；未启用时仍由用户确认下载和安装。关闭开发者总开关会停用自动更新；下载中关闭自动更新时，准备完成后恢复手动安装确认。有冲突任务或历史保存失败时阻止安装。

更新下载遵循系统代理，清单与安装包使用原有 Ed25519 密钥验证。App 使用有效 ad-hoc 签名，没有 Developer ID 或 Apple 公证，首次启动可能需要手动允许。内置 smartctl 7.5，无需额外安装。测速写入和大文件负载仍需确认目标并保留备份。

安装回归使用独立测试 App、历史与偏好，不替换真实用户 App 或数据库，也不证明 Intel 或 macOS 14 真机安装行为。
