# Capricorn V2.9.2 中文发布说明

发布日期：2026-09-28

双语发布说明：[v2.9.2.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.2/docs/releases/v2.9.2.md)

Capricorn V2.9.2 使用 `Version = 2.9`、`Build = 2` 和 Display Name `Capricorn V2.9.2`。

## 主要更新

- 扩充本地硬盘型号数据库，识别 Seagate BarraCuda 2.5 英寸、Portable、Expansion Portable、Backup Plus、One Touch、Ultra Touch，以及 LaCie Mobile Drive、Rugged Mini 系列。独立显示产品名称，并让更具体的 USB 身份/容量规则优先匹配。此更新不是 smartmontools 上游数据库更新。
- 修正 SMART 自检记录的“进行中”误判：明确的通过/完成状态优先于剩余百分比；只有终态的历史记录才标注“已完成”，否则显示“读取时间”。已连接 `ST5000LM000-2U8170` 的只读检查显示快速自检 `Completed without error`（通电 442 小时），不代表其他设备均已实盘验证。

## 下载、兼容性与安全

- Release 包名：`Capricorn-v2.9.2-macOS.zip`；App 名称：`Capricorn V2.9.2.app`。
- 需要 macOS 14.0 或更新版本；内置 smartctl 7.5。部分 USB 桥接器不支持 SMART/自检透传。
- 型号识别只影响显示，不改变硬盘数据；本次状态修复不会自动发起自检。请保留重要数据备份。
- 此分发包未执行 Developer ID 签名、公证或 Gatekeeper 信任验证，首次运行可能需要手动允许。
