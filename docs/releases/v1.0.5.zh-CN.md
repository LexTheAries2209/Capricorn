# Capricorn V1.0.5 发布说明

Capricorn V1.0.5 沿用 `Version = 1.0`、`Build = 5` 的版本命名规则，Display Name 为 `Capricorn V1.0.5`。本版解决了测速卡顿问题，并新增具有严格安全边界的磁盘“急救”流程。

## 下载

- Release 包名：`Capricorn-v1.0.5-macOS.zip`
- App 名称：`Capricorn V1.0.5.app`
- 系统要求：macOS 14.0 或更新版本

首次打开时，如果 macOS Gatekeeper 提示来自互联网下载的 App，请在 Finder 中右键点击 App 后选择“打开”，或在“系统设置 > 隐私与安全性”中允许打开。

## 重点更新

- 解决测速取消、立即重启和后台晚到回调可能造成的界面卡顿问题；停止后会等待文件句柄、临时文件和工作任务完成真实清理。
- 在本地物理硬盘右键菜单加入“急救…”，使用独立预检、用户逐卷选择、双重风险确认和实时系统输出。
- 仅允许外接或可移除 APFS/ExFAT 卷执行 `diskutil repairVolume`，并在每个卷启动前重新验证设备标识、卷 UUID、父物理盘、格式、可写和锁定状态。
- SMART 为 `preFail` 或 `failed` 时阻止直接急救；SMART 警告状态需要额外风险确认。
- 网络卷、虚拟磁盘、内置/系统盘、只读卷、锁定卷和不支持格式会明确显示阻断原因。
- NTFS 不调用任何修复命令，仅提供 Windows CHKDSK 示例和 Microsoft 文档入口。
- 修复前检查占用文件并显示相关进程；Capricorn 不终止进程，也不自动强制卸载。
- 多卷修复按卷串行执行，提供“完成当前卷后停止”；不会中断正在运行的文件系统修复。
- 修复期间禁用刷新、测速、实时写入负载、装载/卸载、重命名和其他磁盘检查；完成后自动刷新磁盘与 SMART 信息。
- 补齐磁盘急救的简体中文、英文、VoiceOver 标签、系统磁盘工具回退和恢复模式说明。
- 新增 APFS/ExFAT 资格、NTFS 阻断、身份变化、非零退出、部分成功、停止后续卷和命令白名单测试。

## 安全边界

- 不提供 `repairDisk`、擦除、重新格式化、分区或裸设备写入。
- 不直接执行 `fsck -y`，不使用 `sudo`、AppleScript 密码提示或管理员 Helper。
- 系统盘和内置盘只显示磁盘工具/恢复模式指引，不从 Capricorn 直接修复。
- 急救修复的是文件系统结构一致性，不是数据恢复，也不能修复 SMART 故障、介质损坏、线材或供电问题。
- 执行前请先备份重要数据、停止复制和测速，并确保供电与连接稳定。

## 可选依赖

Capricorn 不捆绑 `smartctl`。如需更完整的 ATA/NVMe SMART 数据，可以自行安装 smartmontools：

```sh
brew install smartmontools
```
