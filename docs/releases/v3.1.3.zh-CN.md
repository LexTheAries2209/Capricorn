# Capricorn V3.1.3

发布日期：2026-11-02。完整版本 `3.1.3`，Build `0053`。
构建号是独立、全局递增的四位发布构建序号，不再拼入版本号。

## 本版变化

- 修复 APFS 外置硬盘可能被误报为无法唯一确定 SMART 目标的问题。
- 改善 SMART 与 SNT 的设备识别及目标异常提示。

## 安装与安全

下载 `Capricorn-v3.1.3-macOS.zip` 并安装固定名称 `Capricorn.app`。需要 macOS 14.0 或更高版本，包含 arm64/x86_64。V2.10.2 及以后支持应用内更新；更早版本和旧开发 Build `1000` 需手动安装。

特权设备服务须在设置中启用并完成系统批准。推荐 `/Applications`，也可使用本机可写、非可移除磁盘上的固定文件夹。手动移动或替换 App 前先停用服务；应用内更新会尝试恢复此前已启用的服务，系统仍可能要求重新批准。

每次 SNT 仍须确认卸载该 USB 设备上的全部卷，请先关闭文件、结束其他磁盘任务并备份重要数据。结束后尝试恢复挂载，失败时可能需要重新连接或使用“磁盘工具”。重试不会强制卸载或结束程序，显示的占用程序仅是排查线索。可移动卷隐私授权由系统单独管理，后台扫描不会主动接管 USB 设备。

兼容性取决于桥接器、固件与设备，不保证所有 USB 设备可用，也不提供通用 SD 卡健康读取。本次已在真实 USB APFS 外置盘上验证物理盘识别与合成盘排除，未执行真实 SNT 接管、卷卸载或硬件自检。

常规读取使用内置 smartctl 7.5，SAT SMART Drive 可选。测速与负载使用所选文件夹中的临时文件，写入测试可能给存储带来压力，请确认目标并保留备份。

## 验证与源码

全量 721 项测试：719 通过、2 跳过、0 失败。跳过显式启用的 root 硬件操作检查及无证书测试主程序的证书专属检查。真实 USB APFS 只读身份检查通过：物理盘可匹配，合成盘被排除。严格并发与 Swift 6 构建通过；20 个真实 Sparkle 隔离场景全部通过。

App、服务及工具使用同团队 Apple Development 证书签名，更新使用既有 Ed25519 密钥；没有 Developer ID 或 Apple 公证。

Universal Archive、归档 App 启动、存档源码独立 Universal Release 构建、App/服务/两套 smartctl 双架构、完整签名及 dSYM UUID 核对通过。更新包与清单 Ed25519 签名复验通过，真实 Sparkle 候选源确认旧 Build `0052` 发现 `3.1.3 / 0053`，当前 `0053` 无更新。

安装回归使用隔离测试 App、历史与偏好，不替换真实用户 App 或数据库。服务衔接场景使用模拟协调器，不等于真实 root 服务跨版本安装或授权保留验收。Intel、macOS 14 及其他 Mac 的证书信任与服务批准仍需另行验证。

`Capricorn-v3.1.3-source.tar.gz` 提供固定发布提交的完整对应源码、两套 smartctl 的上游源码包、本地 SNT 补丁、构建脚本及许可证。Capricorn 为 GPL-3.0-only，smartctl 与 SNT 工具为 GPL-2.0-or-later。完整验证与安装包摘要见[完整发布说明](https://github.com/LexTheAries2209/Capricorn/blob/v3.1.3/docs/releases/v3.1.3.md)。
