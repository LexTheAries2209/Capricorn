# Capricorn V2.3.1 发布说明

发布日期：2026-08-25

Capricorn V2.3.1 使用 `Version = 2.3`、`Build = 1` 和 Display Name `Capricorn V2.3.1`。

## 主要更新

- 设置中的历史数据库区域新增目录、占用空间与记录总数显示，可打开 Finder 位置，并支持二次确认后清理全部本地历史数据。
- 历史与报告会显示当前硬盘未隐藏和已隐藏记录数。支持清理当前硬盘全部历史，或只清理已隐藏数据；操作均需确认，且不会影响其他硬盘。
- 系统盘测速自动目标改为优先使用桌面目录，避免在系统根目录创建测试文件。
- 实时监控或大文件负载运行时，其他侧边栏硬盘会灰显并禁止鼠标和键盘切换；任务停止后恢复可选。
- Tab 切页说明已放回 Tab 切换开关下方。

## 下载与兼容性

- Release 包名：`Capricorn-v2.3.1-macOS.zip`
- App 名称：`Capricorn V2.3.1.app`
- 系统要求：macOS 14.0 或更新版本
- 可选依赖：用户自行安装的 smartmontools (`smartctl`) 与 SAT SMART Driver
- 本版未使用 Developer ID 签名且未公证；首次打开可能需要 Finder > 打开，或在“系统设置 > 隐私与安全性”中允许。

## 数据提示

- 清理历史数据库、清理当前硬盘历史和清理已隐藏数据都会永久删除相应本地记录，请在确认前核实数量。
- 测速只会在所选目录创建临时文件；写入、混合和循环模式会对存储产生压力。
