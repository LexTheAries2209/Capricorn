## 中文

Capricorn V1.2.5 使用 `Version = 1.2`、`Build = 5` 和 Display Name `Capricorn V1.2.5`。本版主要增强 SMART 自检、smartctl 7.5 兼容性和外接磁盘 SMART 信息布局。

### 下载

- Release 包名：`Capricorn-v1.2.5-macOS.zip`
- App 名称：`Capricorn V1.2.5.app`
- 系统要求：macOS 14.0 或更新版本

### 重点更新

- SMART 自检日志解析兼容 ATA 标准表格、旧字符串格式、NVMe 不同字段布局、缺失字段和数字/字符串混合类型；解析失败时保留原始 JSON/文本输出。
- SMART 页面支持快速自检、完整自检、自动轮询和中止操作，显示当前状态、预计时间、最近记录、失败 LBA、通电小时和原始状态。
- 概览页面只显示设备返回的最近一次自检摘要；完整日志和自检操作集中在 SMART 页面。
- 根据设备能力禁用不支持的自检操作；macOS 原生 NVMe 不支持 admin command `0x14` 时保留可用的健康信息和日志读取能力，不强行启动自检。
- 系统盘自检可以在设置中单独允许，操作仍使用 macOS 原生管理员授权提示。
- 增强 smartctl 7.5 的统一健康字段和诊断信息；SMART 刷新默认避免唤醒休眠磁盘，无法安全识别设备类型时保留上一份快照。
- 外接磁盘 SMART 状态、smartctl 诊断和 SAT 驱动信息新增折叠控制；已验证时默认折叠，异常或未验证时默认展开。

### 安全与限制

- 自检只对设备实际报告支持的目标提供操作；桥接芯片、USB NVMe 和 macOS 传输层可能不支持自检，即使设备本身具备该能力。
- 写入、混合、循环、大文件负载和 SMART 自检可能增加设备工作负载；请确认目标磁盘和供电稳定。
- Capricorn 不捆绑 smartctl，也不会自动安装或卸载 SAT 内核扩展。

## English

Capricorn V1.2.5 uses `Version = 1.2`, `Build = 5`, and Display Name `Capricorn V1.2.5`. This release focuses on SMART self-tests, smartctl 7.5 compatibility, and a less intrusive external-drive SMART layout.

### Highlights

- SMART self-test parsing now accepts ATA table objects, legacy string formats, NVMe field layouts, missing fields, and mixed numeric/string values; raw JSON/text is retained as a fallback when structured parsing is incomplete.
- The SMART page adds short/full self-tests, automatic polling, abort, current state, estimated duration, recent records, failed LBA, power-on hours, and raw status output.
- Overview keeps only the latest device-reported self-test summary; full logs and actions live on the SMART page.
- Unsupported self-test operations are disabled by device capability. When the native macOS NVMe transport cannot send admin command `0x14`, available health and log reads remain intact and a self-test is not forced.
- System-disk self-tests can be allowed separately in Settings and still use the native macOS administrator authorization prompt.
- smartctl 7.5 unified health fields and diagnostics are supported; SMART refresh avoids waking sleeping disks by default and retains the previous snapshot when safe device identification is unavailable.
- External-drive SMART status, smartctl diagnostics, and SAT driver details are collapsible; verified disks start collapsed, while unverified or failing states start expanded.

### Safety and limitations

- Self-test controls are shown only for targets that report support. Bridge chips, USB NVMe transports, and macOS transport limitations can prevent self-tests even when the drive itself supports them.
- Write, mixed, loop, large-file workloads, and SMART self-tests can increase device load. Confirm the target disk and stable power before running them.
- Capricorn does not bundle smartctl or install/remove SAT kernel extensions.
