# Capricorn V2.7.0 中文发布说明

发布日期：2026-09-17

双语发布说明：[v2.7.0.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.0/docs/releases/v2.7.0.md)

Capricorn V2.7.0 使用 `Version = 2.7`、`Build = 0` 和 Display Name `Capricorn V2.7.0`。

## 主要更新

- 重构侧边栏状态区域：固定显示硬盘健康摘要和刷新状态，保留最近三条去重活动及本机时间，并根据实际消息数量动态调整高度。
- SMART 读取、硬盘扫描、占用程序查看和硬盘操作现在都会原地更新为完成状态；已装载卷的“装载”操作会正确禁用。
- 版本号和 macOS 用户名现与设置位于同一行；身份提示、状态文案、SD 卡提示及语言切换布局完成中英文整理。
- 系统盘不再显示 SMART 错误条目；无 SMART 属性或网络设备不显示诊断模块，网络盘也不显示快速自检。网络盘标题优先使用主机名或地址，缺失序列号显示“无”。
- 符合条件但未返回 SMART 数据的 USB 存储设备会显示 SAT SMART Drive 引导和设置入口；网络盘、SD 卡、内部硬盘以及已有 SMART 数据的设备不会误触发。
- 快速自检历史支持卷 UUID 后备匹配；无 SMART 属性时隐藏自检报告，能力恢复后自动重新显示；历史页及测速曲线可根据窗口宽度自适应布局。

## 下载与兼容性

- Release 包名：`Capricorn-v2.7.0-macOS.zip`
- App 名称：`Capricorn V2.7.0.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置。
- SAT SMART Driver 是兼容 USB-SATA 设备的可选组件，不会被自动安装或加载。
- SMART 不可用只表示当前接口没有提供可读取数据，不等同于硬件故障。
