# Capricorn V2.4.0 发布说明

发布日期：2026-09-02

Capricorn V2.4.0 使用 `Version = 2.4`、`Build = 0`，Display Name 为 `Capricorn V2.4.0`。

## 主要更新

- 内置固定版本 smartmontools 7.5，随 App 提供通用 `arm64`/`x86_64` 的 `smartctl`、`drivedb.h` 和 GPL 许可证；仓库同时提供对应源码、哈希和可复现构建脚本。
- SMART 默认使用 App 内置工具，不再自动搜索 PATH 或 Homebrew。设置中的非空路径仅作为用户明确选择的外部覆盖，并显示工具来源、版本、数据库版本和兼容性。
- 将外接 SMART 支持、ATA SMART 选项和 SAT 驱动诊断集中到设置界面，精简诊断内容并保留开源项目入口；不会自动安装或卸载内核扩展。
- SMART 属性表支持独立滚动并自适应可用 UI 高度；移除外置 SMART 模块后，SMART 信息区域会填满内容区。
- 同一磁盘的 SMART 查询与自检命令保持串行，避免并发访问同一个设备。
- 补充和修正 WD Elements Portable 5TB 等外接磁盘型号与卷宗识别规则。

## 下载与兼容性

- Release 包名：`Capricorn-v2.4.0-macOS.zip`
- App 名称：`Capricorn V2.4.0.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。
- SAT SMART Driver、Homebrew 和其他外部工具仍为可选依赖；外部工具只有在设置中明确指定时才会使用。

## 数据提示

- SMART 数据是否可用取决于 macOS、设备协议和 USB 桥接器能力。SAT 仅适用于支持 SATA/ATA 透传的设备；NVMe over USB 设备可能不会提供 SMART。
- Capricorn 不会伪造缺失的 SMART 属性，也不会自动降低 macOS 安全设置来安装 KEXT。
- 测速、写入、修复和自检操作继续遵循目标确认、系统盘保护和设备能力检查。
