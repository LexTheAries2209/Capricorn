# Capricorn V3.2.0

Release date: November 2, 2026. Complete Version `3.2.0`, Build `0055`, macOS 14.0+.

Build is an independent, globally increasing four-digit release-build sequence and is not appended to the version.

- Adds optional automatic SNT reads for idle USB disks on app launch and connection.
- Retains the last valid reading, waits while disks are busy, and pauses repeated failures; a successful manual read enables future automatic attempts.
- Adds clickable device-service warnings in Settings and disables the automatic-read switch while the service is unavailable.

Download `Capricorn-v3.2.0-macOS.zip` and install the stable-name `Capricorn.app`. V2.10.2 and later support in-app upgrades; earlier versions and old development Build `1000` require manual installation.

Automatic reads are off by default. Enable the device service, complete system approval and grant required volume access, then enable Disk Actions > Read SNT automatically. No per-read confirmation is shown; one successful reading is taken per launch or connection. Busy disks wait without consuming failures. Three consecutive read failures or unsuccessful reads using all three unknown bridge protocols stop automatic attempts; a successful manual read enables future attempts.

SNT temporarily unmounts every volume on the device and attempts to restore mounts. Close files, finish disk tasks and back up important data first. No forced unmount or process termination is used; uncertain restoration pauses operation. Compatibility depends on the bridge, firmware and device; not every USB device is supported, and general SD-card health queries are not provided.

Enable the service from `/Applications` or another permanent folder on a local writable, non-removable disk. Disable it before manually moving or replacing the app. In-app updates attempt to restore a previously enabled service; macOS may require renewed approval. Removable-volume privacy consent is managed separately by macOS. smartctl 7.5 is bundled; SAT SMART Drive is optional. Benchmarks and workloads use temporary files in the selected folder.

Full suite: 747 tests, 744 passed, 3 hardware or certificate-condition skips, zero failures. Strict concurrency, Swift 6, universal archive, archived app launch, bundle signatures, dSYM checks and an independent universal Release build of the archived source passed. Twenty real Sparkle fixture scenarios passed; installation tests retained isolated history and preferences, with a mock coordinator for service handoff. Package and feed signatures passed verification. Real Sparkle staging-feed checks confirmed that Build `0054` discovers `3.2.0 / 0055` and Build `0055` reports no update.

Same-team Apple Development certificate signing and the existing Ed25519 update signature are retained; Developer ID and Apple notarization are not established. No real SNT capture, volume unmount or hardware self-test was performed. Privacy changes, system-wide occupancy, unplugging during capture, multivolume restoration, Intel/macOS 14 and service approval on other Macs require real-device acceptance checks.

`Capricorn-v3.2.0-source.tar.gz` includes complete corresponding source, upstream source archives for both smartctl tools, local patches and licenses.
