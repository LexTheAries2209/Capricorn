## 中文

Capricorn V2.4.1 使用 `Version = 2.4`、`Build = 1` 和 Display Name `Capricorn V2.4.1`。

### 主要更新

- 设置仅显示内置 `smartctl` 的版本和 smartmontools 源项目链接，不再提供外部工具选择。
- 概览的数据来源增加 USB-SATA 与 USB-NVMe SMART 命令透传状态，只对适用的 USB 设备显示。
- 统一数据来源三行的字体和布局，移除透传行上方的分割线以及独立的右侧状态文字。
- 修正 WD Elements Portable HDD 5TB 的厂商/型号识别；除 SSD、SD 卡和网络卷外的介质统一显示为 HDD。

### 下载与兼容性

- Release 包名：`Capricorn-v2.4.1-macOS.zip`
- App 名称：`Capricorn V2.4.1.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。

### 数据与安全提示

- SMART 数据是否可用仍取决于 macOS、设备协议和 USB 桥接器能力；透传状态来自实际 smartctl 读取结果，不会伪造 SMART 属性。
- Capricorn 不会自动安装或卸载内核扩展，也不会自动搜索或使用 PATH/Homebrew 中的外部 smartctl。
- 测速、写入、修复和自检操作继续遵循目标确认、系统盘保护和设备能力检查。

- App 主可执行文件为 `arm64`/`x86_64` Mach-O universal binary。

## English

Capricorn V2.4.1 uses `Version = 2.4`, `Build = 1`, and the display name `Capricorn V2.4.1`.

### Highlights

- Settings now shows only the bundled `smartctl` version and the smartmontools project link; external tool selection is removed.
- Overview reports USB-SATA and USB-NVMe SMART command pass-through for eligible USB devices.
- The three data-source rows now share one typography and layout, without a divider or a separate right-side status label on the pass-through row.
- Corrects WD Elements Portable HDD 5TB vendor/model identification; media other than SSDs, SD cards, and network volumes is displayed as HDD.

### Download And Compatibility

- Release package: `Capricorn-v2.4.1-macOS.zip`
- App name: `Capricorn V2.4.1.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.

### Data And Safety Notes

- SMART visibility still depends on macOS, the device protocol, and USB bridge capabilities. Pass-through status is based on actual smartctl reads and does not fabricate SMART attributes.
- Capricorn does not install or remove kernel extensions and does not search or select external smartctl binaries from PATH or Homebrew.
- Benchmark, write, repair, and self-test operations continue to use target confirmation, system-disk protection, and device-capability checks.

### Verification

- Full macOS test suite: 241 tests passed, 0 failures.
- Release build succeeded with App metadata `Version 2.4`, `Build 1`, and `Capricorn V2.4.1`.
- The main executable is a universal `arm64`/`x86_64` Mach-O binary.
- Bundled `smartctl 7.5`, `drivedb.h`, and `COPYING` were verified inside the App.
- Package size: 10,638,209 bytes; SHA-256: `dc67d9d065eef7f0345c248e76d21e0508674e90cccc5a545be12a2e28f6fc35`; `unzip -t` passed.
- Developer ID signing, notarization, and Gatekeeper trust checks are intentionally skipped for this release. The App uses the local build signature; macOS may require manual approval on first launch.
