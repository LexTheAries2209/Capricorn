# Capricorn V2.7.5 中文发布说明

发布日期：2026-09-20

双语发布说明：[v2.7.5.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.5/docs/releases/v2.7.5.md)

Capricorn V2.7.5 使用 `Version = 2.7`、`Build = 5` 和 Display Name `Capricorn V2.7.5`。

## 主要更新

- SMART 历史摘要现在显示健康、寿命、介质错误、累计读取量、累计写入量和通电时间，并补全简体中文文案。
- 每条 SMART 快照可打开独立、可滚动的完整报告窗口，查看快照摘要和全部 SMART 属性；窗口内可选择文件夹并再次保存 CSV。
- SMART 页面新增独立“保存到历史”操作，不生成 CSV；“保存 CSV”仍会同时把当前快照保存到历史。
- 测速历史以共享同一张活动曲线的结果作为一个完整任务，隐藏、恢复和删除会整组处理。
- 紧凑测速图会在保留网格线数量和间距的前提下跳过部分速度标签，避免刻度文字错位或拥挤。
- 设置新增默认关闭的历史逐条删除功能。开启后，可见和已隐藏的 SMART、测速与实时活动记录会显示删除按钮，确认后直接永久删除，不会转入隐藏记录。
- SMART 快照操作文字精简为“选择文件夹”“保存到历史”和“保存 CSV”。

## 下载、兼容性与安全

- Release 包名：`Capricorn-v2.7.5-macOS.zip`
- App 名称：`Capricorn V2.7.5.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置。
- SAT SMART Driver 是兼容 USB-SATA 设备的可选组件，不会被自动安装或加载。
- Capricorn 只在所选测速文件夹中创建临时文件，不直接写入裸设备。“仅读取”仍可能创建读取准备文件，不能视为零写入模式。
- 写入、混合、循环测速和实时活动大文件负载会产生写入与磨损，请先确认目标和可用空间。
- 历史逐条删除是不可撤销操作，因此默认关闭，并要求二次确认。
