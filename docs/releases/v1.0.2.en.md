# Capricorn V1.0.2 Release Notes

Capricorn V1.0.2 is the first public release organized around the new version naming rule: `Version = 1.0`, `Build = 2`, so the public Display Name is `Capricorn V1.0.2`.

## Download

- Release package: `Capricorn-v1.0.2-macOS.zip`
- App name: `Capricorn V1.0.2.app`
- Requirement: macOS 14.0 or later

On first launch, if macOS Gatekeeper shows an internet-download warning, right-click the app in Finder and choose Open, or allow it from System Settings > Privacy & Security.

## Highlights

- Updated Capricorn naming and version identity, with Display Name composed from `Version + Build`.
- Detects local physical disks, external SSDs, mounted partitions, network volumes, and SD/SDXC memory cards.
- Fixes mounted external partition ownership, so paths such as `/Volumes/40G4T_NTFS_E` map back to the correct external physical disk.
- SMART attributes adapt to the available data source and include stable Chinese explanations.
- Limited SMART sources such as SD/SDXC, network volumes, and USB/NVMe bridges show explicit limited-support messages instead of misleading health details.
- Benchmark page includes Default, Peak/NVMe, RealWorld, Demo, and Custom profiles.
- Custom profiles support up to 4 test groups with SEQ/RND, block size, Q, T, and mixed-test options.
- Each benchmark profile can use a synchronous or POSIX AIO asynchronous engine.
- Benchmark history can save the live disk activity samples captured during the run.
- Live Activity supports independent monitoring, selectable sampling intervals, large-file read/write/mixed workloads, and history saving.
- History supports hiding, managing hidden records, and restoring SMART, benchmark, and live activity records.
- Reports can be exported as JSON, CSV, or plain text, with serial numbers redacted by default.

## Safety Notes

- Capricorn creates temporary files only inside the user-selected target folder. It does not perform raw device writes.
- Write, mixed, loop, and large-file workloads can stress and wear storage devices.
- Before running a test, confirm that the target folder is on the drive you intend to test.
- Network volumes can be benchmarked as mounted folders, but they do not expose local per-disk IOKit activity counters.
- The release asset is packaged from the already-built local app and is not notarized by an automated repository workflow.

## Optional Dependency

Capricorn does not bundle `smartctl`. For deeper ATA/NVMe SMART data, install smartmontools yourself:

```sh
brew install smartmontools
```

Restart or refresh Capricorn after installation.
