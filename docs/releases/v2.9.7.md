# Capricorn V2.9.7

中文发布说明：[v2.9.7.zh-CN.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.7/docs/releases/v2.9.7.zh-CN.md)

## 中文

### 主要更新

- 测速与实时活动的控件在窄窗口中横向滚动，窗口缩放更流畅；小块文件测试效率设置与运行按钮同排显示。
- 实时活动统计块在宽窗口中等宽铺满，在窄窗口中自动换行，读取平均和写入平均一起换行。
- 大文件负载新增启动确认窗口，展示目标位置、负载类型、文件大小、循环设置及写入提醒，并说明开始负载会同时开始监控；系统盘默认使用桌面文件夹。
- 移除实时活动页重复的历史列表，统一在历史页管理；实时活动历史图表显示五个纵轴数据标签。
- 系统盘概览的卷宗列表仅显示一个当前系统卷，其他界面保持不变。

### 下载、兼容性与安全

- Release 包名：`Capricorn-v2.9.7-macOS.zip`；App 名称：`Capricorn V2.9.7.app`。
- 版本元数据：Version `2.9`、Build `7`、显示名 `Capricorn V2.9.7`。
- 需要 macOS 14.0 或更新版本；内置 smartctl 7.5，无需另行安装 smartmontools。可选 SAT SMART 驱动不会自动安装。
- SMART 信息取决于设备和桥接器提供的数据；网络卷不提供全部本地物理磁盘活动数据。
- 测速和大文件负载会在选定文件夹创建临时文件。读取负载也需要先写入源文件；持续写入和循环负载可能带来存储压力与磨损，请确认目标位置并保留重要数据备份。
- 此分发包未执行 Developer ID 签名、公证或 Gatekeeper 信任验证，首次运行可能需要手动允许。

## English

### Highlights

- Benchmark and live-activity controls scroll horizontally in narrow windows with smoother resizing; small-block test efficiency settings sit alongside the run buttons.
- Live-activity metric tiles fill wide windows evenly and wrap in narrow windows, keeping read and write averages together.
- Large-file workloads gain a start confirmation showing the target, operation, file size, loop setting, and write warnings, including that monitoring starts with the workload; system-disk workloads default to Desktop.
- Removes the duplicate live-activity history list and keeps record management in History, with five vertical-axis labels on activity-history charts.
- The system-disk overview lists only the current system volume without changing other pages.

### Download, Compatibility, and Safety

- Package: `Capricorn-v2.9.7-macOS.zip`; App: `Capricorn V2.9.7.app`.
- Bundle metadata: Version `2.9`, Build `7`, display name `Capricorn V2.9.7`.
- macOS 14.0 or later; smartctl 7.5 is bundled, so smartmontools need not be installed separately. The optional SAT SMART driver is not installed automatically.
- SMART information depends on the device and bridge; network volumes do not provide all local physical-disk activity data.
- Benchmarks and large-file workloads create temporary files in the selected folder. Read workloads also write source files before reading; sustained writes and loops can cause storage stress and wear. Verify the target and keep important backups.
- This distribution is not Developer ID signed, notarized, or Gatekeeper-trust verified; manual approval may be required on first launch.
