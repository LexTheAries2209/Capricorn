## 中文

Capricorn V1.0.5 使用 `Version = 1.0`、`Build = 5` 和 Display Name `Capricorn V1.0.5`。本版解决了测速卡顿问题，并新增安全受限的磁盘“急救”流程。

### 下载

- Release 包名：`Capricorn-v1.0.5-macOS.zip`
- App 名称：`Capricorn V1.0.5.app`
- 系统要求：macOS 14.0 或更新版本

### 重点更新

- 修复测速取消、立即重启和晚到回调导致的界面卡顿，停止后等待真实清理完成。
- 右键“急救…”支持外接或可移除 APFS/ExFAT 卷的预检、逐卷选择、占用程序检查、串行修复和实时输出。
- 每个卷开始前重新验证设备标识、UUID、父物理盘、格式、可写与锁定状态。
- SMART 故障、系统/内置盘、网络/虚拟盘、只读/锁定卷和 NTFS 均不会执行直接修复。
- NTFS 仅提供 Windows CHKDSK 指引；系统盘提供磁盘工具与恢复模式说明。
- 不包含 `repairDisk`、擦除、分区、直接 `fsck -y`、强制卸载、`sudo` 或管理员 Helper。
- 完整测试连续 5 次通过，每次 122 项；严格并发、Swift 6 兼容和启动验证通过。

### 发布校验

- 通用架构：arm64 + x86_64
- ZIP SHA-256：`f590dc458837745cb060ba2afb6df3e9d793948ac167b050435657271a1cdd7d`
- App 使用 Apple Development 证书与 hardened runtime，但本机信任评估返回 `CSSMERR_TP_NOT_TRUSTED`；不声明为已公证。

## English

Capricorn V1.0.5 uses `Version = 1.0`, `Build = 5`, and the Display Name `Capricorn V1.0.5`. This release fixes benchmark UI stalls and adds a safety-limited disk First Aid workflow.

### Download

- Release package: `Capricorn-v1.0.5-macOS.zip`
- App name: `Capricorn V1.0.5.app`
- Requirement: macOS 14.0 or later

### Highlights

- Fixes benchmark UI stalls caused by cancellation, immediate restart, and late callbacks, while waiting for real cleanup before a new run.
- Adds “First Aid…” for explicitly selected external or removable APFS/ExFAT volumes with preflight checks, open-file inspection, serial repair, and live output.
- Revalidates device identity, UUID, parent disk, format, writable state, and locked state before each target starts.
- SMART failures, system/internal disks, network/virtual volumes, read-only/locked volumes, and NTFS never enter direct repair.
- NTFS shows Windows CHKDSK guidance; system disks show Disk Utility and macOS Recovery guidance.
- No `repairDisk`, erase, partition, direct `fsck -y`, force-unmount, `sudo`, or privileged helper capability is included.
- Five consecutive full test runs passed with 122 tests each; strict concurrency, Swift 6 compatibility, and launch verification also passed.

### Release Verification

- Universal architectures: arm64 + x86_64
- ZIP SHA-256: `f590dc458837745cb060ba2afb6df3e9d793948ac167b050435657271a1cdd7d`
- The App uses an Apple Development certificate with hardened runtime, but local trust evaluation returns `CSSMERR_TP_NOT_TRUSTED`; it is not presented as notarized.
