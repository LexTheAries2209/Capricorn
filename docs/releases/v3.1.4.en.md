# Capricorn V3.1.4

Release date: November 2, 2026. Complete Version `3.1.4`, Build `0054`.
Build is an independent, globally increasing four-digit release-build sequence and is not appended to the version.

## Changes

- Adds horizontal scrolling and bounded column resizing to the SMART table, with a resizable Source column and accessible information after restoring the window.
- Reduces Source's default width by 30% and gives that space to ID; Status stays at a compact fixed width.

## Installation And Safety

Download `Capricorn-v3.1.4-macOS.zip` and install the stable-name `Capricorn.app`. Requires macOS 14.0 or later; includes arm64/x86_64. V2.10.2 and later support in-app upgrades; earlier versions and old development Build `1000` require manual installation.

Enable the privileged device service in Settings and complete system approval. `/Applications` is recommended; other permanent folders on local, writable, non-removable disks are supported. Disable the service before manually moving or replacing the app. In-app updates attempt to restore a previously enabled service; macOS may require renewed approval.

Each SNT read still requires confirmation before unmounting every volume on the USB device. Close files, finish other disk tasks, and back up important data first. Mount restoration is attempted afterward; failure may require reconnecting the device or using Disk Utility. Disks are never force-unmounted and occupying processes are not terminated. Background scans never initiate USB capture; macOS manages removable-volume privacy consent separately.

Compatibility depends on the bridge, firmware and device; not every USB device is supported, and general SD-card health queries are not provided. This release changes the UI. No real SNT capture, volume unmount, or hardware self-test was performed.

smartctl 7.5 is bundled; SAT SMART Drive is optional. Benchmarks and workloads use temporary files in the selected folder, and write tests can stress storage.

## Verification And Source

Full suite: 724 tests, 721 passed, 3 skipped, 0 failed. Skips cover two opt-in hardware checks and the certificate-only check on the unsigned test host. SMART table checks in both languages cover default width redistribution, fixed Status width, Source resizing, horizontal scrolling and window resizing. Strict concurrency and Swift 6 builds passed. Twenty real Sparkle fixture scenarios passed.

Universal archive, archived app launch, an independent universal Release build of the archived source, both architectures for the app/service/tools, complete signatures and dSYM UUID checks passed.

Package and feed Ed25519 signatures passed verification. Real Sparkle staging-feed checks confirmed that Build `0053` discovers `3.1.4 / 0054` and Build `0054` reports no update. The package is 14,501,067 bytes, with SHA-256 `933d92056e31f52a4a2fc03c72ce3ee35dc16eb85877949656e90eb52375d1f5`.

The app, service and tools use same-team Apple Development certificate signatures; updates use the existing Ed25519 key. Developer ID and Apple notarization are not established.

Installation regressions use isolated fixture apps, history and preferences. The service-handoff scenario uses a mock coordinator; it does not establish real root-service upgrades or retained system approval. Intel, macOS 14, and certificate trust and service approval on other Macs require separate validation.
