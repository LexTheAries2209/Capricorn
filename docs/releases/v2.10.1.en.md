# Capricorn V2.10.1

Release date: 2026-10-17

## Highlights

- Read SMART error entries and open an available report with one click. Missing details are identified clearly, without presenting historical errors as an empty log.
- Adds Show Error Entry Reader in Settings, off by default, to show or hide the error-entry section separately.
- Removes the diagnostics summary row and places the collapse button beside its title, with clearer settings descriptions, aligned labels, and complete error explanations.

## Download, Compatibility, and Safety

- Download: [Capricorn-v2.10.1-macOS.zip](https://github.com/LexTheAries2209/Capricorn/releases/download/v2.10.1/Capricorn-v2.10.1-macOS.zip).
- App: `Capricorn V2.10.1.app`; Version `2.10`, Build `1`, display name `Capricorn V2.10.1`.
- macOS 14.0 or later; smartctl 7.5 is bundled, so smartmontools need not be installed separately. The optional SAT SMART driver is not installed automatically.
- Reading error entries does not write to controller logs. Available data depends on the device, bridge, and macOS support; a historical error count alone does not establish media failure.
- Benchmarks and large-file workloads create temporary files, including source files for read workloads. Sustained writes may cause storage stress and wear. Verify the target and keep important backups.
- The GitHub distribution is not Developer ID signed, notarized, or Gatekeeper-trust verified; manual approval may be required on first launch. Apple Development signing in the local run script does not establish public distribution trust.
