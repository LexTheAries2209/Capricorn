# Capricorn V2.10.5

Release date: October 18, 2026.

## Version And Installation

- Complete Version `2.10.5`, Build `0045`. Build is an independent, globally increasing four-digit release-build sequence and is not appended to the version.
- Download `Capricorn-v2.10.5-macOS.zip` and install the fixed-name `Capricorn.app`.
- V2.10.2 and later support in-app upgrades; earlier versions and old development Build `1000` require manual installation.
- Requires macOS 14.0 or later; includes arm64 and x86_64.

## Highlights

- Adds Stop to finish the active benchmark pass, calculate results, and skip remaining tests and custom loops. Cancel still ends immediately without counting the current unfinished test.
- Simplifies custom benchmark groups, labels the mixed toggle “Read/Write Mix”, and retains the four-group limit.
- Marks virtual-disk entry points Beta. Health defaults to automatic calculation with a manual override. Adds built-in system-disk simulation, CFast 2.0, network and SD media, and 512 B / 4 KB sectors.
- Places partition name, type, capacity and used capacity on separate rows, aligns the type picker to the trailing edge, and gives each capacity field independent units. Default virtual-disk names are numbered.
- Defaults first launch to Simplified Chinese while preserving saved choices. Renames Pre-Fail to Error with existing history compatibility and gives network and virtual disks dedicated icons.
- Adds “Automatically download and install updates” under Developer Options, off by default.

## Updates And Safety

Checks on launch default to off, preserve the saved choice, and end after 15 seconds without a result. Developer automatic updates default to off; otherwise users confirm downloads and installation. Disabling Developer Options suspends automatic updates. Disabling automatic updates during download restores manual installation confirmation after preparation. Conflicting tasks or failed history saves block installation.

Downloads follow system proxy settings. The feed and archive use the existing Ed25519 key. The App has valid ad-hoc signatures without Developer ID or Apple notarization; first launch may require manual approval. smartctl 7.5 is bundled. Verify benchmark/write targets and back up important data.

Installation regressions use isolated fixture history and preferences, not the actual user App or database, and do not establish Intel or macOS 14 installation behavior.
