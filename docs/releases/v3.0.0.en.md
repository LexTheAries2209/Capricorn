# Capricorn V3.0.0

Release date: October 30, 2026

Complete Version `3.0.0`, Build `0049`. Build is an independent, globally increasing four-digit release-build sequence and is not appended to the version.

## Highlights

- Adds experimental manual USB-NVMe SNT SMART reads with automatic bridge protocol selection and volume restoration attempts.
- Adds SMART-page guidance and a context-menu SNT refresh action, displays retrieved serial numbers, and retains manual read results.
- Distinguishes physical device capacity from volume capacity and clarifies USB SMART sources and read status.

## Installation And Compatibility

Download `Capricorn-v3.0.0-macOS.zip` and install `Capricorn.app`. Requires macOS 14.0 or later, with an arm64 / x86_64 universal App. V2.10.2 and later support in-app updates; earlier versions or old development Build `1000` require manual installation.

Ordinary SMART reads continue using bundled smartctl 7.5. A separate experimental SNT tool supports JMicron, ASMedia, and Realtek USB-NVMe bridge protocols. Compatibility with every bridge, firmware, or memory card is not guaranteed; this does not provide general SD-card health queries.

SNT runs only after manual confirmation, requires administrator authorization, and temporarily unmounts all volumes on the USB device. Close related files, finish other disk operations, and back up important data first. The App releases the device and attempts to restore its original mounts. If restoration fails, reconnect the device or use Disk Utility. Ordinary automatic refresh never initiates USB capture.

The App does not automatically install SAT SMART Drive. Benchmarks and workloads use temporary files in the selected folder; verify the target and keep backups.

The App uses valid ad-hoc signatures, and the archive and feed use the existing Ed25519 key. Developer ID and Apple notarization are not established.
