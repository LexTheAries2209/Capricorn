# Capricorn V2.10.3

Release date: October 17, 2026.

## Version And Installation

- Complete Version `2.10.3`, Build `0043`. Build is an independent, globally increasing four-digit release-build sequence and is not appended to the version.
- Download `Capricorn-v2.10.3-macOS.zip` and install the fixed-name `Capricorn.app`.
- V2.10.2 supports in-app upgrades. V2.10.1 and earlier, and old development Build `1000`, require manual installation.
- Requires macOS 14.0 or later; includes arm64 and x86_64.

## Highlights

- Unifies update progress, results, and errors in compact localized prompts with centered content and sentence-aware line breaks.
- Ends unanswered launch checks after 15 seconds until the next launch or manual retry; fixes lingering spinners and unresponsive confirmation buttons.
- Uses the settings title “Settings - Capricorn V2.10.3” and places update status at the bottom of the update section.
- Adds a third-party license window in the application menu and Settings for the complete Sparkle and smartctl notices.

## Updates And Safety

Checks on launch and automatic downloads are off by default and preserve saved choices. The 15-second limit applies to launch checks, not update downloads or installation already underway. Conflicting disk tasks still block updates, and history is saved before installation.

Downloads follow system proxy settings. The feed and archive are verified with the existing Ed25519 key. The App is ad-hoc signed without Developer ID or Apple notarization; first launch may require manual approval.

Replacing the App does not clear SwiftData history in the application data directory. Installation regressions use isolated fixture history and preferences, not the actual user database. smartctl 7.5 is bundled. Disk writes and large-file workloads still require target verification and backups.
