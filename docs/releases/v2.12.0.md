## 中文

- 新增共享硬盘连接拓扑，查看 USB、雷雳、PCIe 的连接路径、链路速率与芯片信息。点击硬盘切换侧边栏及详情，点击机身选择系统盘。
- 支持拖动节点、触控板缩放和平移。M 打开拓扑，- / = 缩放，Z 重新整理并自适应显示。
- 增加 Mac 机型和端口视图，桌面机型可选择前后连接接口；常见 Intel、ASMedia、VIA 和 SSD 主控名称随本地数据库提供，无需联网查询。

下载 `Capricorn-v2.12.0-macOS.zip` 并安装 `Capricorn.app`。V2.10.2 及以后支持应用内更新；更早版本或旧开发 Build `1000` 需手动安装。

拓扑显示系统报告的连接信息；链路速率不等于硬盘实测传输速度，未知芯片保留原始标识。系统盘通过本机节点选择。启动检查和开发者自动更新默认关闭，下载及安装保留任务保护。内置 smartctl 7.5，可选 SAT SMART Drive 按需配置。测速及负载使用选定文件夹中的临时文件，请确认目标并备份重要数据。

App 使用有效 ad-hoc 签名，更新包及清单使用既有 Ed25519 密钥，没有 Developer ID 或 Apple 公证。

## English

- Adds shared storage topology for USB, Thunderbolt, and PCIe paths, link rates, and chip information. Select a disk to update the sidebar and details, or select the computer for the system disk.
- Supports draggable nodes and trackpad zoom and pan. M opens topology, - / = zoom, and Z rearranges and fits the graph.
- Adds Mac model and port views, with front and rear socket selection for desktop models. Common Intel, ASMedia, VIA, and SSD controller names are bundled locally without online lookups.

Download `Capricorn-v2.12.0-macOS.zip` and install `Capricorn.app`. V2.10.2 and later support in-app upgrades; earlier versions or old development Build `1000` require manual installation.

Topology uses connection information reported by the system. Link rates are not measured disk throughput, and unknown chips retain their original identifiers. The computer node represents system storage. Launch checks and developer automatic updates default to off, with task protection retained for downloads and installation. smartctl 7.5 is bundled; SAT SMART Drive is optional. Benchmarks and workloads use temporary files in the selected folder. Verify targets and back up important data.

The App uses valid ad-hoc signatures, and the archive and feed use the existing Ed25519 key. Developer ID and Apple notarization are not established.
