# Capricorn V2.4.0 Release Notes

Release date: 2026-09-02

Capricorn V2.4.0 uses `Version = 2.4`, `Build = 0`, and the display name `Capricorn V2.4.0`.

## Highlights

- Bundles pinned smartmontools 7.5 with universal `arm64`/`x86_64` `smartctl`, `drivedb.h`, and the GPL license. The matching source archive, hash, and reproducible build script are included in the repository.
- Uses the bundled tool by default instead of searching PATH or Homebrew. A non-empty Settings path is treated only as an explicit external override, with source, version, database version, and compatibility shown.
- Consolidates external SMART support, ATA SMART options, and SAT driver diagnostics in Settings while retaining the open-source project link. Capricorn does not install or remove kernel extensions automatically.
- Makes the SMART attribute table independently scrollable and adaptive to the available UI height. After removing the external SMART module, the SMART information area fills the content region.
- Serializes SMART queries and self-test commands for the same drive to avoid concurrent access.
- Improves WD Elements Portable 5TB and related external-drive model and volume identification rules.

## Download And Compatibility

- Release package: `Capricorn-v2.4.0-macOS.zip`
- App name: `Capricorn V2.4.0.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
- SAT SMART Driver, Homebrew, and other external tools remain optional. External tools are used only when explicitly selected in Settings.

## Data And Safety Notes

- SMART visibility depends on macOS, the device protocol, and USB bridge capabilities. SAT applies to SATA/ATA pass-through devices; NVMe-over-USB devices may not expose SMART.
- Capricorn does not fabricate SMART attributes when a bridge does not provide pass-through, and it does not lower macOS security settings to install a KEXT automatically.
- Benchmark, write, repair, and self-test operations continue to use target confirmation, system-disk protection, and device-capability checks.
