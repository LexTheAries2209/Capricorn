# Capricorn V2.9.2

中文发布说明：[v2.9.2.zh-CN.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.2/docs/releases/v2.9.2.zh-CN.md)

English release notes: [v2.9.2.en.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.2/docs/releases/v2.9.2.en.md)

发布日期 / Release date: 2026-09-28

This maintenance release expands the local physical-drive model catalog and corrects an inconsistent SMART self-test completion display. The bundled smartctl remains 7.5; the drive-model catalog is a Capricorn resource, not an upstream smartmontools database update.

本次维护版扩充本地物理硬盘型号数据库，并修复 SMART 自检完成状态的显示不一致。内置 smartctl 仍为 7.5；此次更新的是 Capricorn 的硬盘型号资源，不是上游 smartmontools 数据库升级。

## 中文

Capricorn V2.9.2 使用 `Version = 2.9`、`Build = 2` 和 Display Name `Capricorn V2.9.2`。

### 主要更新

- 扩充硬盘型号规则，识别更多 Seagate BarraCuda 2.5 英寸、Portable、Expansion Portable、Backup Plus、One Touch、Ultra Touch，以及 LaCie Mobile Drive、Rugged Mini。加入独立产品名称显示，并优先匹配更具体的 USB 设备身份、容量范围和固定容量规则，避免泛化规则盖过外置硬盘盒型号。
- 修正 SMART 自检状态：明确的设备通过/完成状态优先于剩余百分比；剩余百分比为 0 的已通过记录不再被误显示为“进行中”。历史详情只有终态才显示“已完成”，非终态标记为“读取时间”。
- 现场以只读 `smartctl` 检查一块 `ST5000LM000-2U8170`：短自检日志报告 `Completed without error`，通电 442 小时，检查时没有进行中的选择性自检。此验证不代表所有桥接芯片、机型或新规则都已实盘覆盖。

### 下载、兼容性与安全

- Release 包名：`Capricorn-v2.9.2-macOS.zip`；App 名称：`Capricorn V2.9.2.app`。
- 系统要求：macOS 14.0 或更新版本；App 内置 smartctl 7.5，部分 USB 外壳可能无法传递 SMART/自检命令。
- 型号识别是显示辅助信息，不改变设备固件或盘上数据；自检状态的改动仅修复读取与显示，不会自动触发新的硬件自检。重要数据仍应保持备份。
- 此分发包未经过 Developer ID 签名、公证或 Gatekeeper 信任验证；首次启动可能需要用户手动允许。

### 验证

- 完整 macOS 测试：343 项通过、0 失败；严格并发警告视为错误构建、Swift 6 兼容构建及 Release Archive 成功。Swift 6 检查仍有一条既有 `init(cString:)` 弃用警告。

## English

Capricorn V2.9.2 uses `Version = 2.9`, `Build = 2`, and display name `Capricorn V2.9.2`.

### Highlights

- Expands physical-drive model rules for Seagate BarraCuda 2.5-inch, Portable, Expansion Portable, Backup Plus, One Touch and Ultra Touch, and LaCie Mobile Drive and Rugged Mini. Distinct product names and more-specific USB identity, capacity range, and fixed-capacity matches prevent generic rules from overriding enclosure identification.
- Prioritizes explicit device pass/completion status over remaining progress, so a passed test with zero remaining is not shown as running. Self-test history shows completion time only for terminal records and capture time for nonterminal records.
- A read-only `smartctl` check of a connected `ST5000LM000-2U8170` reported `Completed without error` for a short test at 442 power-on hours and no selective test in progress. This is not field validation for all bridges, models, or new catalog rules.

### Download, Compatibility, and Safety

- Release package: `Capricorn-v2.9.2-macOS.zip`; App: `Capricorn V2.9.2.app`.
- Requires macOS 14.0 or later. Bundles smartctl 7.5; some USB bridges do not pass SMART/self-test commands.
- Model identification changes display data, not device firmware or disk contents. The status fix reads and displays existing self-test results; it does not automatically start a test. Maintain backups of important data.
- This package is not Developer ID signed, notarized, or Gatekeeper-trust verified; first launch may require manual approval.

- The archived App reports Version 2.9, Build 2, display name Capricorn V2.9.2 and minimum macOS 14.0. Its arm64/x86_64 executable UUIDs match the dSYM, the shipped drive-model catalog matches the source byte-for-byte, and smartctl 7.5, drivedb.h and SATSMARTDriver resources are present.
- ZIP size: 9,643,713 bytes; SHA-256: `cb909648d02aa62a3cb6bca0f7460aa3dde3e7fd11873ad74ad1524bad81103b`; `unzip -t` found no errors.
