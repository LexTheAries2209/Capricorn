# Capricorn V2.8.0 中文发布说明

发布日期：2026-09-21

双语发布说明：[v2.8.0.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.8.0/docs/releases/v2.8.0.md)

Capricorn V2.8.0 使用 `Version = 2.8`、`Build = 0` 和 Display Name `Capricorn V2.8.0`。

## 主要更新

- 新增跨进程物理硬盘操作锁，开发版与正式版共享同一锁命名空间，避免多个 Capricorn 实例同时对同一物理硬盘执行互斥操作。
- 测速、实时活动大文件负载、SMART 自检、磁盘检查与急救、装载、卸载、推出、重命名和网络卷断开均在实际执行前检查冲突。
- 检测到冲突时会弹窗显示正在运行的操作与进程，本次操作不会继续。只读监控本身不占用互斥锁。
- 硬盘锁只协调 Capricorn，不锁定 macOS 设备节点，也不阻止 Finder、其他测速工具或系统服务访问硬盘。
- 保留现有 runID，当前任务只清理自己的临时文件，不会全局删除其他运行目录。
- 新任务开始前只清理超过一小时、没有活跃租约且能确认属于 Capricorn 的崩溃残留；无法确认时会保留文件。
- 正常退出、强制结束或系统崩溃后，操作系统都会释放进程持有的文件锁，不会形成永久硬盘锁。
