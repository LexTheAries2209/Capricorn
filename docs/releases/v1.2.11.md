## 中文

Capricorn V1.2.11 使用 `Version = 1.2`、`Build = 11` 和 Display Name `Capricorn V1.2.11`。本版汇总 V1.2.10 之后的改进，重点整理外接磁盘 SMART 支持诊断，并移除应用菜单中重复的设置入口。

### 下载

- Release 包名：`Capricorn-v1.2.11-macOS.zip`
- App 名称：`Capricorn V1.2.11.app`
- 系统要求：macOS 14.0 或更新版本

### V1.2.10 以来的重点更新

- SMART 页面对每个本地物理磁盘保留“外接磁盘 SMART”支持区。内置磁盘以及同时检测到 smartctl 和 SAT SMART Driver 的磁盘默认折叠，缺少依赖或尚未验证的外接磁盘默认展开；网络磁盘和存储卡继续隐藏不适用的支持区。
- 原“smartctl 诊断”更名为“驱动诊断”，在同一区域集中显示 smartctl 版本、硬盘数据库、smartctl 目标路径、设备类型、协议、电源状态、打开错误和 SAT SMART Driver 路径。
- SAT 驱动路径标题明确为“SAT SMART Driver 路径”，避免与 smartctl 的目标路径混淆。未检测到驱动时提供 OS-X-SAT-SMART-Driver 开源项目仓库入口，已检测到驱动后不再显示重复的安装或重连说明。
- 应用菜单删除了额外的中文“设置”命令，只保留 macOS 系统 `Settings…` 项，并将其快捷键映射为 `Command-P`。
- 补充外接 SMART 支持区显示、默认展开策略、SAT 驱动路径文案和设置快捷键的单元测试。

### 安全与限制

- “目标路径”表示 smartctl 为当前磁盘解析出的诊断目标，可能是 IOKit 服务路径或设备路径；它不是 SAT SMART Driver 的安装位置。SAT 驱动安装位置在“SAT SMART Driver 路径”中单独显示。
- 支持区保持可见只代表用户可以检查依赖和诊断信息，不代表 macOS、桥接芯片或当前设备一定能够提供 SMART 数据。
- Capricorn 不捆绑 smartctl，也不会自动下载、安装或卸载 SAT 内核扩展；开源项目链接仅用于引导用户查看来源和安装说明。

## English

Capricorn V1.2.11 uses `Version = 1.2`, `Build = 11`, and Display Name `Capricorn V1.2.11`. This release collects the changes since V1.2.10, focusing on clearer external-drive SMART support diagnostics and removal of the duplicate Settings command.

### Download

- Release package: `Capricorn-v1.2.11-macOS.zip`
- App name: `Capricorn V1.2.11.app`
- Requirement: macOS 14.0 or later

### Highlights Since V1.2.10

- The SMART page keeps the External Drive SMART support section available for every local physical drive. It starts collapsed for internal drives and drives where both smartctl and SAT SMART Driver are detected, and starts expanded for external drives with missing or unverified support. Network drives and memory cards still hide this inapplicable section.
- The former smartctl Diagnostics panel is now Driver Diagnostics. It groups the smartctl version, drive database, smartctl target path, device type, protocol, power mode, open errors, and SAT SMART Driver paths in one place.
- The path heading is now explicitly SAT SMART Driver Paths so it cannot be confused with the smartctl target path. A missing driver shows a link to the OS-X-SAT-SMART-Driver open-source repository, while a detected driver no longer shows redundant installation or reconnect guidance.
- The application menu removes the extra localized Settings command, keeps only the system `Settings…` item, and maps it to `Command-P`.
- Unit coverage now includes external SMART section visibility and expansion policy, the SAT driver path label, and the Settings shortcut.

### Safety And Limitations

- Target Path is the diagnostic target resolved by smartctl for the current disk, such as an IOKit service path or device path. It is not the SAT SMART Driver installation location, which appears separately under SAT SMART Driver Paths.
- Keeping the support section accessible means users can inspect dependencies and diagnostics. It does not imply that macOS, the bridge chipset, or the current device can expose SMART data.
- Capricorn does not bundle smartctl or automatically download, install, or remove SAT kernel extensions. The open-source project link only directs users to upstream source and installation information.
