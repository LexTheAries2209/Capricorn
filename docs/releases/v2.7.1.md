# Capricorn V2.7.1

中文发布说明：[v2.7.1.zh-CN.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.1/docs/releases/v2.7.1.zh-CN.md)

发布日期 / Release date: 2026-09-17

本版完善 SAT SMART Drive 的状态判断与引导，并为设置加入不受输入法影响的反引号/波浪号键快捷键。

This release refines SAT SMART Drive status and guidance, and adds an input-source-independent grave/tilde key shortcut for Settings.

## 中文

Capricorn V2.7.1 使用 `Version = 2.7`、`Build = 1` 和 Display Name `Capricorn V2.7.1`。

### 主要更新

- SAT SMART Driver 的绿色状态现在只取决于驱动文件是否安装并已加载，不再要求当前连接的外置设备触发 IOKit 匹配。
- 符合条件的 USB-SATA 设备在 SMART 数据不可用时会始终显示 SAT 引导，并从设置中移除对应开关。
- 设置中的安装操作改名为“安装 SAT SMART Drive”，继续打开 App 内置安装包供用户确认安装。
- 物理反引号/波浪号键现在可在不同输入法下打开设置；应用菜单显示该快捷键，左下角设置入口仍保留设置图标、版本号和 macOS 用户名。

### 下载与兼容性

- Release 包名：`Capricorn-v2.7.1-macOS.zip`
- App 名称：`Capricorn V2.7.1.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。
- SAT SMART Driver 仅是兼容 USB-SATA 设备的可选组件。Capricorn 不会自动安装或加载驱动，也不会修改系统安全设置。

### 验证

- 完整 macOS 测试：303 项通过，0 失败。
- Release 构建和 Archive 均成功；App 元数据、内置 smartctl/SAT 资源和 arm64/x86_64 通用架构均已检查。
- 严格并发构建和 Swift 6 兼容性构建通过；Swift 6 生产代码仅报告已有的 `String(cString:)` 弃用警告。
- 发布包大小：9,339,002 字节；SHA-256：`deae0bd8293f7eac4b5c543d7c725cab5f7d37312366b546a228123bc6ca4b68`；`unzip -t` 通过。
- 发布包仅保留链接器生成的 ad-hoc 签名，未执行 Developer ID 签名、公证或 Gatekeeper 信任验证；首次打开可能需要手动允许。

## English

Capricorn V2.7.1 uses `Version = 2.7`, `Build = 1`, and the display name `Capricorn V2.7.1`.

### Highlights

- The green SAT SMART Driver state now depends only on the driver files being installed and loaded, without requiring a currently attached external device to trigger an IOKit match.
- SAT guidance is now always enabled for eligible USB-SATA devices when SMART data is unavailable, and the corresponding Settings toggle has been removed.
- The Settings action is renamed to Install SAT SMART Drive and continues to reveal the bundled installer for user-confirmed installation.
- The physical grave/tilde key now opens Settings across input sources. The application menu shows the shortcut, while the lower-left Settings row retains its icon, version, and macOS user name.

### Download And Compatibility

- Release package: `Capricorn-v2.7.1-macOS.zip`
- App name: `Capricorn V2.7.1.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
- SAT SMART Driver remains optional for compatible USB-SATA devices. Capricorn does not install or load it automatically or change system security settings.

### Verification

- Full macOS test suite: 303 tests passed, 0 failures.
- Release build and Archive succeeded; App metadata, bundled smartctl/SAT resources, and arm64/x86_64 universal architecture were checked.
- Strict-concurrency and Swift 6 compatibility builds passed; the Swift 6 production build reported only the existing `String(cString:)` deprecation warning.
- Package size: 9,339,002 bytes; SHA-256: `deae0bd8293f7eac4b5c543d7c725cab5f7d37312366b546a228123bc6ca4b68`; `unzip -t` passed.
- The package retains only the linker-generated ad-hoc signature. Developer ID signing, notarization, and Gatekeeper trust verification were not performed; macOS may require manual approval on first launch.
