# Capricorn V2.3.2 Release Notes

Release date: 2026-08-31

Capricorn V2.3.2 uses `Version = 2.3`, `Build = 2`, and the display name `Capricorn V2.3.2`.

## Highlights

- Added ARRI Codex recording-media identification for the Codex Compact Drive, Compact Drive Express, and SXR Capture Drive families, including models such as `CDXCDC0192M300N40A`.
- Fixed mounted UDF media that can be omitted from `diskutil list`: when device information contains a mount point, Capricorn now recovers the real volume name, capacity, read-only state, volume UUID, and filesystem type.
- Sidebar and volume-aware actions now use the actual mounted volume name and report `UDF` instead of falling back to the drive model as a volume name.

## Download And Compatibility

- Release package: `Capricorn-v2.3.2-macOS.zip`
- App name: `Capricorn V2.3.2.app`
- System requirement: macOS 14.0 or later
- Optional dependencies: user-installed smartmontools (`smartctl`) and SAT SMART Driver
- This release is not Developer ID signed or notarized. On first launch, macOS may require Finder > Open or approval in System Settings > Privacy & Security.

## Data Notes

- Volume names and filesystem types come from macOS `diskutil` device metadata. Capricorn does not infer a volume name from a drive model or turn an unmounted volume into an actionable target.
- Benchmark, write, and repair actions continue to use the existing target-volume protections and confirmation flow.
