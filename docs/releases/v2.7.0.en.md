# Capricorn V2.7.0 English Release Notes

Release date: 2026-09-17

Bilingual release notes: [v2.7.0.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.0/docs/releases/v2.7.0.md)

Capricorn V2.7.0 uses `Version = 2.7`, `Build = 0`, and the display name `Capricorn V2.7.0`.

## Highlights

- Reworks the sidebar status area with pinned drive-health and refresh rows, the three latest deduplicated activities with local timestamps, and content-driven height up to five rows.
- SMART reads, drive scans, open-file inspection, and disk actions now replace in-progress messages with completion states. Mount is disabled for already-mounted volumes.
- Moves the version and macOS user name onto the Settings row, completes identity/status/SD-card localization, and aligns the language control with the refresh action.
- Hides SMART error entries for system disks, diagnostics for devices without SMART attributes and network volumes, and Quick Disk Check for network volumes. Network titles prefer a host name or address, and missing serial numbers display as None.
- Shows contextual SAT SMART Drive guidance and a Settings deep link only for eligible USB storage devices that return no SMART data. Network, SD, internal, and SMART-capable devices do not trigger it.
- Adds volume-UUID fallback matching for Quick Disk Check history, hides self-test reports while SMART attributes are unavailable and restores them when capability returns, and makes History and saved benchmark charts adaptive to window width.

## Download And Compatibility

- Release package: `Capricorn-v2.7.0-macOS.zip`
- App name: `Capricorn V2.7.0.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled.
- SAT SMART Driver is optional for compatible USB-SATA devices and is never installed or loaded automatically.
- A SMART-unavailable state means that the current interface provides no readable data; it does not by itself indicate hardware failure.
