# Capricorn V2.10.1

发布日期：2026-10-17

## 主要更新

- SMART 错误条目可一次点击读取并直接打开可用报告；无法获取详情时明确提示，历史错误不会显示为没有错误。
- 设置新增默认关闭的“显示读取错误条目”，可单独显示或隐藏错误条目模块。
- SMART 诊断区移除简介行，收起按钮与标题同排；完善设置介绍、左对齐和错误说明的完整显示。

## 下载、兼容性与安全

- 下载：[Capricorn-v2.10.1-macOS.zip](https://github.com/LexTheAries2209/Capricorn/releases/download/v2.10.1/Capricorn-v2.10.1-macOS.zip)。
- App：`Capricorn V2.10.1.app`；Version `2.10`、Build `1`、显示名 `Capricorn V2.10.1`。
- 需要 macOS 14.0 或更新版本；内置 smartctl 7.5，无需另行安装 smartmontools。可选 SAT SMART 驱动不会自动安装。
- 错误条目读取不会写入控制器日志。可获取的数据取决于设备、桥接器与 macOS 支持，历史错误计数本身不代表介质损坏。
- 测速和大文件负载会创建临时文件，读取负载也需要先写入源文件；持续写入可能造成压力与磨损。请确认目标位置并保留重要数据备份。
- GitHub 分发包未执行 Developer ID 签名、公证或 Gatekeeper 信任验证，首次运行可能需要手动允许。本地脚本的 Apple Development 签名不适用于公开分发信任。
