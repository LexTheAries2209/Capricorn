# Capricorn V2.5.0 发布说明

发布日期：2026-09-08

Capricorn V2.5.0 使用 `Version = 2.5`、`Build = 0`，Display Name 为 `Capricorn V2.5.0`。

## 主要更新

- 新增 SMART 诊断界面：支持设备自检状态、快速/完整自检、历史记录、错误条目读取与导出，并根据设备能力和权限显示可用操作。
- SMART 温度和错误日志条目改为独立提示：温度沿用 `70–85 °C` 警告、`85 °C` 及以上错误，错误日志条目也保留单项提示，但两者都不会改变整个 SMART 健康等级。
- macOS 无法通过 smartctl 发送 NVMe 自检命令 `0x14` 时，界面显示灰色的“无法完成自检”状态，并提供本地化说明，不再误报为自检状态未知。
- 概览新增与右键菜单一致的快速自检入口；快速自检报告会按硬盘身份保存，系统盘在运行前要求先在设置中允许检查，设置界面支持 Escape 关闭。
- 修复 SMART 诊断视图和测试目标配置导致的编译问题，并补充错误日志、温度、系统盘权限和自检历史测试。

## 下载与兼容性

- Release 包名：`Capricorn-v2.5.0-macOS.zip`
- App 名称：`Capricorn V2.5.0.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。

## 数据与安全提示

- 快速自检和 SMART 硬件自检是不同功能；系统盘自检受设置中的单独权限开关保护。
- macOS 上的 smartctl 无法发送 NVMe 自检命令 `0x14` 时，Capricorn 不会伪造自检结果。
- Capricorn 不会自动安装或卸载内核扩展，也不会自动搜索或使用 PATH/Homebrew 中的外部 smartctl。
- 测速、写入、修复和自检操作继续遵循目标确认、系统盘保护和设备能力检查。
