# Capricorn V1.0.3

## 中文

Capricorn V1.0.3 继续沿用 `Version = 1.0`、`Build = 3` 的版本命名原则，因此 Display Name 显示为 `Capricorn V1.0.3`。本版重点增强磁盘右键操作、系统盘保护、占用程序诊断、只读检查日志和界面快捷操作。

### 下载

- Release 包名：`Capricorn-v1.0.3-macOS.zip`
- App 名称：`Capricorn V1.0.3.app`
- 系统要求：macOS 14.0 或更新版本

### 重点更新

- 在磁盘侧边栏加入右键磁盘操作菜单。
- 支持装载、卸载、强制卸载、推出、重命名卷宗、在 Finder 中显示、刷新和网络卷断开等操作。
- 加入系统内置盘保护，避免从 Capricorn 对系统盘执行装载、卸载、强制卸载或推出。
- 加入“查看占用程序”，可列出当前在所选磁盘上打开文件的进程。
- 卸载、推出等操作失败时，会显示失败原因和可能占用磁盘的进程列表，并可继续执行强制卸载。
- 加入“检查日志”和“详细检查”，展示 `diskutil` 验证结果和 macOS 原生只读文件系统检查输出。
- 磁盘概览加入文件系统格式显示，并改进普通外接分区和网络卷的格式识别。
- SMART、测速和历史页现在会显示当前查看的磁盘名称，避免多磁盘场景下混淆。
- 加入 `Command-R` 刷新磁盘列表。
- 加入 `Tab` / `Shift-Tab` 在概览、SMART、测速、实时活动和历史页之间切换。
- 补充磁盘操作、检查日志、占用程序和快捷键相关测试。

### 安全提示

Capricorn 的磁盘检查以只读诊断为主。装载、卸载、推出、重命名和强制卸载会调用 macOS 系统工具，请确认目标磁盘无重要任务正在运行。系统内置盘的危险操作已在 Capricorn 内禁用。当前 Release 资产使用本地已构建 App 打包，未通过本仓库流程自动公证。

## English

Capricorn V1.0.3 keeps the version naming rule of `Version = 1.0` and `Build = 3`, so the public Display Name is `Capricorn V1.0.3`. This release focuses on drive context actions, system-disk protection, open-file diagnostics, read-only check logs, and faster keyboard navigation.

### Download

- Release package: `Capricorn-v1.0.3-macOS.zip`
- App name: `Capricorn V1.0.3.app`
- Requirement: macOS 14.0 or later

### Highlights

- Adds a drive context menu to the sidebar.
- Supports mount, unmount, force unmount, eject, rename volume, reveal in Finder, refresh, and network disconnect actions.
- Protects internal system disks from mount, unmount, force-unmount, and eject operations initiated from Capricorn.
- Adds open-file inspection to list processes currently using files on the selected disk.
- When unmount or eject actions fail, Capricorn now shows the failure reason, possible occupying processes, and a force-unmount follow-up where appropriate.
- Adds Check Log and Detailed Check views using `diskutil` verification and native read-only macOS filesystem checkers where available.
- Adds filesystem format display to the overview and improves format detection for mounted external partitions and network volumes.
- SMART, benchmark, and history pages now show the selected drive name to reduce confusion in multi-drive workflows.
- Adds `Command-R` to refresh the drive list.
- Adds `Tab` / `Shift-Tab` switching across Overview, SMART, Benchmark, Live Activity, and History.
- Expands tests around disk actions, check logs, open-file inspection, and shortcuts.

### Safety Notes

Capricorn disk checks are read-only diagnostics. Mount, unmount, eject, rename, and force-unmount actions call macOS system tools, so confirm that the target drive is not running important work before using them. Risky operations are disabled for internal system disks inside Capricorn. The release asset is packaged from the already-built local app and is not notarized by an automated repository workflow.
