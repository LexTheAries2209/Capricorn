# Capricorn V2.7.3

中文发布说明：[v2.7.3.zh-CN.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.3/docs/releases/v2.7.3.zh-CN.md)

English release notes: [v2.7.3.en.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.3/docs/releases/v2.7.3.en.md)

本版为三星 Portable SSD T5 和 USB-NVMe 外接硬盘加入更明确、按条件显示的 SMART 兼容性提醒。

This release adds clearer, condition-based SMART compatibility guidance for Samsung Portable SSD T5 and external USB-NVMe drives.

## 中文

Capricorn V2.7.3 使用 `Version = 2.7`、`Build = 3` 和 Display Name `Capricorn V2.7.3`。

### 主要更新

- 当外接三星 Portable SSD T5 无 SMART 数据且 SAT SMART Drive 已安装时，概览和 SMART 页面显示“驱动冲突”，提示三星驱动可能与 SAT SMART Drive 冲突，移除三星驱动后可能恢复 SMART 读取。
- 当外接 USB-NVMe 硬盘无 SMART 数据且 SAT SMART Drive 已安装时，提示部分 USB-NVMe 桥接器在 macOS 上可能无法提供 SMART 数据。
- 两类提醒严格依据设备类型、SMART 读取结果和 SAT 安装状态触发，不会对普通硬盘强制显示。
- 概览提醒位于数据来源列表末尾，不再加入额外分隔线；SMART 页面使用精简、单行说明以减少视觉占用。

### 下载与兼容性

- Release 包名：`Capricorn-v2.7.3-macOS.zip`
- App 名称：`Capricorn V2.7.3.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。
- SAT SMART Driver 仅是兼容 USB-SATA 设备的可选组件。Capricorn 不会自动安装或加载驱动，也不会修改系统安全设置。

### 验证

- 完整 macOS 测试：303 项通过，0 失败。
- 严格并发 Release 构建、Swift 6 兼容性构建和 Release Archive 均成功；Swift 6 生产代码仅报告已有的 `String(cString:)` 弃用警告。
- App 元数据、arm64/x86_64 通用架构、内置 smartctl 和 SAT PKG 已检查；归档 App 与 dSYM 的双架构 UUID 完全匹配。
- 发布包大小：9,179,738 字节；SHA-256：`7ed84494a0c48e0af47ae261b10f486bf8379860e6e78e0837cf121be5119ae1`；`unzip -t` 通过。

## English

Capricorn V2.7.3 uses `Version = 2.7`, `Build = 3`, and the display name `Capricorn V2.7.3`.

### Highlights

- When an external Samsung Portable SSD T5 has no SMART data and SAT SMART Drive is installed, Overview and SMART show a Driver Conflict warning explaining that Samsung's driver may conflict with SAT SMART Drive and that removing it may restore SMART access.
- When an external USB-NVMe drive has no SMART data and SAT SMART Drive is installed, Capricorn explains that some USB-NVMe bridges cannot expose SMART data on macOS.
- Both warnings are gated by device type, SMART results, and SAT installation state; they are never forced onto ordinary drives.
- Overview places the warning at the end of Providers without an extra divider. SMART uses concise, single-line guidance to reduce visual space.

### Download And Compatibility

- Release package: `Capricorn-v2.7.3-macOS.zip`
- App name: `Capricorn V2.7.3.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
- SAT SMART Driver remains optional for compatible USB-SATA devices. Capricorn does not install or load it automatically or change system security settings.

- Package size: 9,179,738 bytes; SHA-256: `7ed84494a0c48e0af47ae261b10f486bf8379860e6e78e0837cf121be5119ae1`; `unzip -t` passed.
