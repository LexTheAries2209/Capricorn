# Capricorn V3.1.1

发布日期：2026-11-01。完整版本 `3.1.1`，Build `0051`。
构建号是独立、全局递增的四位发布构建序号，不再拼入版本号。

## 更新内容

- 改善通过 USB 集线器连接设备时的 SMART 与 SNT 识别。
- 无效 SMART 响应和异常序列号不再显示为健康数据，减少错误警报。
- 修正 SMART 目标选择及无法确定设备时的中文提示。

## 安装与安全

下载 `Capricorn-v3.1.1-macOS.zip` 并安装固定名称 `Capricorn.app`。要求 macOS 14.0 或更新系统，包含 arm64/x86_64。V2.10.2 及以后支持应用内更新；更早版本及旧开发 Build `1000` 需手动安装。

特权设备服务须在设置中启用并完成系统批准。推荐 `/Applications`，也可使用本机可写、非可移除磁盘上的固定文件夹。手动移动或替换 App 前先停用服务；应用内更新会尝试恢复此前已启用的服务，系统仍可能要求重新批准。

每次 SNT 仍须确认卸载该 USB 设备上的全部卷；请先关闭文件、结束其他磁盘任务并备份重要数据。结束后尝试恢复挂载，失败时可能需要重新连接或使用“磁盘工具”。可移动卷隐私授权由系统单独管理，后台扫描不会主动接管设备。

本次修复不会为不支持的设备增加 SMART 能力。未获得可信响应时显示不可用；此前异常属性不能作为健康依据。已通过多级集线器下的真实 USB 标识只读核对，本次未执行真实 SNT 接管、卷卸载或硬件自检。JMicron、ASMedia 和 Realtek 实验性协议的兼容性取决于桥接器、固件及设备；不保证全部 USB 设备可用，不提供通用 SD 卡健康读取。

内置 smartctl 7.5，SAT SMART Drive 可选。测速与负载使用所选文件夹中的临时文件，写入测试可能增加磁盘负载。

App、服务与工具使用同一团队 Apple Development 证书签名，更新包及清单使用既有 Ed25519 密钥；没有 Developer ID 或 Apple 公证，不能保证其他 Mac 上首次运行和服务批准的体验。
