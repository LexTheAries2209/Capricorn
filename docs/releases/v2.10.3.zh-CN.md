# Capricorn V2.10.3

发布日期：2026-10-17。

## 版本与安装

- 完整版本 `2.10.3`，Build `0043`。构建号是独立、全局递增的四位发布构建序号，不再拼入版本号。
- 下载 `Capricorn-v2.10.3-macOS.zip`，解压后安装固定名称的 `Capricorn.app`。
- V2.10.2 可通过应用内更新升级。V2.10.1 及更早版本、旧开发 Build `1000` 需手动安装。
- 系统要求：macOS 14.0 或更高版本，包含 arm64 和 x86_64。

## 更新内容

- 更新检查、结果和错误提示采用统一的紧凑中文窗口，内容居中，按句子换行。
- 启动检查 15 秒无结果自动结束，等待下次启动或手动重试；修复等待圈残留和“好”按钮无响应。
- 设置标题改为“设置 - Capricorn V2.10.3”，更新状态移至更新模块底部。
- 应用菜单和设置提供第三方许可窗口，可查看 Sparkle 和 smartctl 的完整许可。

## 更新与安全

自动检查与自动下载默认关闭，保留用户已保存的选择。15 秒阈值适用于启动时的更新检查，不限制已开始的安装包下载与安装。有冲突磁盘任务时仍提示并阻止更新，安装前保存历史。

更新下载遵循系统代理，清单与安装包使用原有 Ed25519 密钥验证。App 使用 ad-hoc 签名，没有 Developer ID 或 Apple 公证，首次启动可能需要手动允许。

替换 App 不会清除应用数据目录中的 SwiftData 历史。安装回归使用隔离的测试历史与偏好，不代表对真实用户数据库进行了迁移演练。内置 smartctl 7.5，无需额外安装；磁盘写入和大文件负载仍需确认目标并保留备份。
