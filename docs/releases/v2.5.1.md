## 中文

Capricorn V2.5.1 使用 `Version = 2.5`、`Build = 1` 和 Display Name `Capricorn V2.5.1`。

### 主要更新

- 概览健康度电池图标改用系统符号，并按健康度显示 100%、60–99%、40–59%、20–39%、1–19% 和 0% 六档填充。
- 历史页重新整理快速自检、自检报告和 SMART/测速/实时活动模块的布局，快速自检只保留一个“清理结果”入口，不进入隐藏记录。
- 对齐历史页操作按钮并限制按钮使用内容宽度，避免操作按钮拉伸到整行。
- 保留 SMART 温度和错误日志条目的独立提示；它们不会改变整个 SMART 健康等级。
- 完善自检能力探测、系统盘权限保护、无法发送 NVMe 自检命令 `0x14` 时的灰色状态和本地化提示。

### 下载与兼容性

- Release 包名：`Capricorn-v2.5.1-macOS.zip`
- App 名称：`Capricorn V2.5.1.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。

### 验证

- 完整 macOS 测试：277 项通过，0 失败。
- Release 构建成功，App 元数据、内置 smartctl 资源和 arm64+x86_64 双架构已检查。
- 严格并发检查和 Swift 6 兼容性构建通过；Swift 6 仅报告已有的 `String(cString:)` 弃用警告。
- 发布包大小：11,284,108 字节；SHA-256：`5f4995e36dfaa005af734d5a40083ea82738913e12e6f1fcf55957c6c7e8e5f6`；`unzip -t` 通过。
- 本版跳过 Developer ID 签名、公证和 Gatekeeper 信任验证；首次打开可能需要手动允许。

## English

Capricorn V2.5.1 uses `Version = 2.5`, `Build = 1`, and the display name `Capricorn V2.5.1`.

### Highlights

- Uses the system battery symbol in Overview and maps health to six fill bands: 100%, 60–99%, 40–59%, 20–39%, 1–19%, and 0%.
- Reworks History layout for Quick Disk Check, self-test reports, and SMART/benchmark/live-activity modules; Quick Disk Check keeps one “Clear Results” action and is never moved into hidden records.
- Aligns History actions and keeps buttons at intrinsic content width instead of stretching them across the panel.
- Keeps SMART temperature and error-log entries as independent signals; neither changes the overall SMART health level.
- Completes self-test capability probing, system-disk permission protection, and localized muted handling when macOS cannot send NVMe self-test command `0x14`.

### Download And Compatibility

- Release package: `Capricorn-v2.5.1-macOS.zip`
- App name: `Capricorn V2.5.1.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.

### Verification

- Full macOS test suite: 277 tests passed, 0 failures.
- Release build succeeded; App metadata, bundled smartctl resources, and arm64+x86_64 universal architecture were checked.
- Strict-concurrency and Swift 6 compatibility builds passed; Swift 6 reported only the existing `String(cString:)` deprecation warning.
- Package size: 11,284,108 bytes; SHA-256: `5f4995e36dfaa005af734d5a40083ea82738913e12e6f1fcf55957c6c7e8e5f6`; `unzip -t` passed.
- Developer ID signing, notarization, and Gatekeeper trust checks were intentionally skipped; macOS may require manual approval on first launch.
