# Capricorn V3.2.0

发布日期：2026-11-02。完整版本 `3.2.0`，Build `0055`，macOS 14.0+。

Build 是独立、全局递增的四位发布构建序号，不再拼入版本号。

- 新增可选的自动 SNT 读取，在软件启动及硬盘接入时获取空闲 USB 硬盘的健康信息。
- 保留最近有效数据，忙碌时等待，反复读取失败后暂停；手动读取成功后恢复后续自动尝试。
- 设置显示设备服务状态警示，点击红色感叹号查看提示，服务不可用时禁用自动读取开关。

下载 `Capricorn-v3.2.0-macOS.zip`，安装固定名称 `Capricorn.app`。V2.10.2 及以后支持应用内更新；更早版本及旧开发 Build `1000` 需手动安装。

自动读取默认关闭。先在设置中启用设备服务并完成系统批准及所需卷访问授权，再开启“硬盘操作 > 自动读取 SNT”。开启后无需逐次确认，每次启动或连接成功读取一次。被占用时等待空闲，不计失败；连续读取失败三次或三种未知桥接协议均失败后停止自动尝试，手动成功可恢复。

SNT 会临时卸载设备全部卷并尝试恢复挂载，请先关闭文件、结束其他磁盘任务并备份重要数据。不会强制卸载或结束占用程序，恢复不确定时暂停。兼容性取决于桥接器、固件与设备，不保证全部 USB 设备可用，不提供通用 SD 卡健康读取。

推荐在 `/Applications` 或本机可写、非可移除磁盘上的固定文件夹启用服务。手动移动或替换 App 前先停用服务；应用内更新尝试恢复此前已启用的服务，系统可能要求重新批准。macOS 单独管理可移动卷隐私授权。内置 smartctl 7.5，SAT SMART Drive 可选；测速和负载使用所选文件夹中的临时文件。

全量 747 项测试：744 通过、3 项硬件或证书条件跳过、零失败。严格并发、Swift 6、双架构 Archive、归档 App 启动、完整签名及 dSYM 核对、存档源码独立 Universal Release 构建通过。20 个真实 Sparkle 隔离场景全部通过；安装测试保留独立历史与偏好，服务衔接使用模拟协调器。更新包和清单签名复验通过；真实 Sparkle 候选源确认旧 `0054` 发现 `3.2.0 / 0055`，当前 `0055` 无更新。

沿用同团队 Apple Development 证书及既有 Ed25519 更新签名，没有 Developer ID 或 Apple 公证。本次未执行真实 SNT 接管、卷卸载或硬件自检；隐私权限变化、全系统占用检查、接管中拔盘、多卷恢复、Intel/macOS 14 及其他 Mac 的服务批准仍需实机验收。

`Capricorn-v3.2.0-source.tar.gz` 包含完整对应源码、两套 smartctl 上游源码包、本地补丁及许可证。完整验证、包摘要和兼容性说明见[双语发布说明](https://github.com/LexTheAries2209/Capricorn/blob/v3.2.0/docs/releases/v3.2.0.md)。
