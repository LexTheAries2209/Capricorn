# Capricorn V1.0.5 Release Notes

Capricorn V1.0.5 keeps the version convention of `Version = 1.0` and `Build = 5`, with the public Display Name `Capricorn V1.0.5`. This release fixes benchmark UI stalls and adds a guarded disk First Aid workflow with strict safety boundaries.

## Download

- Release package: `Capricorn-v1.0.5-macOS.zip`
- App name: `Capricorn V1.0.5.app`
- Requirement: macOS 14.0 or later

On first launch, if macOS Gatekeeper shows an internet-download warning, right-click the app in Finder and choose Open, or allow it from System Settings > Privacy & Security.

## Highlights

- Fixes UI stalls caused by benchmark cancellation, immediate restart, and late background callbacks. Stop now waits for worker, file-handle, and temporary-file cleanup to finish.
- Adds “First Aid…” to the local physical-drive context menu with a separate preflight, explicit per-volume selection, two required risk confirmations, and live system output.
- Direct repair is limited to external or removable APFS/ExFAT volumes and uses only `diskutil repairVolume`.
- Revalidates the device identifier, volume UUID, parent physical disk, filesystem format, writable state, and locked state immediately before each volume starts.
- Blocks direct repair for SMART `preFail` or `failed` health; SMART warnings require an additional risk confirmation.
- Network volumes, virtual disks, internal/system disks, read-only or locked volumes, and unsupported formats show explicit reasons instead of running a repair command.
- NTFS never invokes a repair command; the UI provides a Windows CHKDSK example and Microsoft documentation instead.
- Checks open files before repair and lists occupying processes. Capricorn does not terminate processes or force-unmount disks.
- Repairs selected volumes serially and supports “Stop After Current Volume” without interrupting an active filesystem repair.
- Blocks refresh, benchmark, live write workload, mount/unmount, rename, and other disk checks during repair, then refreshes drive and SMART state after completion.
- Adds complete Simplified Chinese and English First Aid content, VoiceOver labels, Disk Utility fallback, and macOS Recovery guidance.
- Expands tests for APFS/ExFAT eligibility, NTFS blocking, identity changes, non-zero exits, partial completion, stop-after-current behavior, and the exact command allowlist.

## Safety Boundaries

- No `repairDisk`, erase, reformat, partition, or raw-device write capability is included.
- Capricorn does not invoke `fsck -y` directly and does not use `sudo`, AppleScript password prompts, or a privileged helper.
- Internal and system disks only show Disk Utility/macOS Recovery guidance; Capricorn does not repair them directly.
- First Aid repairs filesystem consistency. It is not data recovery and cannot repair SMART failures, damaged media, unstable cables, or power problems.
- Back up important data, stop transfers and benchmarks, and stabilize power and cabling before running First Aid.

## Optional Dependency

Capricorn does not bundle `smartctl`. Install smartmontools for deeper ATA/NVMe SMART data:

```sh
brew install smartmontools
```
