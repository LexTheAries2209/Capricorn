# Capricorn V2.7.4

中文发布说明：[v2.7.4.zh-CN.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.4/docs/releases/v2.7.4.zh-CN.md)

发布日期 / Release date: 2026-09-19

本版增加测速读写方式选择，并重新设计测速与实时活动历史，让每次任务的曲线和结果更直观地归在一起。

This release adds benchmark operation selection and reorganizes benchmark and Live Activity history so each run's chart and results are easier to read together.

## 中文

Capricorn V2.7.4 使用 `Version = 2.7`、`Build = 4` 和 Display Name `Capricorn V2.7.4`。

### 主要更新

- 测速页新增“仅读取”“仅写入”和“读写”选择，可按当前需要过滤本次执行的测速项目；配置说明和写入确认会同步显示所选方式。
- 调整测速操作按钮、配置控件和结果行间距，使常用操作更集中，窄窗口下的排列也更稳定。
- 每次测速只保存一份活动曲线样本；历史页以一次测速任务为一组，在顶部显示一张曲线，下面列出该次保存的所有测速结果。
- 旧版中多条结果重复保存同一曲线的数据会自动识别为同一组，不需要迁移历史数据库。
- 实时活动历史会显示每条已保存记录的折线图，同时保留时间、采样点、采样间隔和读写峰值摘要。
- 历史页的 SMART 快照、测速记录和实时活动监控保持三栏布局到约 1200 pt，并精简 SMART 快照的空状态文案。

### 下载、兼容性与安全

- Release 包名：`Capricorn-v2.7.4-macOS.zip`
- App 名称：`Capricorn V2.7.4.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。
- SAT SMART Driver 仅是兼容 USB-SATA 设备的可选组件。Capricorn 不会自动安装或加载驱动，也不会修改系统安全设置。
- Capricorn 只在选择的测速目标文件夹中创建临时文件，不会直接写入裸设备。即使选择“仅读取”，读取基准也可能先创建准备文件，因此不能视为零写入模式。
- 写入、混合、循环测速和实时活动大文件负载会产生存储写入和磨损，开始前请确认目标磁盘和可用空间。

## English

Capricorn V2.7.4 uses `Version = 2.7`, `Build = 4`, and the display name `Capricorn V2.7.4`.

### Highlights

- Benchmark adds Read Only, Write Only, and Read & Write selection. The selected operations filter the tests in the next run and appear in configuration details and write confirmation.
- Benchmark actions, configuration controls, and result-row spacing are reorganized for clearer everyday use and more stable narrow-window layouts.
- Each benchmark run stores one activity sample set. History presents one chart at the top of the run, followed by every benchmark result saved by that run.
- Legacy records that repeated the same chart on several results are recognized as one group without a history-database migration.
- Saved Live Activity records display their line chart while retaining time, sample count, interval, and read/write peak summaries.
- SMART Snapshots, Benchmark Runs, and Live Activity History remain in three columns down to about 1200 pt, and the SMART snapshot empty-state copy is shorter.

### Download, Compatibility, And Safety

- Release package: `Capricorn-v2.7.4-macOS.zip`
- App name: `Capricorn V2.7.4.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
- SAT SMART Driver remains optional for compatible USB-SATA devices. Capricorn does not install or load it automatically or change system security settings.
- Capricorn creates temporary files only inside the selected benchmark target and never writes directly to raw devices. Read Only benchmarks may still create a preparation file, so the option is not a zero-write mode.
- Write, mixed, looped benchmark, and Live Activity large-file workloads create storage writes and wear. Confirm the target and free space before starting.
