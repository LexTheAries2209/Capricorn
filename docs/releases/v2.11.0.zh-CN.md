# Capricorn V2.11.0

发布日期：2026-10-19。

## 版本与安装

- 完整版本 `2.11.0`，Build `0046`。构建号是独立、全局递增的四位发布构建序号，不再拼入版本号。
- 下载 `Capricorn-v2.11.0-macOS.zip`，解压后安装固定名称的 `Capricorn.app`。
- V2.10.2 及以后可使用应用内更新；更早版本和旧开发 Build `1000` 需手动安装。
- 要求 macOS 14.0 或更高版本，包含 arm64、x86_64。

## 更新内容

- 测速配置更新为默认、快速、SSD、HDD 和自定义。异步测速的 T 对应真实工作线程；自定义 Q/T 联动，乘积不超过 16。自定义仍需开发者选项及其子开关，不改变原权限规则。
- 快速配置仅测顺序 1 MiB Q1T1 和随机 4 KiB Q1T1，分别传输 128 MiB、1 MiB；预热后测量一次，省去额外等待。用于快速检查基本读写表现，不替代完整介质或坏块检查。
- 改善测速和大文件负载中资源暂时不足导致的异步 I/O 失败；停止时安全等待已提交的请求完成，减少后续重跑异常。
- 大文件负载默认 128 GiB，并按硬盘记住上次选择。准备阶段显示等待说明，停止时显示已等待时间、待完成 I/O 或当前准备/刷盘阶段，结束后仅显示“负载已停止”。

## 更新与安全

启动检查及开发者自动更新均默认关闭；未开启自动更新时仍由用户确认下载与安装，有冲突任务或历史保存失败时阻止安装。

更新清单和安装包使用既有 Ed25519 密钥签名。App 使用有效 ad-hoc 签名，没有 Developer ID 或 Apple 公证，首次启动可能需手动允许。内置 smartctl 7.5，无需另装；可选 SAT SMART Drive 依设备需要手动配置。

测速及负载仅在选定文件夹创建临时文件，不直接向裸设备写入。读取项目也可能先写入临时源文件；持续写入会产生压力和磨损，请确认目标并备份重要数据。系统的进程 AIO 额度仍会限制实际并发。
