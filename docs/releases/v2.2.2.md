## 中文

Capricorn V2.2.2 使用 `Version = 2.2`、`Build = 2` 和 Display Name `Capricorn V2.2.2`。本版改用磁盘拓扑与可操作性识别无用结构分区，避免名称硬匹配或容量阈值误伤正常小卷。

### 主要更新

- 解析 `diskutil` 的 APFS Physical Store 关系与分区内容，将 APFS 容器承载分区、EFI 和其他结构条目标记为不可操作卷宗。
- 容量不再是全局过滤阈值。只有在拓扑信息缺失，同时满足物理分区、未挂载、无 UUID 且不超过 1 GB 时，容量才作为辅助信号。
- 统一从概览、代表卷、切换卷宗、测速、实时活动负载、检查修复、容量汇总和 SMART CSV 中排除结构分区；正常挂载的小容量卷仍然保留。

### 下载与兼容性

- Release 包名：`Capricorn-v2.2.2-macOS.zip`
- App 名称：`Capricorn V2.2.2.app`
- 系统要求：macOS 14.0 或更新版本
- 可选依赖：用户自行安装的 smartmontools (`smartctl`) 与 SAT SMART Driver
- 本版使用本机 Apple Development 开发签名，但未使用 Developer ID 签名且未公证；首次打开可能需要 Finder > 打开或在“系统设置 > 隐私与安全性”中允许。

## English

Capricorn V2.2.2 uses `Version = 2.2`, `Build = 2`, and Display Name `Capricorn V2.2.2`. This release identifies non-operable structural partitions from storage topology instead of hard-coded names or a global capacity cutoff.

### Highlights

- Parses diskutil APFS Physical Store relationships and partition content to classify APFS container backing stores, EFI, and other structural entries as non-operable volumes.
- Capacity is no longer a global filter. It is only a fallback signal when an entry is a physical partition, unmounted, has no volume UUID, and is no larger than 1 GB.
- Applies the same structural filter to Overview, representative-volume selection, Switch Volume, benchmarks, Live Activity workloads, checks and repairs, capacity summaries, and SMART CSV metadata while preserving legitimate small mounted volumes.

### Download And Compatibility

- Release package: `Capricorn-v2.2.2-macOS.zip`
- App name: `Capricorn V2.2.2.app`
- Requires macOS 14.0 or later
- Optional user-installed smartmontools (`smartctl`) and SAT SMART Driver
- This build carries a local Apple Development signature, but it is neither Developer ID signed nor notarized. First launch may require Finder > Open or explicit approval in System Settings > Privacy & Security.
