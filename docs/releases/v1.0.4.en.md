# Capricorn V1.0.4 Release Notes

Capricorn V1.0.4 keeps the version naming rule of `Version = 1.0` and `Build = 4`, so the public Display Name is `Capricorn V1.0.4`. This release focuses on concurrency and cancellation reliability across benchmarks, live workloads, drive refresh, and process execution, while upgrading Settings, responsive layout, persistence boundaries, and project structure.

## Download

- Release package: `Capricorn-v1.0.4-macOS.zip`
- App name: `Capricorn V1.0.4.app`
- Requirement: macOS 14.0 or later

On first launch, if macOS Gatekeeper shows an internet-download warning, right-click the app in Finder and choose Open, or allow it from System Settings > Privacy & Security.

## Highlights

- Benchmark and live-workload sessions now use UUID-scoped `idle`, `running`, and `stopping` states. Stop waits for process, file-handle, and temporary-file cleanup, while late events from superseded work are rejected.
- Progress and results flow through `AsyncStream`; lock-protected state covers synchronous Darwin I/O, and cross-task values have explicit `Sendable` boundaries.
- Reworks cancellable command execution so every run owns its child process, cancellation terminates then interrupts it, and launch failure, non-zero exit, and user cancellation are distinct errors.
- Adds a unified drive refresh service with up to four concurrent disk-information and SMART tasks, one `smartctl` scan per refresh, and newest-refresh-wins semantics.
- Splits the application into App, Domain, Features, Services, Persistence, and Support modules using the macOS 14 Observation model.
- Adds a versioned SwiftData schema, migration plan, container factory, and repository boundary; save and export errors are no longer silently ignored.
- Adds native Settings for language, virtual-drive visibility, report serial numbers, plain-Tab navigation, and a custom `smartctl` path, with complete Simplified Chinese content.
- Adds `Command-P` for Settings plus a bottom-left sidebar entry; `Control-Tab` and `Control-Shift-Tab` always switch feature pages.
- Makes controls, metric cards, and wide tables responsive down to an approximately 1050×680 window.
- Adds categorized Unified Logging, a local build-and-run script, and build/test-only GitHub Actions quality checks.
- Expands regression coverage for late events after cancellation, immediate restart, overlapping refreshes, child-process termination, and legacy database migration.

## Safety Notes

- Capricorn does not provide erase, partition, or raw-device write operations.
- Disk checks are primarily read-only diagnostics; mount, unmount, eject, rename, and force-unmount actions call macOS system tools.
- Risky operations are disabled for internal system disks inside Capricorn.
- Benchmarks, write, mixed, loop, and large-file workloads can stress and wear the target storage, so confirm the target path and available capacity first.
- The release asset is packaged from the already-built local app and is not notarized by an automated repository workflow.

## Optional Dependency

Capricorn does not bundle `smartctl`. For deeper ATA/NVMe SMART data, install smartmontools yourself:

```sh
brew install smartmontools
```

After installation, restore automatic detection in Settings or choose a custom `smartctl` executable.
