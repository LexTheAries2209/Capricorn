# Capricorn V2.4.1 Release Notes

Release date: 2026-09-02

Capricorn V2.4.1 uses `Version = 2.4`, `Build = 1`, and the display name `Capricorn V2.4.1`.

## Highlights

- Settings now shows only the bundled `smartctl` version and the smartmontools project link; external tool selection is removed.
- Overview reports USB-SATA and USB-NVMe SMART command pass-through for eligible USB devices.
- The three data-source rows now share one typography and layout, without a divider or a separate right-side status label on the pass-through row.
- Corrects WD Elements Portable HDD 5TB vendor/model identification; media other than SSDs, SD cards, and network volumes is displayed as HDD.

## Download And Compatibility

- Release package: `Capricorn-v2.4.1-macOS.zip`
- App name: `Capricorn V2.4.1.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.

## Data And Safety Notes

- SMART visibility still depends on macOS, the device protocol, and USB bridge capabilities. Pass-through status is based on actual smartctl reads and does not fabricate SMART attributes.
- Capricorn does not install or remove kernel extensions and does not search or select external smartctl binaries from PATH or Homebrew.
