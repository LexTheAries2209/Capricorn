# Capricorn V2.9.1 English Release Notes

Release date: 2026-09-23

Bilingual release notes: [v2.9.1.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.1/docs/releases/v2.9.1.md)

Capricorn V2.9.1 uses `Version = 2.9`, `Build = 1`, and display name `Capricorn V2.9.1`.

## Highlights

- Full and single benchmark confirmation now uses a compact activity sheet like the SMART self-test monitor. Settings, target folder, and write warning are separated instead of being crowded into a system alert or full-page overlay.
- After starting, the sheet shows progress, current test, status, and cancellation. Hiding the sheet does not stop the run; reopen it while benchmarking.
- A display-only free-space snapshot prevents repeated volume queries during sheet transitions. The target, write access, and remaining capacity are rechecked before starting.

## Download, Compatibility, And Safety

- Package: `Capricorn-v2.9.1-macOS.zip`; App: `Capricorn V2.9.1.app`.
- macOS 14.0 or later; smartctl 7.5 is bundled.
- Benchmarking may write a complete temporary file and cause storage wear. Check the selected target and backups before running. Hiding the sheet is not cancellation.
- Full/single confirmation and dismissal were visually checked, but a complete physical benchmark was not run; in-run progress animation is not yet field-verified.
