## 中文

- 测速新增“停止”：完成当前一轮并计算结果后，取消后续测试与自定义循环；“取消”仍立即结束。精简自定义项目组界面，保留最多四组。
- 虚拟硬盘（Beta）健康度默认自动计算；新增内置系统盘模拟、CFast 2.0、网络和 SD 类型，提供 512 B / 4 KB 扇区。分区字段独立成行，容量与已用容量均可选单位，默认名称依次编号。
- 首次启动默认简体中文，保留已有语言选择；健康状态“预故障”更名为“错误”，兼容已有历史记录。网络与虚拟硬盘使用专用图标。
- 开发者选项新增默认关闭的“自动下载并安装更新”；启用后可自动完成更新，有冲突任务时仍阻止安装。

下载 `Capricorn-v2.10.5-macOS.zip`，解压后安装 `Capricorn.app`。V2.10.2 及以后可使用应用内更新；更早版本和旧开发 Build `1000` 需手动安装。

启动检查默认关闭，保留已有选择，15 秒无结果自动结束。未开启开发者自动更新时，下载与安装仍需确认。安装前保存历史。更新清单和安装包使用原有 Ed25519 密钥验证；App 使用有效 ad-hoc 签名，没有 Developer ID 或 Apple 公证，首次启动可能需手动允许。内置 smartctl 7.5。测速写入与大文件负载仍需确认目标并备份重要数据。

## English

- Adds Stop to finish the active benchmark pass, calculate results, and skip remaining tests and custom loops. Cancel still ends immediately. Simplifies custom test groups while retaining the four-group limit.
- Virtual disks (Beta) default to calculated health, add built-in system-disk simulation plus CFast 2.0, network and SD media, and offer 512 B / 4 KB sectors. Partition fields use separate rows, both capacity fields offer units, and default disk names are numbered.
- Defaults first launch to Simplified Chinese while preserving saved language choices. Renames Pre-Fail to Error with existing history compatibility, and gives network and virtual disks dedicated icons.
- Adds “Automatically download and install updates” under Developer Options, off by default. Conflicting tasks still block installation.

Download `Capricorn-v2.10.5-macOS.zip` and install `Capricorn.app`. V2.10.2 and later support in-app upgrades; earlier versions and old development Build `1000` require manual installation.

Checks on launch default to off, preserve the saved choice, and end after 15 seconds without a result. Downloads and installation require confirmation unless developer automatic updates are enabled. History is saved before installation. The feed and archive use the existing Ed25519 key. The App has valid ad-hoc signatures without Developer ID or Apple notarization; first launch may require manual approval. smartctl 7.5 is bundled. Verify benchmark/write targets and back up important data.
