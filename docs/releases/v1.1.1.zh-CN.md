# Capricorn V1.1.1 发布说明

Capricorn V1.1.1 使用 `Version = 1.1`、`Build = 1`，Display Name 为 `Capricorn V1.1.1`。本版改善 SMART 数据可读性，并为实时活动和测速加入更灵活的续接与单项测试方式。

## 下载

- Release 包名：`Capricorn-v1.1.1-macOS.zip`
- App 名称：`Capricorn V1.1.1.app`
- 系统要求：macOS 14.0 或更新版本

首次打开时，如果 macOS Gatekeeper 提示来自互联网下载的 App，请在 Finder 中右键点击 App 后选择“打开”，或在“系统设置 > 隐私与安全性”中允许打开。

## SMART 显示

- macOS 原生 SMART 温度若为 Kelvin，会显示为例如 `312 K (39 °C)`；若数据源已经提供摄氏度，则显示为例如 `35 °C`，不会重复换算。
- macOS 原生与 `smartctl` 的 NVMe `Data Units Read`、`Data Units Written` 均换算为 TB，并在括号中保留原始 units 数量，方便对照数据源。
- 两种数据源使用相同的 NVMe Data Unit 定义，减少原始大整数难以阅读的问题。

## 实时活动

- 停止监控后新增“继续监控”，再次采集的样本会续接现有图表，便于保留停止前后的趋势。
- 原有“开始监控”逻辑保持不变，仍会清空图表并开始新的监控段；两种操作可按需要选择。

## 测速

- 点击测速结果矩阵左侧的绿色项目按钮，可以只测试该项目一次，并沿用当前选择的引擎、文件大小和数据模式。
- 单项测速固定运行一次并关闭加量测试；启动前仍显示写入文件警告和简要配置。
- 正在执行完整或单项测速时不会允许启动另一个项目，并会提示先停止当前测试。
- 新增“提高小块文件测试效率”开关。开启后可选择 5%、10%、20%、30% 或 50%，作为 4 KiB、16 KiB 和 64 KiB 项目的实际测试文件量比例。
- 开关默认关闭，第一次开启时默认选择 20%；测速期间开关和比例选择会锁定。
- 该比例同时适用于完整测速与单项测速，以及同步和异步引擎；较大的块尺寸仍使用完整测试文件量。
- 调整较长测速项目名称的字号与布局，使绿色按钮内的文字保持单行。
