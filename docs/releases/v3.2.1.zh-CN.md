# Capricorn V3.2.1

发布日期：2026-11-03。完整版本 `3.2.1`，Build `0056`，macOS 14.0+。

Build 是独立、全局递增的四位发布构建序号，不再拼入版本号。

- 48 小时内已有有效 SNT 数据时跳过自动读取，保留手动更新；过期后读取失败仍显示上次数据。
- SNT SMART 表格和历史报告显示实际采集时间，CSV 保留对应时间字段。
- 调整 SMART 默认列宽，名称列缩小 15%，为 ID 留出更多空间。

下载 `Capricorn-v3.2.1-macOS.zip`，安装固定名称 `Capricorn.app`。V2.10.2 及以后支持应用内更新；更早版本及旧开发 Build `1000` 需手动安装。

自动读取默认关闭，启用设备服务并完成系统批准及所需卷访问授权后才可开启。启动或接入时复用未满 48 小时的成功数据，持续连接期间不因到期主动读取。失败和占用不延长有效期，手动成功后重新计算。连续三次有效失败或三种未知桥接协议均失败后停止自动尝试；挂载恢复不确定时暂停。

SNT 会临时卸载设备全部卷并尝试恢复挂载，请先关闭文件、结束其他磁盘任务并备份重要数据。不会强制卸载或结束占用程序。兼容性取决于桥接器、固件与设备，不保证全部 USB 设备可用，不提供通用 SD 卡健康读取。

推荐在 `/Applications` 或本机可写、非可移除磁盘上的固定文件夹启用服务。手动移动或替换 App 前先停用服务；应用内更新尝试恢复此前已启用的服务，系统可能要求重新批准。内置 smartctl 7.5，SAT SMART Drive 可选；测速和负载使用所选文件夹中的临时文件。

全量 754 项测试：751 通过、3 项硬件或证书条件跳过、零失败。严格并发、Swift 6、双架构 Archive、归档 App 启动、完整签名和 dSYM 核对、存档源码独立 Universal Release 构建通过。20 个真实 Sparkle 隔离场景全部通过，保留独立历史与偏好，服务衔接使用模拟协调器；下载中冲突场景加入两秒下载延迟后通过。更新包和清单签名复验通过；真实 Sparkle 候选源确认旧 `0055` 发现 `3.2.1 / 0056`，当前 `0056` 无更新。

沿用同团队 Apple Development 证书及既有 Ed25519 更新签名，没有 Developer ID 或 Apple 公证。SNT 验证使用模拟设备和命令；真实权限变化、占用检查、接管中拔盘、多卷恢复、Intel/macOS 14 及其他 Mac 的服务批准仍需实机验收。

`Capricorn-v3.2.1-source.tar.gz` 包含完整对应源码、两套 smartctl 上游源码包、本地补丁及许可证。完整验证、包摘要和兼容性说明见[双语发布说明](https://github.com/LexTheAries2209/Capricorn/blob/v3.2.1/docs/releases/v3.2.1.md)。
