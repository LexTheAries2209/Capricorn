# Capricorn V2.7.4 中文发布说明

发布日期：2026-09-19

双语发布说明：[v2.7.4.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.4/docs/releases/v2.7.4.md)

Capricorn V2.7.4 使用 `Version = 2.7`、`Build = 4` 和 Display Name `Capricorn V2.7.4`。

## 主要更新

- 测速页新增“仅读取”“仅写入”和“读写”选择，可按需要过滤本次执行的测速项目，并同步更新配置说明和写入确认。
- 重新整理测速操作按钮、配置控件和结果行间距，在常规与窄窗口下都更直观。
- 每次测速只保存一份活动曲线；历史页按一次测速任务分组，在顶部显示曲线，下面列出该次保存的结果。
- 旧版重复保存同一曲线的多条结果会自动归为同组，不需要迁移历史数据库。
- 实时活动历史显示已保存记录的折线图，并保留时间、采样点、间隔和读写峰值摘要。
- 历史三栏布局的折行阈值降低到约 1200 pt，同时精简 SMART 快照空状态文案。

## 下载、兼容性与安全

- Release 包名：`Capricorn-v2.7.4-macOS.zip`
- App 名称：`Capricorn V2.7.4.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置。
- SAT SMART Driver 是兼容 USB-SATA 设备的可选组件，不会被自动安装或加载。
- Capricorn 只在所选测速文件夹中创建临时文件，不直接写入裸设备。“仅读取”仍可能创建读取准备文件，不能视为零写入模式。
- 写入、混合、循环测速和实时活动大文件负载会产生写入与磨损，请先确认目标和可用空间。
