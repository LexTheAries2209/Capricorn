# Capricorn V2.6.3 Release Notes

Release date: 2026-09-15

Capricorn V2.6.3 uses `Version = 2.6`, `Build = 3`, and the display name `Capricorn V2.6.3`. This release collects the changes made after `v2.5.1`.

## Highlights

- Adds optional SAT SMART Driver support and Settings diagnostics for compatible USB-SATA devices, including installation state, version, source, and passthrough guidance.
- Improves USB-SATA and USB-NVMe SMART passthrough reporting, hides sources that cannot be confirmed by an actual read, and adds localized dynamic diagnostics.
- Strengthens SMART read fallback and capability caching, preserving last-known-good data across transient probe failures and never forcing unsupported macOS NVMe admin commands.
- Reworks Live Activity controls for monitoring, sample intervals, workload targets, and actions while keeping the monitored drive linked to sidebar selection.
- Moves the app version and macOS user name to the right-aligned status row at the bottom of the sidebar; removes the Settings `Command-P` shortcut and its visible hint.

## Download And Compatibility

- Release package: `Capricorn-v2.6.3-macOS.zip`
- App name: `Capricorn V2.6.3.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
- The SAT SMART Driver installer is optional for compatible USB-SATA devices. Capricorn does not install or load it automatically or change system security settings.
