# Capricorn V2.10.2

发布日期 / Release date: 2026-10-17

完整版本 / Complete Version `2.10.2` · Build `0042` · macOS 14.0+ · arm64 / x86_64

构建号是独立、全局递增的四位发布构建序号，不再拼入版本号；迁移基线为此前核实的 41 次正式 Release。

Build is an independent, globally increasing four-digit release-build sequence, no longer appended to the public version. Its migration baseline is 41 previously verified stable Releases.

## 中文

- 新增应用内手动更新、启动时检查，以及可选的自动下载和退出时安装；更新偏好会保存。
- 有测速、监控、磁盘检查、自检等冲突任务时，提示并阻止更新；安装前保存历史。
- 更新设置更紧凑，检查时间与按钮同排；开发者选项可控制构建号显示，默认关闭。

下载 `Capricorn-v2.10.2-macOS.zip`，解压后安装 `Capricorn.app`。V2.10.1 及更早公开版本需手动安装一次；同为 Build `0042` 或旧 Build `1000` 的本地开发包也应手动替换。

更新清单和安装包使用 Ed25519 签名验证，并遵循系统代理。App 使用 ad-hoc 签名，没有 Developer ID 或 Apple 公证，首次启动可能需要手动允许。自动检查与自动下载均默认关闭；磁盘写入操作和历史数据的安全边界保持不变，内置 smartctl 7.5。

## English

- Adds manual in-app updates, checks on launch, and optional automatic downloads with installation on quit; update choices persist.
- Conflicting benchmarks, monitoring, disk checks, self-tests, and other disk tasks block updates with a warning; history is saved before installation.
- Makes update settings more compact with the last-check time beside the button; build visibility is optional under Developer Options and off by default.

Download `Capricorn-v2.10.2-macOS.zip` and install `Capricorn.app`. Public V2.10.1 and earlier require one manual installation; local development builds already numbered `0042` or the old `1000` also need manual replacement.

The appcast and archive use Ed25519 signature verification and system proxy settings. The App is ad-hoc signed without Developer ID or Apple notarization, so first launch may require manual approval. Checks on launch and automatic downloads are off by default. Existing disk-write and history-data safety boundaries remain; smartctl 7.5 is bundled.
