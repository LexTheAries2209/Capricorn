# Capricorn V2.9.0 English Release Notes

Release date: 2026-09-23

Bilingual release notes: [v2.9.0.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.0/docs/releases/v2.9.0.md)

Capricorn V2.9.0 uses `Version = 2.9`, `Build = 0`, and display name `Capricorn V2.9.0`.

## Highlights

- Corrects USB-NVMe SMART self-test capability and transport guidance so readable attributes alone do not imply the bridge can start a test.
- Adds start confirmation, a hideable/reopenable progress monitor, compact status, completion results, and confirmed abort for supported non-system disks. Percentages come from the drive; completion time is an estimate, and hiding the monitor does not stop the test.
- Distinguishes pass, failure, abort, disconnect, and unknown results without inventing detailed checks or unreported progress.
- Removes Overview quick checks, SMART diagnostic self-tests, and related History sections for system disks, blocking checks/self-tests in both menus and operation paths. Ordinary SMART attributes and snapshots remain visible.
- Moves diagnostic visibility controls to Interface Display and adds a confirmed Reset All Settings action that retains disk caches and the history database.
- SMART diagnostics self-test history CSV/JSON export prompts for a save location every time; SMART snapshot CSV export is unchanged.

## Download, Compatibility, And Safety

- Release package: `Capricorn-v2.9.0-macOS.zip`; App name: `Capricorn V2.9.0.app`.
- Requires macOS 14.0 or later; smartctl 7.5 is bundled.
- Extended self-tests can take a long time. Do not disconnect an external drive during testing. The virtual T7 is development-only and not enabled in the production app; physical T7 validation is still outstanding.
- First Aid may modify eligible non-system filesystems. Benchmark and Live Activity workloads may write data and cause wear; check the target and backups first.
