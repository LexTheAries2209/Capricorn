# Capricorn V3.2.2

发布日期：2026-11-11

完整版本 `3.2.2` · Build `0057` · macOS 14.0+ · arm64 / x86_64

Build 是独立、全局递增的四位发布构建序号，不再拼入版本号。

## 本版变化

- 自动 SNT 跳过只读介质及包含只读卷的硬盘，减少 Codex 等存储卡接管后挂载恢复失败的风险。
- “读取错误日志”移至开发者选项，默认关闭，同时受开发者选项总开关控制。
- 新增默认关闭的“始终显示 SMART 自检”。开启后，对已有 SMART 信息的设备跳过通常的自检模块显示判断；SNT 硬盘和没有 SMART 信息的设备仍不显示。关闭时沿用原规则，实际自检命令的安全限制保持不变。该选项不改变错误日志模块的显示条件。

## 安装与使用

下载 `Capricorn-v3.2.2-macOS.zip`，解压后将固定名称 `Capricorn.app` 放到 `/Applications` 或其他本机固定工具目录。V2.10.2 及以后支持应用内更新；更早版本和旧开发 Build `1000` 需手动安装一次。

自动 SNT 默认关闭。先启用设备服务，完成系统批准和所需卷访问授权。自动探测只考虑可写介质且所有已知卷均可写的硬盘。有效 SNT 数据复用 48 小时，缓存到期本身不会在硬盘持续连接期间发起读取。占用时等待，连续失败或挂载恢复不确定时暂停；手动读取仍可主动发起。

SNT 会临时卸载同一 USB 设备的全部卷并尝试恢复，不会强制卸载或结束占用程序。请关闭相关文件、结束磁盘任务并备份重要数据。恢复失败时可能需要重新连接或使用“磁盘工具”。本版仍不开放 SNT 自检和错误报告界面。

服务应从本机可写、非可移除磁盘上的固定目录启用。手动移动或替换 App 前先停用服务；应用内更新尝试恢复原有服务，macOS 可能要求重新批准。可移动卷隐私授权由系统单独管理。兼容性依赖桥接器、固件和设备，不保证全部 USB 硬盘可用，不提供通用 SD 卡健康读取。内置 smartctl 7.5，SAT SMART Drive 可选。测速和负载使用所选目录内的临时文件。
