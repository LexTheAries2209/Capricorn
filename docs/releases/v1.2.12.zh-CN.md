# Capricorn V1.2.12 发布说明

Capricorn V1.2.12 使用 `Version = 1.2`、`Build = 12`，Display Name 为 `Capricorn V1.2.12`。本版加入静默的 GitHub 更新检查，并完善 SMART CSV 快照导出和本地化字段。

## 下载

- Release 包名：`Capricorn-v1.2.12-macOS.zip`
- App 名称：`Capricorn V1.2.12.app`
- 系统要求：macOS 14.0 或更新版本

## 重点更新

- 应用启动时在后台静默检查 GitHub 最新稳定版；不会自动弹窗或打断当前工作。
- 应用菜单和 `Command-P` 设置页提供“检查更新…”入口。检查失败时会说明无法连接 GitHub，并提供手动重试或打开 Releases 页面；检测到新版本时显示版本信息和发布说明链接。
- 更新检查只接受 GitHub 的非草稿、非预发布版本，避免把测试版误报为稳定更新。
- SMART 快照改为紧凑 CSV 导出，避免重复写入整份快照元数据和属性表头。
- 中文界面的 CSV 增加 `chinese_name` 中文名称列，并导出与 SMART 属性列表一致的本地化说明；英文界面使用英文名称和说明。
- 保留 CSV 的原始值、当前值、最差值、阈值、状态和数据来源字段；CSV 值按 RFC 4180 规则转义。
- SMART 快照文件名继续包含磁盘名称和捕获时间：中文使用 UTC+8 并标注 `UTC+8`，英文使用 UTC+0 并标注 `UTC+0`。

## 安全与限制

- 更新检查需要访问 `api.github.com`。网络不可用时不会影响磁盘监控、SMART、测速或历史功能。
- Capricorn 不会自动下载、安装或替换 App；用户可以从 Releases 页面手动下载。
- Capricorn 不捆绑 smartctl，也不会自动安装 SAT SMART Driver。SMART 数据仍取决于 macOS、磁盘协议、桥接芯片和可选依赖。
- CSV 快照只读出当前 SMART 属性，不对磁盘执行写入。

## 发布校验

- 版本元数据：`MARKETING_VERSION = 1.2`、`CURRENT_PROJECT_VERSION = 12`、Display Name `Capricorn V1.2.12`。
- Release App：计划提供 arm64/x86_64 通用二进制，最低支持 macOS 14.0。
- 完整测试、Release 构建、ZIP 大小和 SHA-256 将在本次发布构建完成后写入双语总说明。
- 按发布要求跳过代码签名和公证；本版本不声明为已签名或已公证，首次打开可能需要在 Finder 中选择“打开”。
