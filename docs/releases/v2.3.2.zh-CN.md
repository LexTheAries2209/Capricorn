# Capricorn V2.3.2 发布说明

发布日期：2026-08-31

Capricorn V2.3.2 使用 `Version = 2.3`、`Build = 2`，Display Name 为 `Capricorn V2.3.2`。

## 主要更新

- 新增 ARRI Codex 存储介质型号识别，覆盖 Codex Compact Drive、Compact Drive Express 和 SXR Capture Drive 系列，包括 `CDXCDC0192M300N40A` 等型号。
- 修正部分摄影机/录制介质的 UDF 卷宗未出现在 `diskutil list` 结果中的情况：在设备信息中发现挂载点时，回填真实卷宗名称、容量、只读状态、卷宗 UUID 和文件系统格式。
- 侧边栏和卷宗相关操作现在可以正确显示真实挂载卷名与 `UDF` 格式，不再回退显示硬盘型号作为卷名。

## 下载与兼容性

- Release 包名：`Capricorn-v2.3.2-macOS.zip`
- App 名称：`Capricorn V2.3.2.app`
- 系统要求：macOS 14.0 或更新版本
- 可选依赖：用户自行安装的 smartmontools (`smartctl`) 与 SAT SMART Driver
- 本版未使用 Developer ID 签名且未公证；首次打开可能需要 Finder > 打开，或在“系统设置 > 隐私与安全性”中允许。

## 数据提示

- 卷宗名称和格式来自 macOS `diskutil` 返回的设备元数据。Capricorn 不会根据型号猜测卷名，也不会把未挂载卷伪造成可操作卷。
- 测速、写入和修复操作仍遵循当前版本的目标卷保护与确认流程。
