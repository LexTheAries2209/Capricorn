# Capricorn V1.2.10 Release Notes

Capricorn V1.2.10 uses `Version = 1.2`, `Build = 10`, and Display Name `Capricorn V1.2.10`. This release collects the SMART presentation, capacity reporting, external-drive naming, and Live Activity drive-linking improvements made since V1.2.5.

## Download

- Release package: `Capricorn-v1.2.10-macOS.zip`
- App name: `Capricorn V1.2.10.app`
- Requirement: macOS 14.0 or later

## Changes Since V1.2.5

- The SMART page uses a stable vertical scrolling layout, recent self-test records can be collapsed, and status messages can be dismissed without changing the self-test session.
- Common external ATA SMART fields have clearer localized names. `Total LBAs Read/Written` is converted using logical block size while retaining the original LBA context.
- The sidebar and overview show total, used, and available capacity. Shared APFS containers are deduplicated before aggregation.
- A bundled external HDD model catalog shows canonical model, product family, and capacity for a verified set of model patterns; unknown devices keep their original system-reported name.
- Recognized drive names are structured more clearly in the sidebar and page headers, while help text preserves the original model.
- Live Activity now follows the sidebar drive and no longer exposes a duplicate drive picker. Other drives are locked during monitoring or workload execution, and disappearance of the active drive stops related tasks with an error.
- Samples, continuation state, history actions, and errors remain isolated by drive so switching after a stop does not mix data.
- Large-file workloads automatically use the first writable mounted partition, with explicit same-drive partition or folder selection. Read-only, unmounted, stale, and cross-drive targets are rejected or safely reset.
- Workload targets persist separately per drive, and the legacy global folder migrates only when it is writable and belongs to the current drive.

## Safety and Limitations

- Write, mixed, loop, and large-file workloads increase storage load and write wear. Confirm the target partition, free space, and stable power before starting.
- Cross-drive folders are not saved; AppModel and the workload service revalidate target ownership before execution.
- The model catalog improves labels for verified patterns and does not establish health, interface capability, or warranty status.
- Capricorn does not bundle smartctl or install/remove SAT kernel extensions.
