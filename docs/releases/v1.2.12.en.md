# Capricorn V1.2.12 Release Notes

Capricorn V1.2.12 uses `Version = 1.2`, `Build = 12`, and Display Name `Capricorn V1.2.12`. This release adds a quiet GitHub update check and improves localized SMART CSV snapshot exports.

## Download

- Release package: `Capricorn-v1.2.12-macOS.zip`
- App name: `Capricorn V1.2.12.app`
- Requirement: macOS 14.0 or later

## Highlights

- Performs a quiet background check for the latest stable GitHub release at launch; it never interrupts the current workflow with an update alert.
- Adds “Check for Updates…” to the application menu and the `Command-P` Settings window. Connection failures explain that GitHub could not be reached and offer retry or the Releases page; an available release shows its version and release-notes link.
- Only non-draft, non-prerelease GitHub releases are considered stable updates.
- SMART snapshots now export a compact CSV, avoiding repeated snapshot metadata and duplicated attribute-table headers.
- The Simplified Chinese CSV adds a `chinese_name` column and localized explanations matching the SMART table; the English CSV uses English names and explanations.
- CSV output retains raw/current/worst/threshold values, status, and source, with RFC 4180 escaping for commas and quotes.
- Snapshot filenames continue to include the drive name and capture time: Simplified Chinese uses UTC+8 and labels it `UTC+8`; English uses UTC+0 and labels it `UTC+0`.

## Safety And Limitations

- Update checks access `api.github.com`. An unavailable network does not affect disk monitoring, SMART, benchmark, or history features.
- Capricorn never downloads, installs, or replaces the App automatically; users can download manually from Releases.
- Capricorn does not bundle smartctl or automatically install SAT SMART Driver. SMART visibility still depends on macOS, drive protocol, bridge chipset, and optional dependencies.
- CSV snapshots read the current SMART attributes and do not write to the drive.
