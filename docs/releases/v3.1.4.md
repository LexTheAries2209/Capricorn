## 中文

- SMART 表格支持横向滚动和有界列宽调整，来源列可拖动，窗口恢复后仍可查看完整信息。
- 来源列默认缩窄 30%，腾出的空间分配给 ID；状态列保持紧凑固定宽度。

下载 `Capricorn-v3.1.4-macOS.zip` 并安装固定名称 `Capricorn.app`。V2.10.2 及以后支持应用内更新；更早版本及旧开发 Build `1000` 需手动安装。

特权设备服务须在设置中启用并完成系统批准。推荐 `/Applications`，也可使用本机可写、非可移除磁盘上的固定文件夹。手动移动或替换 App 前先停用服务；应用内更新会尝试恢复此前已启用的服务，系统仍可能要求重新批准。

每次实验性 SNT 仍须确认卸载该 USB 设备上的全部卷；请先关闭文件、结束其他磁盘任务并备份重要数据。结束后尝试恢复挂载，失败时可能需要重新连接或使用“磁盘工具”。不强制卸载磁盘或结束占用程序；后台扫描不会主动接管 USB 设备，可移动卷隐私授权由系统单独管理。

兼容性取决于桥接器、固件与设备，不保证全部 USB 设备可用，也不提供通用 SD 卡健康读取。本次为界面更新，未执行真实 SNT 接管、卷卸载或硬件自检。

常规读取使用内置 smartctl 7.5，SAT SMART Drive 可选。测速与负载使用所选文件夹中的临时文件，请确认目标并保留备份。

## English

- Adds horizontal scrolling and bounded column resizing to the SMART table, with a resizable Source column and accessible information after restoring the window.
- Reduces Source's default width by 30% and gives that space to ID; Status stays at a compact fixed width.

Download `Capricorn-v3.1.4-macOS.zip` and install the stable-name `Capricorn.app`. V2.10.2 and later support in-app upgrades; earlier versions and old development Build `1000` require manual installation.

Enable the privileged device service in Settings and complete system approval. `/Applications` is recommended; other permanent folders on local, writable, non-removable disks are supported. Disable the service before manually moving or replacing the app. In-app updates attempt to restore a previously enabled service; macOS may require renewed approval.

Each experimental SNT read still requires confirmation before unmounting every volume on the USB device. Close files, finish other disk tasks, and back up important data first. Mount restoration is attempted afterward; failure may require reconnecting the device or using Disk Utility. Disks are never force-unmounted and occupying processes are not terminated. Background scans never initiate USB capture; macOS manages removable-volume privacy consent separately.

Compatibility depends on the bridge, firmware and device; not every USB device is supported, and general SD-card health queries are not provided. This release changes the UI. No real SNT capture, volume unmount, or hardware self-test was performed.

Ordinary reads use bundled smartctl 7.5; SAT SMART Drive is optional. Benchmarks and workloads use temporary files in the selected folder. Verify targets and keep backups.

App、特权服务及工具使用同一团队 Apple Development 证书签名，更新使用既有 Ed25519 密钥。没有 Developer ID 或 Apple 公证；首次打开及系统授权体验不能等同于已公证分发。

The app, privileged service and tools use same-team Apple Development certificate signatures; updates use the existing Ed25519 key. Developer ID and Apple notarization are not established. First launch and system approval should not be assumed equivalent to notarized distribution.

安装回归使用隔离测试 App、历史与偏好，不替换真实用户 App 或数据库。服务衔接安装场景使用模拟协调器，不等于真实 root 服务跨版本安装或授权保留验收。Intel、macOS 14 及其他 Mac 的证书信任与服务批准仍需另行验证。

Installation regressions use isolated fixture apps, history and preferences without replacing the real user app or database. The service-handoff scenario uses a mock coordinator; it does not establish real root-service upgrades or retained system approval. Intel, macOS 14, and certificate trust and service approval on other Macs require separate validation.
