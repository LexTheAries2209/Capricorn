# Capricorn V1.0.4 发布说明

Capricorn V1.0.4 继续沿用 `Version = 1.0`、`Build = 4` 的版本命名原则，因此 Display Name 显示为 `Capricorn V1.0.4`。本版重点提升测速、实时负载、磁盘刷新和命令执行的并发可靠性，并完成设置页、响应式布局、持久化边界和工程结构升级。

## 下载

- Release 包名：`Capricorn-v1.0.4-macOS.zip`
- App 名称：`Capricorn V1.0.4.app`
- 系统要求：macOS 14.0 或更新版本

首次打开时，如果 macOS Gatekeeper 提示来自互联网下载的 App，请在 Finder 中右键点击 App 后选择“打开”，或在“系统设置 > 隐私与安全性”中允许打开。

## 重点更新

- 测速和实时负载使用带 UUID 的 `idle`、`running`、`stopping` 会话状态；停止操作会等待进程、文件句柄和临时文件真正清理完成，并拒绝旧任务的晚到事件。
- 使用 `AsyncStream` 在后台任务和主界面之间传递进度与结果，Darwin I/O 共享状态由锁保护，跨任务数据补充 `Sendable` 边界。
- 重写可取消命令执行层：每次运行独占一个子进程，取消时先终止再中断，并区分启动失败、非零退出和用户主动取消。
- 新增统一磁盘刷新服务：磁盘信息和 SMART 查询采用最多 4 路受控并发，每次刷新只执行一次 `smartctl` 扫描，重叠刷新时只有最新结果生效。
- 将应用拆分为 App、Domain、Features、Services、Persistence 和 Support 模块，并使用 macOS 14 的 Observation 状态模型。
- SwiftData 历史记录加入版本化 Schema、迁移计划、容器工厂和统一 Repository；保存和导出错误不再被静默忽略。
- 新增原生设置页，可配置语言、虚拟磁盘、报告序列号、普通 Tab 切页和自定义 `smartctl` 路径，设置内容完整支持简体中文。
- 新增 `Command-P` 打开设置，并在侧边栏左下角提供设置入口；`Control-Tab` / `Control-Shift-Tab` 始终可用于切换功能页。
- 控制栏、指标卡和宽表格改为响应式布局，最小窗口约为 1050×680。
- 新增分类 Unified Logging、本地构建运行脚本和只执行构建/测试的 GitHub Actions 质量检查。
- 补充取消后的晚到事件、立即重启、重叠刷新、子进程终止和旧数据库迁移等回归测试。

## 安全提示

- Capricorn 不提供擦除、分区或裸设备写入功能。
- 磁盘检查以只读诊断为主；装载、卸载、推出、重命名和强制卸载会调用 macOS 系统工具。
- 系统内置盘的危险操作已在 Capricorn 内禁用。
- 测速、写入、混合、循环和大文件负载会对目标存储造成压力和写入磨损，请先确认目标路径和剩余空间。
- 当前 Release 资产使用本地已构建 App 打包，未通过本仓库流程自动公证。

## 可选依赖

Capricorn 不捆绑 `smartctl`。如需更完整的 ATA/NVMe SMART 数据，可以自行安装 smartmontools：

```sh
brew install smartmontools
```

安装后可在设置页恢复自动检测，或选择自定义 `smartctl` 可执行文件。
