## 中文

Capricorn V2.8.1 使用 `Version = 2.8`、`Build = 1` 和 Display Name `Capricorn V2.8.1`。

### 主要更新

- 测速配置首排改为独立标题行和控件行，所有标题按首行文字基线对齐。
- 下拉菜单、数值选择器、按钮与分段控件统一按控件中心线对齐，消除不同控件固有高度导致的上下错位。
- 测速活动图和实时活动图的纵轴网格统一为 9 条横线。
- 纵轴数字仅标注在第 1、3、5、7、9 条线上，数字与对应横线保持一致。
- 本次不改变测速项目、同步或异步引擎、文件大小、数据模式与实际读写流程。

### 下载、兼容性与安全

- Release 包名：`Capricorn-v2.8.1-macOS.zip`
- App 名称：`Capricorn V2.8.1.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。
- Capricorn 只在选择的测速目标文件夹中创建临时文件，不直接写入裸设备。“仅读取”仍可能创建读取准备文件，不能视为零写入模式。
- 写入、混合、循环测速和实时活动大文件负载会产生存储写入和磨损，开始前请确认目标磁盘和可用空间。

## English

Capricorn V2.8.1 uses `Version = 2.8`, `Build = 1`, and the display name `Capricorn V2.8.1`.

### Highlights

- Separates the first benchmark configuration row into dedicated label and control rows, aligning all labels by their first text baseline.
- Aligns menus, numeric selectors, buttons, and segmented controls by their control center line, removing vertical offsets caused by intrinsic control heights.
- Standardizes the benchmark activity and Live Activity chart grids on nine horizontal lines.
- Shows numeric axis labels only on lines 1, 3, 5, 7, and 9, keeping every label aligned with its grid line.
- Does not change benchmark items, synchronous or asynchronous engines, file sizes, data modes, or the underlying read/write workflow.

### Download, Compatibility, And Safety

- Release package: `Capricorn-v2.8.1-macOS.zip`
- App name: `Capricorn V2.8.1.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
- Capricorn creates temporary files only in the selected benchmark folder and never writes directly to raw devices. Read Only may still create a preparation file and is not a zero-write mode.
- Write, mixed, looped benchmark, and Live Activity large-file workloads create storage writes and wear. Confirm the target and available capacity first.
