# Capricorn V2.7.6

中文发布说明：[v2.7.6.zh-CN.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.6/docs/releases/v2.7.6.zh-CN.md)

本版解决自动化测试可能长期停滞的问题，并为 SMART 命令和 GitHub Actions 增加明确的隔离、超时与重复运行控制。

This release prevents long-running automation stalls and adds explicit isolation, timeouts, and duplicate-run control for SMART commands and GitHub Actions.

## 中文

Capricorn V2.7.6 使用 `Version = 2.7`、`Build = 6` 和 Display Name `Capricorn V2.7.6`。

### 主要更新

- App 作为 XCTest 宿主启动时，不再执行真实磁盘刷新、磁盘事件监控或 GitHub 更新检查，避免系统 I/O 与网络副作用阻塞测试进程。
- SMART 测试使用独立命令协调器，不再与全局运行队列共享状态，减少测试之间相互等待的可能。
- 为内置 `smartctl` 扫描、SMART 读取和版本查询分别设置 15 秒、30 秒和 10 秒超时；超时后会终止子进程并释放协调器队列。
- 网络卷和存储卡会在 `smartctl` 设备扫描前直接返回不支持，避免无意义的外部命令和 CI 环境等待。
- GitHub Actions 质量工作流仅在 `Main` 分支推送和拉取请求运行，不再因发布标签重复执行完整测试。
- 同一分支的新运行会取消旧运行；完整测试最长 20 分钟，严格并发和 Swift 6 兼容性构建最长 15 分钟。
- CI 测试显式关闭 App 启动副作用并启用无缓冲日志，使停滞位置更容易定位。

### 下载、兼容性与安全

- Release 包名：`Capricorn-v2.7.6-macOS.zip`
- App 名称：`Capricorn V2.7.6.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。
- SAT SMART Driver 仅是兼容 USB-SATA 设备的可选组件。Capricorn 不会自动安装或加载驱动，也不会修改系统安全设置。
- Capricorn 只在选择的测速目标文件夹中创建临时文件，不会直接写入裸设备。即使选择“仅读取”，读取基准也可能先创建准备文件，因此不能视为零写入模式。
- 写入、混合、循环测速和实时活动大文件负载会产生存储写入和磨损，开始前请确认目标磁盘和可用空间。

## English

Capricorn V2.7.6 uses `Version = 2.7`, `Build = 6`, and the display name `Capricorn V2.7.6`.

### Highlights

- When the app runs as an XCTest host, it no longer starts real disk refresh, disk-event monitoring, or GitHub update checks, preventing system I/O and network side effects from blocking the test process.
- SMART tests use an isolated command coordinator instead of sharing the global runtime queue, reducing cross-test waits.
- Bundled `smartctl` scan, SMART read, and version queries now have 15-second, 30-second, and 10-second timeouts. Timed-out child processes are terminated and release the coordinator queue.
- Network volumes and memory cards now return unsupported before `smartctl` device scanning, avoiding unnecessary external commands and CI waits.
- The GitHub Actions quality workflow now runs only for `Main` branch pushes and pull requests, avoiding a duplicate full suite for release tags.
- New runs on the same branch cancel older runs. Full tests have a 20-minute limit, while strict-concurrency and Swift 6 compatibility builds have 15-minute limits.
- CI explicitly disables app startup side effects and enables unbuffered logging so any future stall is easier to locate.

### Download, Compatibility, And Safety

- Release package: `Capricorn-v2.7.6-macOS.zip`
- App name: `Capricorn V2.7.6.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
- SAT SMART Driver remains optional for compatible USB-SATA devices. Capricorn does not install or load it automatically or change system security settings.
- Capricorn creates temporary files only inside the selected benchmark target and never writes directly to raw devices. Read Only benchmarks may still create a preparation file, so the option is not a zero-write mode.
- Write, mixed, looped benchmark, and Live Activity large-file workloads create storage writes and wear. Confirm the target and free space before starting.
