# Capricorn V2.9.3 中文发布说明

发布日期：2026-09-29

双语发布说明：[v2.9.3.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.3/docs/releases/v2.9.3.md)

Capricorn V2.9.3 使用 `Version = 2.9`、`Build = 3` 和 Display Name `Capricorn V2.9.3`。

## 主要更新

- 无 SMART 属性时隐藏 SMART 页面顶部区域；没有 `smartctl` 来源属性时隐藏下方 SMART 诊断区，避免对普通三星 T7 等无法完成有效诊断的设备显示无效功能。
- 修复 SMART 自检确认窗口取消后的白色残留块，并恢复快速自检取消/关闭行为。
- 测速、实时监控和实时工作负载运行时锁定左侧硬盘选择，防止操作过程中切换到其他硬盘；任务结束后恢复选择。
- 延续硬盘型号目录扩展和 SMART 自检状态解析修复。

## 下载、兼容性与安全

- Release 包名：`Capricorn-v2.9.3-macOS.zip`；App 名称：`Capricorn V2.9.3.app`。
- 需要 macOS 14.0 或更新版本；内置 smartctl 7.5。USB 桥接器是否支持 SMART、自检和错误日志取决于实际设备与传输层能力。
- 界面不会伪造 SMART 诊断能力；测速会在目标文件夹创建临时测试文件，请确认目标位置并保留备份。
- 此分发包未执行 Developer ID 签名、公证或 Gatekeeper 信任验证，首次运行可能需要手动允许。
