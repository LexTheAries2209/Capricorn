# Capricorn V2.10.4

Release date: October 17, 2026.

## Version And Installation

- Complete Version `2.10.4`, Build `0044`. Build is an independent, globally increasing four-digit release-build sequence and is not appended to the version.
- Download `Capricorn-v2.10.4-macOS.zip` and install the fixed-name `Capricorn.app`.
- V2.10.2 / V2.10.3 support in-app upgrades. V2.10.1 and earlier, and old development Build `1000`, require manual installation.
- Requires macOS 14.0 or later; includes arm64 and x86_64.

## Highlights

- Requires user confirmation for update downloads, installation, and relaunch. Removes automatic downloads and installation on quit, and directs users to Check for Updates when a new version is available.
- Renames the SMART settings section to Third-Party Components and groups Sparkle, smartctl, and SAT SMART Drive versions and project links there.
- Removes the separate third-party license reader while retaining complete notices in the source tree. Places the SAT version beside its title and shortens the section.
- Renames the virtual-disk option to “Allow adding virtual disks” without changing its behavior.

## Updates And Safety

Checks on launch default to off and preserve the saved choice. Checks without a result end after 15 seconds until the next launch or manual retry. Previous automatic-download choices are disabled, and the native update window no longer offers automatic downloads. Users initiate downloads and explicitly confirm installation and relaunch once preparation finishes; cancellation or an ordinary quit does not install an unconfirmed update. Conflicting disk tasks still block updates, and history is saved before installation.

Downloads follow system proxy settings. The feed and archive are verified with the existing Ed25519 key. The App is ad-hoc signed without Developer ID or Apple notarization; first launch may require manual approval.

Replacing the App does not clear SwiftData history in the application data directory. Installation regressions use isolated fixture history and preferences, not the actual user database, and do not establish installation behavior on Intel or macOS 14 hardware. smartctl 7.5 is bundled. Disk writes and large-file workloads still require target verification and backups.
