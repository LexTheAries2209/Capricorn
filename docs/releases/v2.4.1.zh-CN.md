# Capricorn V2.4.1 发布说明

发布日期：2026-09-02

Capricorn V2.4.1 使用 `Version = 2.4`、`Build = 1`，Display Name 为 `Capricorn V2.4.1`。

## 主要更新

- 设置仅显示内置 `smartctl` 的版本和 smartmontools 源项目链接，不再提供外部工具选择。
- 概览的数据来源增加 USB-SATA 与 USB-NVMe SMART 命令透传状态，只对适用的 USB 设备显示。
- 统一数据来源三行的字体和布局，移除透传行上方的分割线以及独立的右侧状态文字。
- 修正 WD Elements Portable HDD 5TB 的厂商/型号识别；除 SSD、SD 卡和网络卷外的介质统一显示为 HDD。

## 下载与兼容性

- Release 包名：`Capricorn-v2.4.1-macOS.zip`
- App 名称：`Capricorn V2.4.1.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。

## 数据提示

- SMART 数据是否可用取决于 macOS、设备协议和 USB 桥接器能力；透传状态来自实际 smartctl 读取结果，不会伪造 SMART 属性。
- Capricorn 不会自动安装或卸载内核扩展，也不会自动搜索或使用 PATH/Homebrew 中的外部 smartctl。
