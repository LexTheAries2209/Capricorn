## 中文

### 主要更新

- SMART 错误条目可一次点击读取并直接打开可用报告；无法获取详情时明确提示，不会将已有历史错误显示为没有错误。
- 设置新增默认关闭的“显示读取错误条目”，可单独显示或隐藏错误条目模块，节省 SMART 页面的纵向空间。
- SMART 诊断区移除简介行，收起按钮与标题同排；完善中英文设置介绍、左对齐和错误说明的完整显示。

### 下载、兼容性与安全

- 下载：[Capricorn-v2.10.1-macOS.zip](https://github.com/LexTheAries2209/Capricorn/releases/download/v2.10.1/Capricorn-v2.10.1-macOS.zip)；App 名称：`Capricorn V2.10.1.app`。
- 版本元数据：Version `2.10`、Build `1`、显示名 `Capricorn V2.10.1`。
- 需要 macOS 14.0 或更新版本；内置 smartctl 7.5，无需另行安装 smartmontools。可选 SAT SMART 驱动不会自动安装。
- 错误条目读取不会写入控制器日志；可获取的 SMART 信息和错误详情取决于设备、桥接器及 macOS 支持，历史错误计数本身不代表介质损坏。
- 测速和大文件负载会在选定文件夹创建临时文件，读取负载也需要先写入源文件。持续写入可能带来存储压力与磨损，请确认目标位置并保留重要数据备份。
- GitHub 分发包未执行 Developer ID 签名、公证或 Gatekeeper 信任验证，首次运行可能需要手动允许。本地脚本的 Apple Development 签名不代表公开分发包获得签名或公证。

## English

### Highlights

- Read SMART error entries and open an available report with one click. Missing details are identified clearly, without presenting existing historical errors as an empty log.
- Adds Show Error Entry Reader in Settings, off by default, to show or hide the error-entry section separately and save vertical space on the SMART page.
- Removes the diagnostics summary row and places the collapse button beside its title, with clearer bilingual settings descriptions, aligned labels, and complete error explanations.

### Download, Compatibility, and Safety

- Download: [Capricorn-v2.10.1-macOS.zip](https://github.com/LexTheAries2209/Capricorn/releases/download/v2.10.1/Capricorn-v2.10.1-macOS.zip); App: `Capricorn V2.10.1.app`.
- Bundle metadata: Version `2.10`, Build `1`, display name `Capricorn V2.10.1`.
- macOS 14.0 or later; smartctl 7.5 is bundled, so smartmontools need not be installed separately. The optional SAT SMART driver is not installed automatically.
- Reading error entries does not write to controller logs. Available SMART data and error details depend on the device, bridge, and macOS support; a historical error count alone does not establish media failure.
- Benchmarks and large-file workloads create temporary files in the selected folder, including source files for read workloads. Sustained writes may cause storage stress and wear. Verify the target and keep important backups.
- The GitHub distribution is not Developer ID signed, notarized, or Gatekeeper-trust verified; manual approval may be required on first launch. Apple Development signing in the local run script does not establish public distribution signing or notarization.
