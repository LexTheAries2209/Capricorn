# Capricorn V2.2.1 发布说明

发布日期：2026-08-25

## 主要更新

- 多卷磁盘现在使用“代表卷”作为侧边栏名称以及重命名、测速和实时活动自动目标的共同起点。外接物理磁盘可在“磁盘操作 > 切换卷宗”中选择一个可操作卷；系统盘和网络卷不允许切换，Time Machine、只读或未挂载卷会保留可见状态但不可操作。
- 设置新增“Capricorn 打开时选择的卷宗”。默认选择容量最大的可操作卷，也可改为恢复上次手动选择；选择会优先以完整硬件序列号和卷 UUID 记忆，避免设备重新插拔后 `diskN` 变化造成错配。
- EFI、未挂载的 APFS 容器支撑分区，以及 Preboot、Recovery、VM、Update 等 APFS 辅助卷不再显示为普通卷或操作目标。系统盘固定优先根挂载卷，因此显示 `Macintosh HD`，不会误显示 `Preboot`。
- 扩充型号识别库：新增 Intel/Solidigm D5-P4320、D5-P4326、D5-P4420、D5-P5430、D5-P5336、D7-P4510、D7-P4511、D7-P4610、D7-P5810、D7-PS1010、D7-PS1030 等企业 SSD 映射，并新增 WD Ultrastar DC SN640；同时补全部分 EDSFF/U.2 型号代码变体。

## 下载与兼容性

- Release 包名：`Capricorn-v2.2.1-macOS.zip`
- App 名称：`Capricorn V2.2.1.app`
- 系统要求：macOS 14.0 或更新版本
- 可选依赖：用户自行安装的 smartmontools (`smartctl`) 与 SAT SMART Driver
- 本版按要求跳过签名和公证。首次打开时可能需要在 Finder 中右键选择“打开”，或到“系统设置 > 隐私与安全性”中允许。

## 安全说明

- Capricorn 仅在选择的文件夹内创建测速或负载临时文件，不会直接写入裸设备。
- 写入、混合、循环和大文件负载会对介质产生压力；请确认代表卷或手动目标位于预期磁盘上。
- 系统、网络、Time Machine、只读和未挂载卷不会成为代表卷操作目标。
