# Capricorn V2.3.1 Release Notes

Release date: 2026-08-25

Capricorn V2.3.1 uses `Version = 2.3`, `Build = 1`, and the display name `Capricorn V2.3.1`.

## Highlights

- Settings now shows History Database location, disk usage, and record count. You can reveal it in Finder or clear all local history after confirmation.
- History and Reports shows visible and hidden record counts for the selected drive. Clear all history for that drive or only its hidden data, with confirmation and without affecting other drives.
- The automatic benchmark target for the system disk now prefers the Desktop directory, avoiding test files at the system root.
- During Live Activity monitoring or a large-file workload, other sidebar drive rows are dimmed and disabled for pointer and keyboard selection. They become available again after the task stops.
- The Tab navigation explanation now sits directly below its matching setting.

## Download And Compatibility

- Release package: `Capricorn-v2.3.1-macOS.zip`
- App name: `Capricorn V2.3.1.app`
- System requirement: macOS 14.0 or later
- Optional dependencies: user-installed smartmontools (`smartctl`) and SAT SMART Driver
- This release is not Developer ID signed or notarized. On first launch, macOS may require Finder > Open or approval in System Settings > Privacy & Security.

## Data Notes

- Clearing the history database, selected-drive history, or hidden data permanently removes the corresponding local records. Check the displayed counts before confirming.
- Benchmarks create temporary files only inside the selected directory. Write, mixed, and loop modes can stress storage.
