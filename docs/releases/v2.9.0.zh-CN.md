# Capricorn V2.9.0 中文发布说明

发布日期：2026-09-23

双语发布说明：[v2.9.0.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.0/docs/releases/v2.9.0.md)

Capricorn V2.9.0 使用 `Version = 2.9`、`Build = 0` 和 Display Name `Capricorn V2.9.0`。

## 主要更新

- 修正 USB-NVMe SMART 自检能力及传输层提示，避免把可读取 SMART 属性误判为可启动自检。
- 非系统盘支持快速/完整自检启动确认、可隐藏和重新打开的进度监视器、紧凑状态条、完成结果及中止二次确认。百分比由硬盘报告，预计完成时间只是估算，隐藏窗口不停止硬盘测试。
- 区分通过、失败、中止、断开与结果未知，不伪造硬盘没有提供的进度或详细检查项目。
- 系统盘不显示概览快速自检、SMART 诊断自检及历史中的相关报告，也不能从菜单或内部路径执行检查/自检；仍可查看普通 SMART 属性和快照。
- 设置加入保留硬盘缓存与历史数据库的重置所有设置操作，点击后必须二次确认；诊断显示开关移入界面显示区域。
- SMART 诊断的自检历史 CSV/JSON 每次导出时选择保存位置，不影响 SMART 快照 CSV 导出。

## 下载、兼容性与安全

- Release 包名：`Capricorn-v2.9.0-macOS.zip`；App 名称：`Capricorn V2.9.0.app`。
- 系统要求：macOS 14.0 或更新版本；内置 smartctl 7.5。
- 长程自检可能耗时很久，测试期间不要断开外接盘。虚拟 T7 仅用于开发演示，正式版不启用，暂无真实 T7 实盘验证。
- 急救可能修改非系统卷文件系统；测速与实时活动负载可能写入数据并造成磨损，请先核对目标和备份。
