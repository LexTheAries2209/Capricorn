# Capricorn V2.7.5 English Release Notes

Release date: 2026-09-20

Bilingual release notes: [v2.7.5.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.5/docs/releases/v2.7.5.md)

Capricorn V2.7.5 uses `Version = 2.7`, `Build = 5`, and the display name `Capricorn V2.7.5`.

## Highlights

- SMART History summaries now show health, life remaining, media errors, cumulative reads, cumulative writes, and power-on time, with complete Simplified Chinese localization.
- Every SMART snapshot can open a separate scrolling full-report window containing the snapshot summary and all SMART attributes. The window can choose a folder and export another CSV.
- SMART adds a separate Save to History action that does not create a CSV. Save CSV continues to store the current snapshot in History.
- Benchmark History treats all results sharing one activity chart as a complete run, so hide, restore, and delete actions operate on the whole group.
- Compact benchmark charts skip selected speed labels while retaining the same grid-line count and spacing, preventing crowded or misaligned axis text.
- Settings adds a default-off individual history deletion option. When enabled, visible and hidden SMART, benchmark, and Live Activity records show a delete button and are permanently removed after confirmation instead of being moved to hidden records.
- SMART snapshot actions use the shorter Select Folder, Save to History, and Save CSV labels.

## Download, Compatibility, And Safety

- Release package: `Capricorn-v2.7.5-macOS.zip`
- App name: `Capricorn V2.7.5.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled.
- SAT SMART Driver is optional for compatible USB-SATA devices and is never installed or loaded automatically.
- Capricorn creates temporary files only in the selected benchmark folder and never writes directly to raw devices. Read Only may still create a preparation file and is not a zero-write mode.
- Write, mixed, looped benchmark, and Live Activity large-file workloads create storage writes and wear. Confirm the target and available capacity first.
- Individual history deletion is irreversible, so it is disabled by default and always requires confirmation.
