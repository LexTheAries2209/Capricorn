# Capricorn V2.7.1 中文发布说明

发布日期：2026-09-17

双语发布说明：[v2.7.1.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.1/docs/releases/v2.7.1.md)

Capricorn V2.7.1 使用 `Version = 2.7`、`Build = 1` 和 Display Name `Capricorn V2.7.1`。

## 主要更新

- SAT SMART Driver 的绿色状态现在只取决于驱动文件是否安装并已加载，不再要求当前连接的外置设备触发 IOKit 匹配。
- 符合条件的 USB-SATA 设备在 SMART 数据不可用时会始终显示 SAT 引导，并从设置中移除对应开关。
- 设置中的安装操作改名为“安装 SAT SMART Drive”，继续打开 App 内置安装包供用户确认安装。
- 物理反引号/波浪号键现在可在不同输入法下打开设置；应用菜单显示该快捷键，左下角设置入口仍保留设置图标、版本号和 macOS 用户名。

## 下载与兼容性

- Release 包名：`Capricorn-v2.7.1-macOS.zip`
- App 名称：`Capricorn V2.7.1.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置。
- SAT SMART Driver 是兼容 USB-SATA 设备的可选组件，不会被自动安装或加载。
