# Capricorn V2.8.0 English Release Notes

Release date: 2026-09-21

Bilingual release notes: [v2.8.0.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.8.0/docs/releases/v2.8.0.md)

Capricorn V2.8.0 uses `Version = 2.8`, `Build = 0`, and the display name `Capricorn V2.8.0`.

## Highlights

- Adds a cross-process physical-disk operation lock shared by development and release builds, preventing multiple Capricorn instances from starting conflicting operations on the same physical disk.
- Benchmarking, Live Activity large-file workloads, SMART self-tests, disk checks and First Aid, mount, unmount, eject, rename, and network-volume disconnect check for conflicts before execution.
- A conflict alert identifies the running operation and process, and the requested operation does not proceed. Read-only monitoring itself does not hold the exclusive operation lock.
- The lock coordinates Capricorn only. It does not lock macOS device nodes or prevent Finder, other benchmark tools, or system services from accessing the disk.
- Existing runIDs remain intact. The active task cleans only its own temporary files and never globally deletes other run directories.
- Before a new task, Capricorn removes only crash leftovers older than one hour that have no active lease and can be confirmed as Capricorn-owned. Uncertain files are retained.
- The operating system releases process-held file locks after normal exit, force-quit, or a system crash, so the lock cannot remain permanently held.

## Download, Compatibility, And Safety

- Release package: `Capricorn-v2.8.0-macOS.zip`
- App name: `Capricorn V2.8.0.app`
- System requirement: macOS 14.0 or later

- Read Only benchmarks may still create preparation files. Write, mixed, looped, and Live Activity workloads create storage writes and wear.
