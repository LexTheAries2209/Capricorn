## 中文

- 新增实验性 USB-NVMe SNT SMART 手动读取，自动选择兼容的桥接协议，并尝试恢复卷挂载。
- SMART 页面提供读取引导，右键菜单支持刷新 SNT SMART；展示读取到的序列号，并保留手动读取结果。
- 分别显示物理设备容量与卷容量，完善 USB SMART 数据来源和读取状态说明。

下载 `Capricorn-v3.0.0-macOS.zip` 并安装 `Capricorn.app`。V2.10.2 及以后支持应用内更新；更早版本或旧开发 Build `1000` 需手动安装。

实验性 SNT 支持 JMicron、ASMedia 和 Realtek USB-NVMe 桥接协议，兼容性取决于设备及固件，不保证所有 USB 设备可用，也不是通用 SD 卡健康读取。读取需要手动确认、管理员授权和暂时卸载该 USB 设备上的所有卷；请先关闭文件、结束其他磁盘任务并备份重要数据。结束后尝试恢复挂载，失败时可能需要重新连接或使用“磁盘工具”。自动刷新不会自动接管 USB 设备。

常规读取继续使用内置 smartctl 7.5，SAT SMART Drive 为可选项。测速及负载使用所选文件夹中的临时文件，请确认目标并保留备份。

App 使用有效 ad-hoc 签名，更新包及清单使用既有 Ed25519 密钥，没有 Developer ID 或 Apple 公证。

## English

- Adds experimental manual USB-NVMe SNT SMART reads with automatic bridge protocol selection and volume restoration attempts.
- Adds SMART-page guidance and a context-menu SNT refresh action, displays retrieved serial numbers, and retains manual read results.
- Distinguishes physical device capacity from volume capacity and clarifies USB SMART sources and read status.

Download `Capricorn-v3.0.0-macOS.zip` and install `Capricorn.app`. V2.10.2 and later support in-app upgrades; earlier versions or old development Build `1000` require manual installation.

Experimental SNT supports JMicron, ASMedia, and Realtek USB-NVMe bridge protocols. Compatibility depends on the device and firmware; it is not guaranteed for every USB device and does not provide general SD-card health queries. Reads require manual confirmation, administrator authorization, and temporarily unmounting all volumes on the USB device. Close files, finish other disk tasks, and back up important data first. Mount restoration is attempted afterward; failures may require reconnecting the device or using Disk Utility. Automatic refresh never initiates USB capture.

Ordinary reads continue using bundled smartctl 7.5; SAT SMART Drive is optional. Benchmarks and workloads use temporary files in the selected folder. Verify targets and keep backups.

The App uses valid ad-hoc signatures, and the archive and feed use the existing Ed25519 key. Developer ID and Apple notarization are not established.
