# Capricorn V2.9.3 English Release Notes

Release date: 2026-09-29

Bilingual release notes: [v2.9.3.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.3/docs/releases/v2.9.3.md)

Capricorn V2.9.3 uses `Version = 2.9`, `Build = 3`, and display name `Capricorn V2.9.3`.

## Highlights

- Hides the SMART-page header and save actions when no SMART attributes are available, and hides the SMART diagnostics panel unless the current attributes include a `smartctl` source.
- Fixes the white dismissal artifact and restores reliable cancel/close behavior for the SMART self-test confirmation sheet.
- Locks sidebar drive selection during benchmarks, live monitoring, and live workloads so operation state cannot move to another drive mid-run.
- Carries forward the drive-model catalog expansion and SMART self-test state parsing fixes from the unreleased V2.9.2 preparation.

## Download, Compatibility, and Safety

- Package: `Capricorn-v2.9.3-macOS.zip`; App: `Capricorn V2.9.3.app`.
- macOS 14.0 or later; smartctl 7.5 is bundled. SMART, self-test, and error-log support still depends on the drive and transport bridge.
- The UI does not invent diagnostic capability. Benchmarks create temporary test files in the selected target folder; verify the target and keep important backups.
- This distribution is not Developer ID signed, notarized, or Gatekeeper-trust verified; manual approval may be required on first launch.
