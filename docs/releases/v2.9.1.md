# Capricorn V2.9.1

中文发布说明：[v2.9.1.zh-CN.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.1/docs/releases/v2.9.1.zh-CN.md)

English release notes: [v2.9.1.en.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.1/docs/releases/v2.9.1.en.md)

发布日期 / Release date: 2026-09-23

This maintenance release makes benchmark confirmation and progress easier to read and reduces repeated main-thread free-space queries during sheet transitions. It does not change the benchmark engine or the disk-write safety boundary.

本次维护版改进测速确认与进度的可读性，减少活动窗口切换时在主线程重复查询可用空间；测速引擎和写入安全边界不变。

## 中文

Capricorn V2.9.1 使用 `Version = 2.9`、`Build = 1` 和 Display Name `Capricorn V2.9.1`。

### 主要更新

- 完整测速与单项测速的运行确认不再使用拥挤的系统提醒或全页遮罩，改为类似 SMART 自检的紧凑活动窗口；测试配置分项显示，目标文件夹和写入风险单独呈现。
- 启动测速后，同一活动窗口显示进度条、当前测试、状态和取消按钮。隐藏活动窗口不会停止测速；运行中可从测速页重新打开。
- 界面显示可用空间时使用容量快照，避免窗口打开与关闭时反复在主线程查询目标卷。真正启动前仍实时验证目标文件夹归属、可写性与可用空间。

### 下载、兼容性与安全

- Release 包名：`Capricorn-v2.9.1-macOS.zip`；App 名称：`Capricorn V2.9.1.app`。
- 系统要求：macOS 14.0 或更新版本；内置 smartctl 7.5。
- 测速可能创建完整临时测试文件并产生写入和存储磨损。运行前核对目标磁盘、可用空间和备份；隐藏进度窗口不等于取消测试。临时文件按现有会话流程清理。
- 本版仅人工检查了完整/单项确认窗口的呈现与取消，没有对真实硬盘执行完整测速；运行中进度动画尚未进行实盘观察。

### 验证

- 完整 macOS 测试：340 项通过，0 失败；严格并发构建、Swift 6 兼容性构建和 Release Archive 成功。Swift 6 检查出现一条既有 `init(cString:)` 弃用警告，不影响构建通过。
- 归档 App 元数据为 Version 2.9、Build 1、Display Name Capricorn V2.9.1；arm64/x86_64 双架构、内置 smartctl/SAT 资源及 dSYM UUID 匹配已验证。
- ZIP 大小：9,633,338 字节；SHA-256：`4cc513658bb74d8acd7c8e29c3c438147a3ba3a81687a6857623a36e760bc270`；`unzip -t` 通过。
- 未执行 Developer ID 签名、公证或 Gatekeeper 信任验证；首次打开可能需要手动允许。

## English

Capricorn V2.9.1 uses `Version = 2.9`, `Build = 1`, and display name `Capricorn V2.9.1`.

### Highlights

- Replaces crowded system alerts and the full-page overlay with a compact SMART-style activity sheet for full and single benchmark confirmation. Settings, target folder, and write warning are separated for readability.
- After starting, the same sheet shows a progress bar, current test, status, and cancel action. Hiding it does not stop the benchmark; reopen it from the benchmark page while the run is active.
- Caches display-only free space so sheet transitions do not repeatedly query the volume on the main thread. The target, write access, and free space are checked again immediately before a run.

### Download, Compatibility, And Safety

- Release package: `Capricorn-v2.9.1-macOS.zip`; App: `Capricorn V2.9.1.app`.
- Requires macOS 14.0 or later; smartctl 7.5 is bundled.
- Benchmarking may create a complete temporary file and cause storage writes and wear. Check the target disk, free space, and backups before running. Hiding progress is not cancellation; temporary files follow the existing session cleanup path.
- Full and single-test confirmation presentation and dismissal were visually checked, but no complete physical benchmark was run. In-run progress animation remains unverified on a physical drive.

### Verification

- All 340 macOS tests passed (0 failures); strict-concurrency build, Swift 6 compatibility build, and Release Archive succeeded. The Swift 6 gate reported one existing `init(cString:)` deprecation warning without failing the build.
- Archived App metadata is Version 2.9, Build 1, and display name Capricorn V2.9.1. The universal arm64/x86_64 executable, bundled smartctl/SAT resources, and matching dSYM UUIDs were verified.
- ZIP size: 9,633,338 bytes; SHA-256: `4cc513658bb74d8acd7c8e29c3c438147a3ba3a81687a6857623a36e760bc270`; `unzip -t` passed.
- Developer ID signing, notarization, and Gatekeeper trust verification were not performed; first launch may require manual approval.
