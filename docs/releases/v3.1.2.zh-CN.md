# Capricorn V3.1.2

发布日期：2026-11-01。完整版本 `3.1.2`，Build `0052`。
构建号是独立、全局递增的四位发布构建序号，不再拼入版本号。

## 本版变化

- 改善磁盘短暂正忙时的 SNT 读取，加入有限次卸载重试。
- 无法卸载时显示更清晰的提示及可能占用磁盘的程序，便于释放磁盘后重试。

## 安装与安全

下载 `Capricorn-v3.1.2-macOS.zip` 并安装固定名称 `Capricorn.app`。需要 macOS 14.0 或更高版本，包含 arm64/x86_64。V2.10.2 及以后支持应用内更新；更早版本和旧开发 Build `1000` 需手动安装。

特权设备服务须在设置中启用并完成系统批准。推荐 `/Applications`，也可使用本机可写、非可移除磁盘上的固定文件夹。手动移动或替换 App 前先停用服务；应用内更新会尝试恢复此前已启用的服务，系统仍可能要求重新批准。

每次 SNT 仍须确认卸载该 USB 设备上的全部卷，请先关闭文件、结束其他磁盘任务并备份重要数据。结束后尝试恢复挂载，失败时可能需要重新连接或使用“磁盘工具”。重试不会强制卸载或结束程序，显示的占用程序仅是排查线索。可移动卷隐私授权由系统单独管理，后台扫描不会主动接管 USB 设备。

兼容性取决于桥接器、固件与设备，不保证所有 USB 设备可用，也不提供通用 SD 卡健康读取。本次未在真实 SanDisk 设备上复现占用故障，未执行真实 SNT 接管、卷卸载或硬件自检。

常规读取使用内置 smartctl 7.5，SAT SMART Drive 可选。测速与负载使用所选文件夹中的临时文件，写入测试可能给存储带来压力，请确认目标并保留备份。

App、服务及工具使用同团队 Apple Development 证书签名，更新使用既有 Ed25519 密钥；没有 Developer ID 或 Apple 公证。

存档源码独立 Universal Release 构建通过。更新包和清单 Ed25519 签名复验通过，真实 Sparkle 候选源验证旧 Build `0051` 发现 `3.1.2 / 0052`，当前 `0052` 无更新。

安装回归使用隔离测试 App、历史与偏好，不替换真实用户 App 或数据库。服务衔接场景使用模拟协调器，不等于真实 root 服务跨版本安装或授权保留验收。Intel、macOS 14 及其他 Mac 的证书信任与服务批准仍需另行验证。
