# Capricorn V2.7.3 English Release Notes

Release date: 2026-09-19

Bilingual release notes: [v2.7.3.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.3/docs/releases/v2.7.3.md)

Capricorn V2.7.3 uses `Version = 2.7`, `Build = 3`, and the display name `Capricorn V2.7.3`.

## Highlights

- When an external Samsung Portable SSD T5 has no SMART data and SAT SMART Drive is installed, Overview and SMART show a Driver Conflict warning explaining that Samsung's driver may conflict with SAT SMART Drive and that removing it may restore SMART access.
- When an external USB-NVMe drive has no SMART data and SAT SMART Drive is installed, Capricorn explains that some USB-NVMe bridges cannot expose SMART data on macOS.
- Both warnings are gated by device type, SMART results, and SAT installation state; they are never forced onto ordinary drives.
- Overview places the warning at the end of Providers without an extra divider. SMART uses concise, single-line guidance to reduce visual space.

## Download And Compatibility

- Release package: `Capricorn-v2.7.3-macOS.zip`
- App name: `Capricorn V2.7.3.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled.
- SAT SMART Driver is optional for compatible USB-SATA devices and is never installed or loaded automatically.
