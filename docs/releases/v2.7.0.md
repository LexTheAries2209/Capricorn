# Capricorn V2.7.0

中文发布说明：[v2.7.0.zh-CN.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.0/docs/releases/v2.7.0.zh-CN.md)

English release notes: [v2.7.0.en.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.0/docs/releases/v2.7.0.en.md)

发布日期 / Release date: 2026-09-17

本版整理 `v2.6.3` 之后的改动，重点完善侧边栏状态反馈、SAT SMART Drive 引导、无 SMART 数据设备的界面判断，以及历史记录的匹配与自适应布局。

This release summarizes the changes since `v2.6.3`, focusing on sidebar status feedback, contextual SAT SMART Drive guidance, capability-aware presentation for devices without SMART data, and more robust history matching and layout.

## 中文

Capricorn V2.7.0 使用 `Version = 2.7`、`Build = 0` 和 Display Name `Capricorn V2.7.0`。

### 主要更新

- 重构侧边栏状态区域：固定显示硬盘健康摘要和刷新状态，保留最近三条去重活动及本机时间，并根据实际消息数量动态调整高度。
- 为 SMART 读取、硬盘扫描、占用程序查看和硬盘操作补充完成状态；已装载卷的“装载”操作会正确禁用。
- 将版本号和 macOS 用户名放到设置同一行，完善身份提示、状态文案和 SD 卡相关中英文翻译，并统一语言切换控件的右侧对齐。
- 按设备能力控制 SMART 界面：系统盘不显示 SMART 错误条目，无 SMART 属性或网络设备不显示诊断模块，网络盘也不显示快速自检；网络盘标题优先显示主机名或地址，缺失序列号显示“无”。
- 为符合条件但未返回 SMART 数据的 USB 存储设备加入 SAT SMART Drive 引导和设置入口；网络盘、SD 卡、内部硬盘及已有 SMART 数据的设备不会误触发该提示。
- 改进历史记录：快速自检支持卷 UUID 后备匹配；无 SMART 属性时隐藏自检报告，并在 SMART 能力恢复后自动重新显示；历史页和测速曲线可随窗口宽度自适应排列。

### 下载与兼容性

- Release 包名：`Capricorn-v2.7.0-macOS.zip`
- App 名称：`Capricorn V2.7.0.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。
- SAT SMART Driver 仅是兼容 USB-SATA 设备的可选组件。Capricorn 不会自动安装或加载驱动，也不会修改系统安全设置。
- 网络盘、SD 卡或其他设备显示 SMART 不可用，仅代表当前接口未提供可读取的数据，不等同于设备发生硬件故障。

## English

Capricorn V2.7.0 uses `Version = 2.7`, `Build = 0`, and the display name `Capricorn V2.7.0`.

### Highlights

- Reworks the sidebar status area with pinned drive-health and refresh rows, the three most recent deduplicated activities with local timestamps, and height that follows the actual message count.
- Adds explicit completion states for SMART reads, drive scans, open-file inspection, and disk operations; Mount is now disabled for volumes that are already mounted.
- Places the version and macOS user name on the Settings row, completes identity/status/SD-card localization, and aligns the language control with the refresh action.
- Makes SMART presentation capability-aware: system disks omit SMART error entries, devices without SMART attributes and network volumes omit diagnostics, and network volumes omit Quick Disk Check. Network sidebar titles prefer the host name or address, and missing serial numbers display as None.
- Adds contextual SAT SMART Drive guidance and a Settings deep link for eligible USB storage devices that return no SMART data, without prompting for network, SD, internal, or already SMART-capable devices.
- Improves history behavior with volume-UUID fallback matching for Quick Disk Check, capability-aware self-test report visibility that recovers when SMART data returns, and adaptive History/benchmark chart layouts.

### Download And Compatibility

- Release package: `Capricorn-v2.7.0-macOS.zip`
- App name: `Capricorn V2.7.0.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
- SAT SMART Driver remains optional for compatible USB-SATA devices. Capricorn does not install or load it automatically or change system security settings.
- SMART-unavailable states for network volumes, SD cards, or other devices mean that the current interface provides no readable data; they do not by themselves indicate hardware failure.
