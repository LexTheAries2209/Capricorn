# Capricorn V2.11.0

Release date: October 19, 2026.

## Version And Installation

- Complete Version `2.11.0`, Build `0046`. Build is an independent, globally increasing four-digit release-build sequence and is not appended to the version.
- Download `Capricorn-v2.11.0-macOS.zip` and install the fixed-name `Capricorn.app`.
- V2.10.2 and later support in-app upgrades; earlier versions and old development Build `1000` require manual installation.
- Requires macOS 14.0 or later; includes arm64 and x86_64.

## Highlights

- Offers Default, Quick, SSD, HDD, and Custom benchmark profiles. Asynchronous T now represents real worker threads; linked Q/T choices keep their product at or below 16. Custom still requires Developer Options and its custom-benchmark switch.
- Quick tests sequential 1 MiB Q1T1 and random 4 KiB Q1T1, transferring 128 MiB and 1 MiB respectively, with one measured pass after warm-up and no added pauses. It checks basic read/write behavior and does not replace a complete media or bad-sector check.
- Improves asynchronous I/O reliability in benchmarks and large-file workloads when resources are temporarily unavailable. Stopping safely waits for submitted requests, improving subsequent reruns.
- Defaults large-file workloads to 128 GiB and remembers the last size per drive. Preparation and stopping show clearer explanations, elapsed wait time and pending I/O or the current preparation/flush stage; the final status simply says the workload stopped.

## Updates And Safety

Launch checks and developer automatic updates default to off. Downloads and installation require confirmation unless automatic updates are enabled; conflicting tasks or failed history saves block installation.

The feed and archive use the existing Ed25519 key. The App has valid ad-hoc signatures without Developer ID or Apple notarization; first launch may require manual approval. smartctl 7.5 is bundled. SAT SMART Drive is optional and configured manually for applicable devices.

Benchmarks and workloads create temporary files in the selected folder and do not write directly to raw devices. Reads may first create a source file; sustained writes cause storage stress and wear. Verify targets and back up important data. The process AIO allowance still limits actual concurrency.
