# Capricorn V2.7.6 English Release Notes

Release date: 2026-09-20

Bilingual release notes: [v2.7.6.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.6/docs/releases/v2.7.6.md)

Capricorn V2.7.6 uses `Version = 2.7`, `Build = 6`, and the display name `Capricorn V2.7.6`.

## Highlights

- When the app runs as an XCTest host, it no longer starts real disk refresh, disk-event monitoring, or GitHub update checks, preventing system I/O and network side effects from blocking the test process.
- SMART tests use an isolated command coordinator instead of sharing the global runtime queue, reducing cross-test waits.
- Bundled `smartctl` scan, SMART read, and version queries now have 15-second, 30-second, and 10-second timeouts. Timed-out child processes are terminated and release the coordinator queue.
- Network volumes and memory cards now return unsupported before `smartctl` device scanning, avoiding unnecessary external commands and CI waits.
- The GitHub Actions quality workflow now runs only for `Main` branch pushes and pull requests, avoiding a duplicate full suite for release tags.
- New runs on the same branch cancel older runs. Full tests have a 20-minute limit, while strict-concurrency and Swift 6 compatibility builds have 15-minute limits.
- CI explicitly disables app startup side effects and enables unbuffered logging so any future stall is easier to locate.

## Download, Compatibility, And Safety

- Release package: `Capricorn-v2.7.6-macOS.zip`
- App name: `Capricorn V2.7.6.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled.
- SAT SMART Driver is optional for compatible USB-SATA devices and is never installed or loaded automatically.
- Capricorn creates temporary files only in the selected benchmark folder and never writes directly to raw devices. Read Only may still create a preparation file and is not a zero-write mode.
- Write, mixed, looped benchmark, and Live Activity large-file workloads create storage writes and wear. Confirm the target and available capacity first.
