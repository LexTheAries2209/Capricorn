This release summarizes the changes since `v2.5.1`, including optional SAT SMART Driver support, SMART passthrough diagnostics, Live Activity control refinements, and the sidebar identity layout update.

## 中文

Capricorn V2.6.3 使用 `Version = 2.6`、`Build = 3` 和 Display Name `Capricorn V2.6.3`。

### 主要更新

- 新增可选 SAT SMART Driver 支持与设置诊断，覆盖兼容 USB-SATA 设备的安装状态、版本、来源和透传能力说明。
- 增强 USB-SATA/USB-NVMe SMART 透传状态展示，隐藏无法由实际读取结果证实的数据来源，并补充动态诊断的简体中文文案。
- 完善 SMART 读取回退与能力缓存，保留设备暂时读取失败时的上一次有效数据，并避免强行执行 macOS 不支持的 NVMe 管理命令。
- 重新整理实时活动页的监控、采样间隔、工作负载目标和动作控件布局，保持监控磁盘与侧边栏选择联动。
- 将版本号和 macOS 用户名移到侧边栏底部状态行右侧并右对齐；移除设置入口的 `Command-P` 快捷键及界面提示。

- SAT SMART Driver 安装包仅作为兼容 USB-SATA 设备的可选组件，Capricorn 不会自动安装、加载驱动或修改系统安全设置。

## English

Capricorn V2.6.3 uses `Version = 2.6`, `Build = 3`, and the display name `Capricorn V2.6.3`.

### Highlights

- Adds optional SAT SMART Driver support and Settings diagnostics for compatible USB-SATA devices, including installation state, version, source, and passthrough guidance.
- Improves USB-SATA and USB-NVMe SMART passthrough reporting, hides sources that cannot be confirmed by an actual read, and adds localized dynamic diagnostics.
- Strengthens SMART read fallback and capability caching, preserving last-known-good data across transient probe failures and never forcing unsupported macOS NVMe admin commands.
- Reworks Live Activity controls for monitoring, sample intervals, workload targets, and actions while keeping the monitored drive linked to sidebar selection.
- Moves the app version and macOS user name to the right-aligned status row at the bottom of the sidebar; removes the Settings `Command-P` shortcut and its visible hint.

### Download And Compatibility

- Release package: `Capricorn-v2.6.3-macOS.zip`
- App name: `Capricorn V2.6.3.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
- The SAT SMART Driver installer is optional for compatible USB-SATA devices. Capricorn does not install or load it automatically or change system security settings.

- Release build succeeded; App metadata, bundled resources, and arm64/x86_64 universal architecture were checked.
- Strict-concurrency and Swift 6 compatibility builds passed; Swift 6 reported only the existing `String(cString:)` deprecation warning.
- Package size: 11,716,005 bytes; SHA-256: `0879e04d802487880d7b21b3bf755b072985091d2a5429c75a6936e7694dfb05`; `unzip -t` passed.
- Developer ID signing, notarization, and Gatekeeper trust checks were intentionally skipped; macOS may require manual approval on first launch.
