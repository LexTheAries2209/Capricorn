# Capricorn V3.1.0

发布日期：2026-11-01。完整版本 `3.1.0`，Build `0050`。
构建号是独立、全局递增的四位发布构建序号，不再拼入版本号。

## 更新内容

- 新增经系统批准的特权设备服务，供 SMART 读取、受支持的自检和手动 SNT 共用，减少重复认证。
- 支持在本地固定文件夹启用服务，应用内更新时安全停用并尝试恢复服务。
- 设置说明改为鼠标悬浮提示，拓扑补充更多 SSD 型号名称。

## 安装与安全

下载 `Capricorn-v3.1.0-macOS.zip`，安装固定名称 `Capricorn.app`。要求 macOS 14.0 或更新系统。V2.10.2 及以后支持应用内更新；更早版本和旧开发 Build `1000` 需手动安装。

在设置中启用特权设备服务并完成系统批准。推荐 `/Applications`，也可使用本机可写、非可移除磁盘上的固定文件夹。临时、系统转移、只读、可移除和网络位置不支持启用服务。移动或手动替换 App 前先停用服务；应用内更新会尝试恢复此前已启用的服务，系统仍可能要求重新批准。

SNT 每次仍需确认卸载该 USB 设备上的所有卷，结束后尝试恢复挂载；请先关闭文件、结束其他磁盘任务并备份重要数据。恢复失败时可能需要重新连接或使用“磁盘工具”。可移动卷隐私授权由系统单独管理，后台扫描不会主动接管设备。

已完成本机真实特权服务和外接 NVMe SMART/日志只读验证；USB-SNT 的隐私归属、接管和恢复挂载，以及硬件自检启动/中止仍需对应设备验收。支持 JMicron、ASMedia、Realtek 的实验性桥接协议，不保证所有设备或固件可用，不提供通用 SD 卡健康读取。

内置 smartctl 7.5，SAT SMART Drive 可选。测速与负载仅使用用户选择文件夹中的临时文件，写入测试可能增加磁盘负载。

App 与服务使用 Apple Development 证书签名，更新包和清单使用既有 Ed25519 密钥；没有 Developer ID 或 Apple 公证，不能保证其他 Mac 上首次运行和服务授权的体验。
