# Capricorn V2.7.5

中文发布说明：[v2.7.5.zh-CN.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.5/docs/releases/v2.7.5.zh-CN.md)

English release notes: [v2.7.5.en.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.5/docs/releases/v2.7.5.en.md)

发布日期 / Release date: 2026-09-20

本版完善 SMART 历史摘要和完整报告，并把历史记录的分组管理、导出与可选删除操作整理成更清晰的一套流程。

This release expands SMART History summaries and full reports while making grouped history management, export, and optional deletion more coherent.

## 中文

Capricorn V2.7.5 使用 `Version = 2.7`、`Build = 5` 和 Display Name `Capricorn V2.7.5`。

### 主要更新

- SMART 历史摘要显示健康、寿命、介质错误、累计读取量、累计写入量和通电时间，并补全简体中文显示。
- 每条 SMART 快照可打开独立、可滚动的完整报告窗口，查看快照摘要和全部 SMART 属性；窗口内可选择文件夹并再次保存 CSV。
- SMART 页面新增独立“保存到历史”操作，不生成 CSV；“保存 CSV”仍会同时把当前快照写入历史。
- 测速历史以共享同一张活动曲线的结果作为一个完整任务，隐藏、恢复和删除会整组处理。
- 紧凑测速图会在保留网格线数量和间距的前提下跳过部分速度标签，避免刻度文字错位或拥挤。
- 设置新增默认关闭的历史逐条删除功能。开启后，可见和已隐藏的 SMART、测速与实时活动记录均可在二次确认后永久删除，且不会转入隐藏记录。
- SMART 快照操作文字精简为“选择文件夹”“保存到历史”和“保存 CSV”。

### 下载、兼容性与安全

- Release 包名：`Capricorn-v2.7.5-macOS.zip`
- App 名称：`Capricorn V2.7.5.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置，运行时不需要另外安装 smartmontools。
- SAT SMART Driver 仅是兼容 USB-SATA 设备的可选组件。Capricorn 不会自动安装或加载驱动，也不会修改系统安全设置。
- Capricorn 只在选择的测速目标文件夹中创建临时文件，不会直接写入裸设备。即使选择“仅读取”，读取基准也可能先创建准备文件，因此不能视为零写入模式。
- 写入、混合、循环测速和实时活动大文件负载会产生存储写入和磨损，开始前请确认目标磁盘和可用空间。
- 历史逐条删除不可撤销，因此默认关闭并始终要求二次确认。

## English

Capricorn V2.7.5 uses `Version = 2.7`, `Build = 5`, and the display name `Capricorn V2.7.5`.

### Highlights

- SMART History summaries show health, life remaining, media errors, cumulative reads, cumulative writes, and power-on time, with complete Simplified Chinese localization.
- Every SMART snapshot can open a separate scrolling full-report window containing the snapshot summary and all SMART attributes. The window can choose a folder and export another CSV.
- SMART adds a separate Save to History action that does not create a CSV. Save CSV continues to store the current snapshot in History.
- Benchmark History treats all results sharing one activity chart as a complete run, so hide, restore, and delete actions operate on the whole group.
- Compact benchmark charts skip selected speed labels while retaining the same grid-line count and spacing, preventing crowded or misaligned axis text.
- Settings adds a default-off individual history deletion option. When enabled, visible and hidden SMART, benchmark, and Live Activity records can be permanently removed after confirmation instead of being moved to hidden records.
- SMART snapshot actions use the shorter Select Folder, Save to History, and Save CSV labels.

### Download, Compatibility, And Safety

- Release package: `Capricorn-v2.7.5-macOS.zip`
- App name: `Capricorn V2.7.5.app`
- System requirement: macOS 14.0 or later
- smartctl 7.5 is bundled; no separate smartmontools installation is required at runtime.
- SAT SMART Driver remains optional for compatible USB-SATA devices. Capricorn does not install or load it automatically or change system security settings.
- Capricorn creates temporary files only inside the selected benchmark target and never writes directly to raw devices. Read Only benchmarks may still create a preparation file, so the option is not a zero-write mode.
- Write, mixed, looped benchmark, and Live Activity large-file workloads create storage writes and wear. Confirm the target and free space before starting.
- Individual history deletion is irreversible, so it is disabled by default and always requires confirmation.
