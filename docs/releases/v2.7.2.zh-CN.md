# Capricorn V2.7.2 中文发布说明

发布日期：2026-09-17

双语发布说明：[v2.7.2.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.7.2/docs/releases/v2.7.2.md)

Capricorn V2.7.2 使用 `Version = 2.7`、`Build = 2` 和 Display Name `Capricorn V2.7.2`。

## 主要更新

- 设置新增“界面显示”与“快捷键”模块；快捷键位于 SMART 下方、历史数据库上方，集中列出打开设置、刷新、保存 SMART 快照和功能页切换操作。
- 自动刷新硬盘、休眠硬盘保护和 SMART 诊断选项已合并到“硬盘操作”，历史数据库移动到设置页底部，使相关设置更集中。
- 功能页现在始终使用 `Tab` 按顺序切换；移除原设置开关以及 Control-Tab、Control-Shift-Tab 组合，仅保留 Tab 快捷键。
- App 内的 SAT SMART Drive 资源仅保留 `SATSMARTDriver-0.10.3.pkg`，不再重复打包 ZIP 安装包。

## 下载与兼容性

- Release 包名：`Capricorn-v2.7.2-macOS.zip`
- App 名称：`Capricorn V2.7.2.app`
- 系统要求：macOS 14.0 或更新版本
- smartctl 7.5 已内置。
- SAT SMART Driver 是兼容 USB-SATA 设备的可选组件，不会被自动安装或加载。
