# Capricorn V2.10.4

发布日期：2026-10-17。

## 版本与安装

- 完整版本 `2.10.4`，Build `0044`。构建号是独立、全局递增的四位发布构建序号，不再拼入版本号。
- 下载 `Capricorn-v2.10.4-macOS.zip`，解压后安装固定名称的 `Capricorn.app`。
- V2.10.2 / V2.10.3 可通过应用内更新升级。V2.10.1 及更早版本、旧开发 Build `1000` 需手动安装。
- 系统要求：macOS 14.0 或更高版本，包含 arm64 和 x86_64。

## 更新内容

- 更新下载、安装和重启均需用户确认，移除自动下载与退出时安装。发现新版本后，设置提示点击“检查更新”下载并安装。
- 设置中的“SMART”模块改为“第三方组件”，集中显示 Sparkle、smartctl 和 SAT SMART Drive 的版本与项目链接。
- 移除独立第三方许可阅读窗口，完整说明继续保留在源码中；SAT 版本号移至标题右侧，精简说明。
- 虚拟硬盘开关改名为“允许添加虚拟硬盘”，行为不变。

## 更新与安全

启动检查默认关闭，保留已保存的选择；15 秒无结果自动结束，可在下次启动或手动重试。旧的自动下载选择会关闭，原生更新窗口不再显示自动下载选项。下载由用户发起，准备完成后需明确确认安装并重启；取消或普通退出不会安装尚未确认的更新。有冲突磁盘任务时仍提示并阻止更新，安装前保存历史。

下载遵循系统代理，清单与安装包使用原有 Ed25519 密钥验证。App 使用 ad-hoc 签名，没有 Developer ID 或 Apple 公证，首次启动可能需要手动允许。

替换 App 不会清除应用数据目录中的 SwiftData 历史。安装回归使用隔离的测试历史与偏好，不代表对真实用户数据库进行了迁移演练，也不证明 Intel 或 macOS 14 真机安装行为。内置 smartctl 7.5，无需额外安装；磁盘写入和大文件负载仍需确认目标并保留备份。
