# Capricorn V3.2.1

Release date: November 3, 2026. Complete Version `3.2.1`, Build `0056`, macOS 14.0+.

Build is an independent, globally increasing four-digit release-build sequence and is not appended to the version.

- Reuses valid SNT data for 48 hours while keeping manual refresh available; failed refreshes retain the previous reading.
- Shows the actual capture time in the SNT SMART table and history reports, with the corresponding timestamp in CSV exports.
- Reduces the default Name column width by 15% to give ID more space.

Download `Capricorn-v3.2.1-macOS.zip` and install the stable-name `Capricorn.app`. V2.10.2 and later support in-app upgrades; earlier versions and old development Build `1000` require manual installation.

Automatic reads are off by default and require the device service, system approval and required volume access. Launch and connection reuse successful readings less than 48 hours old. Expiry alone does not start a read while a disk remains connected. Failed and busy attempts do not extend freshness; a successful manual read starts a new period. Three consecutive effective failures or unsuccessful reads using all three unknown bridge protocols stop automatic attempts; uncertain mount restoration pauses operation.

SNT temporarily unmounts every volume on the device and attempts to restore mounts. Close files, finish disk tasks and back up important data first. No forced unmount or process termination is used. Compatibility depends on the bridge, firmware and device; not every USB device is supported, and general SD-card health queries are not provided.

Enable the service from `/Applications` or another permanent folder on a local writable, non-removable disk. Disable it before manually moving or replacing the app. In-app updates attempt to restore a previously enabled service; macOS may require renewed approval. smartctl 7.5 is bundled; SAT SMART Drive is optional. Benchmarks and workloads use temporary files in the selected folder.

Full suite: 754 tests, 751 passed, 3 hardware or certificate-condition skips, zero failures. Strict concurrency, Swift 6, universal archive, archived app launch, bundle signatures, dSYM checks and an independent universal Release build of the archived source passed. Twenty real Sparkle fixture scenarios passed, retaining isolated history and preferences with a mock service-handoff coordinator; the download-conflict fixture passed with a two-second download delay. Package and feed signatures passed verification. Real Sparkle staging-feed checks confirmed that Build `0055` discovers `3.2.1 / 0056` and Build `0056` reports no update.

Same-team Apple Development certificate signing and the existing Ed25519 update signature are retained; Developer ID and Apple notarization are not established. SNT validation uses simulated devices and commands. Real-device permission changes, occupancy checks, unplugging during capture, multivolume restoration, Intel/macOS 14 and service approval on other Macs require separate validation.

`Capricorn-v3.2.1-source.tar.gz` includes complete corresponding source, upstream source archives for both smartctl tools, local patches and licenses.
