# Capricorn V2.9.2 English Release Notes

Release date: 2026-09-28

Bilingual release notes: [v2.9.2.md](https://github.com/LexTheAries2209/Capricorn/blob/v2.9.2/docs/releases/v2.9.2.md)

Capricorn V2.9.2 uses `Version = 2.9`, `Build = 2`, and display name `Capricorn V2.9.2`.

## Highlights

- Expands the local model catalog for Seagate BarraCuda 2.5-inch, Portable, Expansion Portable, Backup Plus, One Touch and Ultra Touch, and LaCie Mobile Drive and Rugged Mini. Distinct product names and specific USB identity/capacity matches take priority over generic rules. This does not update the upstream smartmontools drive database.
- Fixes SMART self-test status interpretation: explicit pass/completion overrides remaining percentage, preventing completed zero-remaining entries from showing as running. History labels terminal capture times as completed, but nonterminal times as captured. A read-only check of a connected `ST5000LM000-2U8170` showed `Completed without error` for a short test at 442 power-on hours; other devices have not all been field-validated.

## Download, Compatibility, and Safety

- Package: `Capricorn-v2.9.2-macOS.zip`; App: `Capricorn V2.9.2.app`.
- macOS 14.0 or later; smartctl 7.5 is bundled. Some USB bridges cannot pass SMART/self-test commands.
- Model matching changes only displayed metadata; the state fix does not start another test or modify stored data. Keep important data backed up.
- This distribution is not Developer ID signed, notarized, or Gatekeeper-trust verified; manual approval may be required on first launch.
