# Capricorn V1.1.1 Release Notes

Capricorn V1.1.1 uses `Version = 1.1` and `Build = 1`, with the public Display Name `Capricorn V1.1.1`. This release makes SMART values easier to read and adds more flexible continuation and single-item workflows for Live Activity and benchmarks.

## Download

- Release package: `Capricorn-v1.1.1-macOS.zip`
- App name: `Capricorn V1.1.1.app`
- Requirement: macOS 14.0 or later

On first launch, if macOS Gatekeeper shows an internet-download warning, right-click the app in Finder and choose Open, or allow it from System Settings > Privacy & Security.

## SMART Display

- A native macOS SMART temperature reported in Kelvin is shown as, for example, `312 K (39 °C)`. If the provider already reports Celsius, it remains a Celsius-only value such as `35 °C`.
- Native macOS and `smartctl` NVMe `Data Units Read` and `Data Units Written` values are converted to TB, with the raw unit count retained in parentheses for source comparison.
- Both providers use the same NVMe Data Unit interpretation, replacing hard-to-read raw integers with consistent values.

## Live Activity

- Continue Monitoring is available after stopping. New samples append to the existing chart so trends remain visible across the pause.
- The existing Start Monitoring behavior is unchanged: it clears the chart and starts a new monitoring segment. Both paths remain available.

## Benchmark

- Clicking a green result-row button runs only that item once using the currently selected engine, file size, and data pattern.
- A single-item run forces one pass and disables incremental testing. The write warning and concise configuration confirmation still appear before starting.
- An active full or single-item benchmark blocks another run and tells the user to stop the current test first.
- A new Improve Small-Block Test Efficiency option scales the actual test data for 4 KiB, 16 KiB, and 64 KiB items to 5%, 10%, 20%, 30%, or 50%.
- The option is off by default and selects 20% the first time it is enabled. The switch and percentage selector are locked while testing.
- The ratio applies to full and single-item runs with synchronous and asynchronous engines; larger block sizes continue to use the full configured test data.
- Typography and layout adjustments keep longer benchmark item names on one line inside the green row buttons.
