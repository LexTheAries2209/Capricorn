## English

Capricorn V1.2.12 uses `Version = 1.2`, `Build = 12`, and Display Name `Capricorn V1.2.12`. It adds a quiet GitHub stable-release check and a more readable localized CSV SMART snapshot export.

### Highlights Since V1.2.11

- Checks GitHub quietly at launch and exposes manual check, retry, and Releases actions from Settings and the application menu. Network failure does not affect disk features.
- Exports SMART snapshots as one compact CSV; Simplified Chinese adds a Chinese-name column and matching localized explanations, while English keeps English names and explanations.
- Uses UTC+8 for Simplified Chinese filenames and UTC+0 for English filenames, with an explicit timezone label.

### Safety And Limitations

- Update checks only call the GitHub API and never download or replace the App automatically.
- Code signing and notarization are intentionally skipped for this release; no signed or notarized status is claimed.

### Release Verification

- Full test suite: 181 passed, 0 failed; strict-concurrency build passed; Swift 6 build passed with one existing `String(cString:)` deprecation warning.
- Release App: macOS 14.0+, universal arm64/x86_64 binary, version `1.2 / 12 / Capricorn V1.2.12`.
- ZIP: `Capricorn-v1.2.12-macOS.zip`, `9,204,446` bytes, SHA-256 `de2e3294af9ac72c1700c40d3131e966759090ab9495f932b001983d76ba9cc5`; integrity check passed.
- The V1.2.12 old-version archive builds independently. This release intentionally skips signing and notarization, and its App bundle is unsigned.
