## English

- Offers Default, Quick, SSD, HDD, and developer Custom profiles. Asynchronous T represents real worker threads; linked Q/T choices keep their product at or below 16, with the existing two-switch Custom permission unchanged.
- Quick uses sequential 1 MiB Q1T1 and random 4 KiB Q1T1 groups, transferring 128 MiB and 1 MiB respectively, with one measured pass after warm-up for a basic read/write check.
- Improves asynchronous I/O reliability in benchmarks and large-file workloads, safely waiting for submitted I/O when stopping.
- Defaults large-file workloads to 128 GiB and remembers each drive's size, with clearer preparation and stop-wait messages and a simple stopped status.

Download `Capricorn-v2.11.0-macOS.zip` and install `Capricorn.app`. V2.10.2 and later support in-app upgrades; earlier versions or old development Build `1000` require manual installation.

Launch checks and developer automatic updates default to off. The signed feed and archive use the existing Ed25519 key. The App has valid ad-hoc signatures without Developer ID or Apple notarization. smartctl 7.5 is bundled; SAT SMART Drive is optional. Tests use temporary files in the selected folder; reads may first write a source file. Verify targets and back up important data. Quick does not replace a complete media check.
