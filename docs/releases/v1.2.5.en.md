# Capricorn V1.2.5 Release Notes

Capricorn V1.2.5 uses `Version = 1.2`, `Build = 5`, and Display Name `Capricorn V1.2.5`. This release focuses on SMART self-tests, smartctl 7.5 compatibility, and a less intrusive external-drive SMART layout.

## Download

- Release package: `Capricorn-v1.2.5-macOS.zip`
- App name: `Capricorn V1.2.5.app`
- Requirement: macOS 14.0 or later

## Highlights

- Improves ATA, NVMe, and SAT self-test log parsing, retaining raw smartctl JSON/text as a fallback.
- Adds short/full self-tests, automatic polling, abort, recent records, and detailed status on the SMART page.
- Overview keeps only the latest device-reported self-test summary; full logs and actions live on the SMART page.
- Does not force macOS native NVMe self-tests when admin command `0x14` is unsupported, while preserving available health and log reads.
- System-disk self-tests can be enabled separately in Settings with native macOS administrator authorization.
- Improves smartctl 7.5 diagnostics and sleep protection; verified external SMART details start collapsed.
