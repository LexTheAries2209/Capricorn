## 中文

### 主要更新

- 测速页面将运行、取消、保存结果、目标位置和小块效率设置整合为同排的三个标题分组，保留目标可写状态并移除单独的详细路径行。
- 小块文件测试效率改为下拉框，可选择关闭、5%、10%、20%、30% 或 50%；详细测速配置说明集中在帮助窗口。
- 双击侧栏分隔线可自动适应硬盘信息宽度，更完整地显示长名称、连接信息和容量；仍可手动拖动调整。
- 实时活动大图显示九个纵轴标签，标题与速度标签居中对齐；概览移除重复的 SMART 状态块。

### 下载、兼容性与安全

- 下载：[Capricorn-v2.9.8-macOS.zip](https://github.com/LexTheAries2209/Capricorn/releases/download/v2.9.8/Capricorn-v2.9.8-macOS.zip)；App 名称：`Capricorn V2.9.8.app`。
- 版本元数据：Version `2.9`、Build `8`、显示名 `Capricorn V2.9.8`。
- 需要 macOS 14.0 或更新版本；内置 smartctl 7.5，无需另行安装 smartmontools。可选 SAT SMART 驱动不会自动安装。
- SMART 信息取决于设备和桥接器提供的数据；网络卷不提供全部本地物理磁盘活动数据。
- 测速和大文件负载会在选定文件夹创建临时文件。读取负载也需要先写入源文件；持续写入和循环负载可能带来存储压力与磨损，请确认目标位置并保留重要数据备份。
- 此分发包未执行 Developer ID 签名、公证或 Gatekeeper 信任验证，首次运行可能需要手动允许。

## English

### Highlights

- Benchmark actions, target selection, and small-block efficiency share one row in three labeled groups, retaining writable-target status and removing the separate full-path row.
- Small-block efficiency is a dropdown offering Off, 5%, 10%, 20%, 30%, or 50%; detailed benchmark configuration is available in Help.
- Double-clicking the sidebar divider fits drive information for more complete long names, connection details, and capacities; manual resizing remains available.
- Expanded live-activity charts show nine vertical-axis labels with a centered title and speed labels; Overview removes the redundant SMART status tile.

### Download, Compatibility, and Safety

- Download: [Capricorn-v2.9.8-macOS.zip](https://github.com/LexTheAries2209/Capricorn/releases/download/v2.9.8/Capricorn-v2.9.8-macOS.zip); App: `Capricorn V2.9.8.app`.
- Bundle metadata: Version `2.9`, Build `8`, display name `Capricorn V2.9.8`.
- macOS 14.0 or later; smartctl 7.5 is bundled, so smartmontools need not be installed separately. The optional SAT SMART driver is not installed automatically.
- SMART information depends on the device and bridge; network volumes do not provide all local physical-disk activity data.
- Benchmarks and large-file workloads create temporary files in the selected folder. Read workloads also write source files before reading; sustained writes and loops can cause storage stress and wear. Verify the target and keep important backups.
- This distribution is not Developer ID signed, notarized, or Gatekeeper-trust verified; manual approval may be required on first launch.
