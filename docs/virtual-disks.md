# 虚拟硬盘：第一阶段

分支：`codex/virtual-disk-overview`。

## 范围

虚拟硬盘是用户自定义的模拟设备，只在当前应用会话中存在。第一阶段完成创建、概览展示和推出删除，不创建磁盘镜像、文件系统或真实挂载点，不预分配磁盘空间。

“添加虚拟硬盘”仅在开发者总开关和“开启虚拟硬盘”均开启时显示。关闭这些开关隐藏新增入口，已有设备仍可查看和推出。

## 配置

| 分组 | 字段 |
| --- | --- |
| 硬盘信息 | 名称、可选型号、可选序列号、容量及 MB/GB/TB 单位、SSD/HDD、NVMe/SATA/USB/Thunderbolt、512/4096 B 扇区 |
| 分区 | 可添加和移除；每个分区包含名称、容量及单位、已用容量、APFS/ExFAT/NTFS/HFS+/未格式化 |
| 概览指标 | 健康状态，以及可留空的温度、剩余寿命、通电小时、通电次数、介质错误、异常断电次数 |

默认创建 1 TB SSD 和一个 1 TB 数据分区。容量采用十进制单位。分区总容量不能超过硬盘容量，已用容量不能超过分区容量，可以保留未分配空间或不创建分区。

## 展示与生命周期

- 侧栏及概览标题使用配置的硬盘名称，并追加 `（虚拟硬盘）`；英文使用 `(Virtual Disk)`。
- 概览展示容量、已用/可用空间、格式、健康和配置的指标，另列未分配空间、扇区大小及分区详情。未填写指标显示不可用。
- 数据来源明确标为模拟数据。第一阶段仅开放概览，不接入真实 SMART、测速、实时活动、磁盘急救或文件操作。
- 刷新真实设备时保留当前会话中的模拟硬盘，模拟数据不会被真实磁盘扫描覆盖。
- 侧栏硬盘操作菜单和概览均提供“推出”。推出立即移除模拟设备及其会话数据；退出应用也不保留设备。
- 所有模拟设备均禁止历史写入、历史匹配、SMART 能力缓存和卷宗选择持久化。此规则不依赖是否填写序列号。
- 模拟设备以独立的会话 UUID 标识。即使与真实硬盘或其他模拟设备使用相同名称、型号、序列号，也不共享身份或数据；推出不清除真实硬盘记录。

## 后续阶段

后续单独规划模拟 SMART 属性、可调整的运行状态和负载行为。保持模拟设备与真实磁盘命令、缓存、历史的边界，未经新需求不加入设备恢复或永久保存。
